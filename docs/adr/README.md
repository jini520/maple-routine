# 폐기된 결정 — 주제별 목록

번호순 인덱스([`../ADR.md`](../ADR.md))로는 "이 영역에서 뭐가 죽었는지"가 한눈에 안 보인다.
죽은 ADR 36개를 주제로 묶어 여기 모았다. **같은 문제를 두 번 풀지 않으려고 만든 목록이다.**

**파일은 합치지 않았다.** 36개가 전부 바깥에서 인용받고 있어서(소스 261건 · 문서 149건) 파일을
지우면 링크가 깨진다. 여기는 목차이고 본문은 각 파일에 그대로 있다.

**🔗 표시**는 그 문서의 결정 일부가 아직 코드에 살아 있다는 뜻이다. 파일 배너의 🔗 줄에 적힌
것만 인용해도 되고, 나머지는 인용하면 안 된다. 🔗 가 없는 문서는 인용할 것이 하나도 없다 —
소스가 그런 문서를 인용하면 `src/__tests__/adr-citation-policy.test.ts` 가 실패한다.

## 스크롤 · 헤더 · 고정 영역 (14건)

가장 많이 죽은 영역이다. 웹에서 헤더를 화면에 붙여 두려고 `sticky`·`fixed`·실측 spacer 를
번갈아 쓰다가 실패를 반복했고, [[ADR-131]]이 **고정 영역을 아예 두지 않는 것**으로 끝냈다.
RN 에서는 헤더가 스크롤 뷰의 형제라 화면 밖으로 밀려날 수가 없다.

| ADR | 하려던 것 | 죽은 이유 |
|---|---|---|
| [047](./ADR-047.md) 🔗 | 펼친 카드 헤더를 중첩 sticky 로 고정 | [[ADR-131]] 이 중첩 sticky 를 걷었다 |
| [049](./ADR-049.md) 🔗 | 보스 수익 헤더 정렬·유격을 px 로 확정 | px 단위 CSS 기하라 옮겨 온 수치가 없다 |
| [077](./ADR-077.md) 🔗 | 드롭 히스토리를 중첩 라우트 + 전면 오버레이로 | RN 스택 내비게이터가 대체했다 |
| [078](./ADR-078.md) 🔗 | 기간 이동의 브릿지 왕복 줄이기 | 웹뷰 왕복이 전제였다 (병렬·재사용은 살아 있다) |
| [079](./ADR-079.md) 🔗 | 깜빡임을 `will-change` 레이어 고정으로 | 실기기에서 무효 — 페인트가 아니라 레이아웃 문제였다 |
| [080](./ADR-080.md) 🔗 | 깜빡임의 원인은 스크롤 클램프 프레임 | 문서 스크롤이 없어 클램프도 없다 |
| [081](./ADR-081.md) | 아코디언 펼침을 기간별로 기억 | 같은 날 접었다 — 짝인 082 가 불가능해서 |
| [082](./ADR-082.md) 🔗 | 스크롤 위치도 기간별로 기억 | 복원하면 헤더가 한 프레임 사라졌다 |
| [084](./ADR-084.md) | 접기 직후 페인트 전에 스크롤을 자른다 | 웹뷰 시대 결정이라 본문을 지웠다 |
| [085](./ADR-085.md) 🔗 | 헤더를 `fixed` 로 떼고 실측 spacer 를 둔다 | [[ADR-131]] 이 이 구조를 통째로 걷었다 |
| [098](./ADR-098.md) 🔗 | 같은 처방을 스케줄러 4화면으로 확대 | 문서 스크롤 클램프 처방이라 대응물이 없다 |
| [102](./ADR-102.md) 🔗 | 접기 전 사전 스크롤 워크어라운드 제거 | 웹 워크어라운드를 걷는 정리 작업이었다 |
| [107](./ADR-107.md) 🔗 | 캐릭터 관리 모달 높이를 안전영역에서 파생 | [[ADR-144]] 가 모달을 두 층 페이지로 바꿨다 |
| [112](./ADR-112.md) 🔗 | spacer 실측의 한 프레임 어긋남 잡기 | `ResizeObserver` 도 실측 spacer 도 RN 에 없다 |

> **여기서 배운 것**: 웹에서 헤더가 화면 밖으로 날아가는 버그를 다섯 번(079·080·082·085·112)
> 다르게 고치려다 전부 실패했다. 원인은 매번 달랐지만 공통점은 하나였다 — **문서 하나가 스크롤을
> 소유하는 구조**. 구조를 바꾸니([[ADR-131]]) 다섯 개가 한꺼번에 없어졌다.
