# ADR-107: 캐릭터 관리 모달 높이를 안전영역에 묶는다 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-144]] 가 모달을 두 층 페이지로 재설계했다. `vh`·`dvh` 식은 RN 에 없다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(안전영역을 뺀 화면에서 높이를 잰다) · 2(385px 최소 높이는 짧은 화면에서 양보) · 3(스크롤포트는 그리드가 아니라 호스트가 소유) — `CharacterTrackingPicker`·`CharacterTrackingGrid`·`SettingsCharactersScreen` 이 지금도 이 규칙이다.

## 무엇을 결정했었나 (요약)

캐릭터 관리 **모달**의 높이를 안전영역을 뺀 화면에서 파생시키고(`vh` 대신 `dvh` 식), 3줄 최소 높이 385px 는 짧은 화면에서 양보하며, 스크롤포트는 그리드가 아니라 호스트가 소유하게 했다.
