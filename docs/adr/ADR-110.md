# ADR-110 — API 키 발급 가이드를 앱이 아니라 안내 사이트에 둔다 (`mapleroutine.store/api-key`)

> 🟢 **ACTIVE — 유효.** 현행 RN 앱에 적용되는 결정이다.

**날짜**: 2026-08-07
**상태**: 구현 완료 (앱 쪽 링크 연결까지 2026-08-08 완료 — 아래 "후속 처리")
**관련**: [[ADR-090]](안내 사이트가 생긴 이유) · [[ADR-007]](개인 키로 기기에서 직접 호출) · [[ADR-003]](백엔드 없음) · [[ADR-038]](대용량 원본 에셋 제외 기준)

## 맥락

이 앱은 회원가입이 없다. 사용자가 **자기 넥슨 오픈 API 키를 직접 발급받아** 넣어야 첫 화면을
넘어간다([[ADR-003]], [[ADR-007]]). 그런데 그 발급 절차 전체가 **앱 밖에**, 그것도 7단계로 있다 —
로그인 → 마이 페이지 → 애플리케이션 등록 → 약관·게임·단계 선택 → 서비스 정보 입력 → 목록에서
열기 → 키 복사.

앱이 지금 주는 안내는 `ApiKeyForm.tsx` 의 링크 한 줄(`openapi.nexon.com`)뿐이다. 사용자를 넥슨
첫 화면에 떨궈 놓고 끝나므로, **온보딩의 첫 관문이 가장 안내가 얇은 지점**이 된다.

## 결정

### 1. 가이드는 안내 사이트에 둔다 — 앱 번들이 아니라

`site/api-key.md` → `mapleroutine.store/api-key`. 앱 안에 화면을 만들지 않는다.

- **스크린샷 7장(약 1.2MB)이 앱 번들에 들어가면 모든 사용자가 받는다.** 실제로 보는 건 최초 1회다.
  OTA 번들이 그만큼 무거워지는 대가가 쓰임에 비해 크다.
- **넥슨이 화면을 바꾸면 가이드도 바뀐다.** 사이트는 `main` push → Actions 로 즉시 반영되지만,
  앱은 OTA 배포를 한 번 더 돌려야 한다. 갱신 주기가 우리 통제 밖인 문서일수록 웹이 맞다.
- 사용자는 키를 발급받는 동안 **어차피 브라우저에 있다.**

### 2. 스크린샷은 저장소에 커밋한다 — [[ADR-038]] 의 반대쪽 사례다

[[ADR-038]] 은 드롭 이펙트 원본(29MB)과 스토어 스크린샷(26MB)을 저장소에서 뺐다. 그 기준은
크기 자체가 아니라 **다시 만들 수 있는가**였다(앱에서 다시 찍으면 나온다).

이 7장은 **다시 만들 수 없다** — 사용자 개인 넥슨 계정으로 들어가야 나오는 화면이고, 그 위에
손으로 빨간 주석("클릭!", "스크롤 끝까지!")을 얹은 결과물이다. 게다가 합쳐서 1.2MB다. 원본을
잃으면 가이드가 통째로 죽으므로 커밋한다(`site/images/api-key/`).

### 3. "서비스 단계"로 안내한다

`foundation/nexon-api.md` 가 이미 **개발 단계 초당 5건·하루 1,000건 / 서비스 단계 초당 500건**을
기록해 두었고, "이 앱은 사용자가 이미 승인받은 서비스 단계 키를 쓰므로 개발 단계 상한 검증은
불필요"가 **문서화된 전제**다(2026-07-09). 가이드가 개발 단계를 허용하면 그 전제가 깨진다 —
여러 캐릭터를 병렬로 동기화하는 구조([[ADR-008]] 정정)에서 초당 5건은 바로 걸린다.

### 4. 정적 자산 복사를 재귀 복사로 바꾼다

`build-site.mjs` 의 복사 루프는 `readFile`/`writeFile` 이라 **디렉터리를 만나면 EISDIR 로 죽는다.**
`cp(src, dest, { recursive: true })` 한 줄로 바꾼다 — 파일도 디렉터리도 같은 호출로 처리되므로
"`.md` 와 `template.html` 만 소스로 제외하고 나머지는 그대로 나간다"는 기존 규칙이 그대로 유지된다.
이미지를 `site/` 루트에 흩뿌리지 않아도 되는 것이 이 변경의 전부다.

## 후속 처리 (2026-08-08, 이슈 #61 — 완료)

**`ApiKeyForm.tsx` 의 링크 연결.** 전제였던 "페이지가 실제로 서빙되는가"를 확인한 뒤(`/api-key`
200, 7단계 + FAQ) 앱 첫 화면을 이 페이지에 연결했다. **교체가 아니라 둘 다 둔다**(사용자 확정):

- 1차 경로 = `API 키 발급 방법` → `mapleroutine.store/api-key`. 처음 쓰는 사용자를 넥슨 첫 화면에
  떨궈 놓지 않기 위한 것이 이 ADR의 목적이므로 여기가 첫 줄이다.
- 보조 = `openapi.nexon.com` 바로 가기. 이미 키를 발급받은 사용자에게 7단계 안내를 경유시키지
  않는다. 가이드 1단계가 같은 링크를 품고 있지만 **중복이 아니라 서로 다른 두 진입점**이다.
- **설정 화면에는 두지 않는다**(사용자 확정) — 설정에 API 키 재입력 경로 자체가 없어서(계정
  변경·연결 해제뿐) 가이드 링크만 놓으면 갈 곳 없는 안내가 된다. 키 교체 경로는 별도 과제다.

## 범위 밖 (후속)

- 가이드의 영어판. 사이트 전체가 한국어 단일이라 여기만 이중화하지 않는다.
