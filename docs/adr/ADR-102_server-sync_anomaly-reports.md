# ADR-102 예상하지 못한 상황을 서버 로그로 남긴다

> ⚪ 미구현
> 관련 소스: (구현할 때 정한다)

## 배경

강화 내역을 원본 대신 합계로 저장하면([[ADR-100]]), 응답 원본이 기기에 남지 않는다. 그래서 받은 줄을 합계에서 빼거나 판정하지
못한 일이 생겨도 나중에 원인을 볼 길이 없다(#614 를 구현하며 사용자 지정 2026-10-26). 실기기에는 강화 내역 30,793 줄 가운데
5,029 줄이 장비 표에 없는 장비였다.

## 결정

### 결정 1. 앱이 이 상황을 만나면 서버에 알리고, 서버가 로그로 남긴다

| 상황 | 언제 생기나 | 남길 것 |
|---|---|---|
| 이벤트 월드를 판정하지 못함 | 캐릭터 목록 요청이 실패한 회차의 큐브 · 잠재 · 소울 줄([[ADR-100]] 결정 5) | 날짜 · 종류 · 줄 수 · 목록 요청의 실패 이유 |
| 비용을 못 매겨 합계에서 뺌 | 장비 표에 없는 장비의 스타포스, 재설정 전 등급을 모르는 잠재 · 소울, 비용 표에 없는 단계 등([[ADR-100]] 결정 1) | 날짜 · 종류 · 장비 이름 · 뺀 이유 · 줄 수 |

목적은 예상하지 못한 상황이 얼마나 · 어떤 모양으로 생기는지 운영자가 보는 것이다. 통계에 쓰지 않는다.

## 열린 질문

- 앱이 보내는 방법(전용 경로 · 묶음 여부)과 서버가 남기는 곳(로그 줄 · 표)
- 캐릭터 이름을 함께 남길지. 처리방침([[ADR-099]] 결정 9)에 적을 항목이 달라진다

## 테스트

구현할 때 적는다.

## 번호 기록

- ADR-102 (2026-10-26): 강화 합계에서 빼거나 판정하지 못한 줄을 서버 로그로 남기는 결정을 처음 작성했다
