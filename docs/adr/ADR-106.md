# ADR-106: 테마 배경 이미지를 둘 다 뗀다 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-108]]·[[ADR-109]] 가 새 배경으로 되돌렸다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.

## 무엇을 결정했었나 (요약)

테마 배경 그림을 새로 정하기로 하고 혼테일·검은마법사 **둘 다 뗐다**(배경을 가진 테마가 2개 → 0개). 기계장치(`--theme-bg-*` 방출·백드롭 렌더 분기)는 남기고, 테스트는 «배경 있는 테마»를 데이터에서 고르지 않고 픽스처로 만들게 바꿨다. 새 배경은 [[ADR-108]]·[[ADR-109]] 가 넣었다.
