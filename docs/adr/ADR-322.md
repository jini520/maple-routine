# ADR-322: 애니메이션 값이 React 에 넘어가기 전에 지워진다. reanimated 를 4.5.5 로 올린다

> 🟢 유효 · **구현 완료** 2026-09-28(`package.json`) · 실기기 미검증 · 이슈 #394 · #409

**관련**: [[ADR-250]] 정정 1(세그먼트 상자가 사라졌던 다른 원인) · [[ADR-213]](캐릭터 관리를 격자 하나로 합친 결정) · [[ADR-207]](끌기를 `react-native-sortables` 에 넘긴 결정) · [[ADR-279]] 결정 4(스토어 버전과 OTA 버전을 따로 올린다)

## 맥락

증상 둘이 따로 열려 있었다.

- **#394**: 안드로이드에서 세그먼트의 선택 배경이 사라진다.
- **#409**: 캐릭터 관리 격자가 가끔 깨진다. 구분자가 맨 위로 올라가고 후보가 사라진다.

**원인이 하나다.** 설치된 `react-native-reanimated` 4.5.1 이 애니메이션된 값을 React 에 넘기기
전에 지운다. 값을 잃은 뷰는 다음 React 커밋에서 정적 스타일만 남는다.

### 사슬 (라이브러리 소스로 확인했다. 버전 4.5.1)

1. **`useAnimatedStyle` 이 낸 스타일은 React 렌더에서 빠진다.** `filterOutAnimatedStyles` 가
   `viewDescriptors` 를 든 항목을 `style` 배열에서 걸러낸다
   (`createAnimatedComponent/AnimatedComponent.tsx:555`). React 가 커밋하는 스타일은
   `[정적 스타일, state.settledProps]` 둘뿐이다(`:543`). UI 스레드가 네이티브 뷰에 직접 쓴 값은
   React 가 모른다.
2. **그 값은 `settledProps` 로 되돌려 줘야 산다.** 500ms JS 인터벌이 네이티브에서 멈춘 값을 받아
   컴포넌트 state 에 넣는다(`PropsRegistryGarbageCollector.ts:11`·`:42`). 이 동작을 켜는
   `FORCE_REACT_RENDER_FOR_SETTLED_ANIMATIONS` 는 기본값이 참이다(`featureFlags/staticFlags.json:11`).
3. **4.5.1 은 넘기기 전에 먼저 지운다.** `getSettledUpdates` 가 `(현재-1초, 현재-2초)` 로 부르고
   (`ReanimatedModuleProxy.cpp:660`), `getUpdatesOlderThanTimestamp` 는 첫 줄에서
   `removeUpdatesOlderThanTimestamp(cleanupTimestamp)` 를 돌린 뒤 수집한다
   (`AnimatedPropsRegistry.cpp:49`). 값이 멈춘 뒤 1초에서 2초 사이에 인터벌이 한 번도 안 돌면 그
   값은 React 에 한 번도 못 가고 사라진다. 라이브러리가 그 자리에 자기 버그를 적어 뒀다:
   `// TODO: fix bug when threshold difference is smaller than 1 second`(`ReanimatedModuleProxy.cpp:657`).
   JS 스레드가 막히거나 앱이 잠깐 멈추면 그 구간이 열린다.
4. **다음 React 커밋이 뷰를 정적 스타일만으로 되돌린다.**
5. **한 번 되돌아가면 안 풀린다.** UI 스레드가 든 값은 여전히 맞아서 다시 쓰지 않는다.
   `useSlidingThumb` 은 `useAnimatedStyle(…, [placement, reduceMotion])` 이라 `placement` 가 안
   바뀌면 워크렛이 아예 안 돈다.

### 되돌아갈 자리가 달라서 증상이 둘로 보였다

| 이슈 | 정적 스타일에 없는 것 | 보이는 것 |
|---|---|---|
| #394 세그먼트 상자 | `width`·`opacity`·`transform`(`TabSegment.tsx:60` · `Segment.tsx:67`) | 폭이 0 이 되어 **사라진다** |
| #409 격자 칸 | 절대 좌표. 마운트 시점에 따라 `position: relative` 또는 화면 밖 숨김 좌표(`react-native-sortables` 의 `useItemLayout.ts`) | 구분자가 **맨 위로 올라가고** 후보가 **사라진다** |

#394 에 함께 적힌 둘째 증상(`엉뚱한 조각에 남는다`)도 같은 고리의 다른 얼굴이다. `settledProps`
에 옛 자리가 이미 들어 있고 새 자리가 못 넘어간 채 지워지면 옛 자리로 되돌아간다.

**두 이슈를 잇는 관찰이 하나 더 있다.** #394 의 열린 질문에 `iOS 때는 캐릭터 관리를 다녀오면 잘
났다` 가 적혀 있다. 캐릭터 관리는 #409 의 격자가 있는 화면이고, 칸 예순 개가 한꺼번에
`withTiming` 으로 움직이며 로스터 조회가 같이 도는 자리다. JS 스레드가 가장 잘 막힌다.

### 업스트림

- **MatiPl01/react-native-sortables#592**: 같은 증상. 메인테이너가 원인을 reanimated 4.5.0~4.5.2
  의 settled props 정리 버그로 진단했고, 제보자가 4.5.3 에서 재발 없음을 확인해 닫혔다(2026-08-28).
- **software-mansion/react-native-reanimated#9987**: `Prevent animated views from reverting to
  stale values after app pause or re-animation`. 4.5.3 에 들어갔다.

## 결정

### 결정 1. `react-native-reanimated` 를 4.5.5 로 올린다

사슬의 3번 고리를 끊는다. 4.5.3 이 `AnimatedPropsRegistry` 를 다시 썼다.

- `getUpdatesOlderThanTimestamp(timestamp, cleanupTimestamp)` 가
  `collectSettledUpdates(settledTimestamp)` 가 됐다. **시간으로 지우지 않고 React 가 값을 받았는가
  (`syncedTags_`)로** 지운다. React 가 받은 뒤에만 레지스트리 항목을 버린다.
- 재애니메이션으로 낡은 값은 `invalidatedTags_` 가 다음 틱에 다시 넘긴다. #394 의 `엉뚱한 자리`
  증상이 여기에 걸린다.
- 그 `TODO: fix bug` 주석도 없어졌다.

**4.5.5 를 고르는 이유는 4.5.3 보다 나은 것이 있어서가 아니다.** 두 버전의
`AnimatedPropsRegistry.cpp` 는 바이트 단위로 같고, `src/`·`Common/` 전체에서 다른 파일은
버전 문자열(`platform-specific/jsVersion.ts`) 하나다. 같은 수정을 받으면서 그 줄의 최신을 받는다.

회귀 범위가 작은 것도 확인했다. 4.5.1 에서 4.5.5 까지 `src/` 5파일 · `Common/` 9파일만 다르다.
peer 범위 `react-native 0.83 - 0.86` · `react-native-worklets 0.10.x - 0.11.x` 안에 지금 조합
(0.86.2 · 0.10.3)이 든다.

### 결정 2. Expo 고정값을 벗어나는 것을 `expo.install.exclude` 에 적는다

`expo/bundledNativeModules.json` 이 reanimated 를 4.5.1 로 묶는다. 적어 두지 않으면 다음
세션이 `expo install --fix` 를 돌려 **버그 버전으로 되돌린다.**

`expo install --check` 는 이 저장소에서 이미 일곱 패키지를 벗어남으로 보고한다
(`expo-sharing`·`expo-splash-screen`·`expo-updates`·`react`·`react-native`·`jest-expo`·`react-dom`,
2026-09-28 측정). 그래서 경고를 지우는 것이 목적이 아니다. **되돌리면 결함이 되살아나는 것은
reanimated 하나뿐이라** 그것만 적는다.

### 결정 3. 완화책을 안 쓴다

격자에 `key` 를 줘 다시 마운트하는 우회(MatiPl01/react-native-sortables#565)나 `renderItem` 을
고정해 다시 그리기를 줄이는 것은 터지는 빈도만 줄인다. 값이 지워지는 고리는 그대로 남아,
JS 가 막히면 다시 난다.

같은 이유로 #394 에 적어 둔 값싼 탐침(안쪽 줄에 `collapsable={false}`)도 넣지 않는다.

### 결정 4. #394 의 나머지 가설 셋은 쫓지 않는다

`잰 자리가 0 으로 온다` · `뷰 재부착에서 애니메이션 스타일이 유실된다` · `부모가 접힌다` 셋은
이 사슬이 증상을 다 설명하므로 순위가 내려갔다. **배제된 것은 아니다.** 올린 빌드의 실기기에서
상자가 여전히 사라지면 그때 다시 잰다.

[[ADR-250]] 정정 1 이 고친 것(`onItemLayout` 이 닫아 둔 `selectedIndex`)은 **별개의 실제 결함이고
그대로 유효하다.** 그 고침이 안 한 일은 이 고리를 끊는 것뿐이다.

## 대가

- **스토어 빌드에 묶인다.** 수정이 C++(`AnimatedPropsRegistry.cpp`·`ReanimatedModuleProxy.cpp`)
  이라 OTA 로 못 보낸다. 지문도 바뀐다.

  | 플랫폼 | 올리기 전 | 올린 뒤 |
  |---|---|---|
  | iOS | `87be37912a890135efdbd747c78584c151753b4f` | `34201e5fb185a0d890dc46199d3825eba4bb5486` |
  | Android | `19d059d4c336ef388f98fed5b0b7d4c559642647` | `d950f7a1d762e47766204512ef18c83bf254648f` |

  **iOS 값은 `pod install` 을 돌린 뒤에 재야 한다.** `ios` 디렉터리 전체가 하나의 재료로
  해시되므로(`bareNativeDir`) `Podfile.lock` 이 `RNReanimated 4.5.5` 로 바뀌면 지문이 또
  움직인다. `package.json` 만 고친 상태에서 잰 값은 `7b68da32…` 였고 그것은 빌드할 트리의
  지문이 아니다. Android 는 `Podfile.lock` 을 안 읽어 두 시점 값이 같다.

- **회귀 범위가 앱 전역이다.** reanimated 는 `useAnimatedStyle` 11파일 ·
  `createAnimatedComponent` 9파일(테스트 둘 제외)에서 돈다. today 헤더 초상화 · 가계부 · 스피너
  둘 · 드롭 가격 FAB · 바텀 시트 · 입력 카드 · 스피드 다이얼 · 공지 레일 · 스켈레톤이 그 안이다.
- **jest 로는 못 닫는다.** 값이 지워지는 것은 네이티브 타이밍이라 실기기에서 눈으로 봐야 끝난다.
- **결정적 재현을 안 세웠다**(사용자 결정, 2026-09-28). #409 에 적어 둔 절차(해제 콜백 끝에 동기
  루프 2.5초를 넣어 JS 를 막고 격자를 다시 그리기)를 밟지 않았다. 그래서 `올렸더니 안 나네` 와
  `올려서 고쳐졌다` 를 숫자로 가를 수 없다. 원인은 소스로 확인했고 증상 재현은 실기기 관찰에 맡긴다.

## 검증

- `npx tsc --noEmit` · `npx eslint src` · `npx jest src/hooks src/components src/app`
- 지문 변화를 `npx expo-updates runtimeversion:resolve` 로 확인(위 표).
- 네이티브가 실제로 컴파일된다. iOS 시뮬레이터 빌드 성공(`libRNReanimated.a` 재생성) · Android
  Release APK 성공(`lib/*/libreanimated.so` 4종). 시뮬레이터에서 앱이 뜨고 `남은 스케줄` 세그먼트
  상자가 제자리에 선다. **캐릭터 관리 격자도 제자리다** - 구분자(계정 드롭다운)가 다섯째 행 아래
  서고 후보 셋이 보인다. 증상이 간헐적이라 고쳐졌다는 증거는 아니고, 4.5.5 가 격자를 깨뜨리지
  않는다는 확인이다.
- **실기기에 올리면 잠금 모달에 막힌다.** 지문을 바꿨으니 `/latest` 의
  `acceptedRuntimeVersions` 에 자기 지문이 없다. 푸는 법은 `features/live-update.md` 의
  「지문을 바꾼 검증 빌드는 자기가 잠긴다」에 적었다.
- **남은 것**: 실기기(iOS · Android)에서 셋을 본다. ① 세그먼트 상자가 캐릭터 관리를 다녀온 뒤에도
  선다 ② 캐릭터 관리에서 추가·해제·순서 바꾸기와 앱 전환 뒤 복귀에 격자가 안 깨진다 ③ 위 대가에
  적은 애니메이션 아홉 자리가 그대로 돈다.
