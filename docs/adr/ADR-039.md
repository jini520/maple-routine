# ADR-039: 바텀시트 자체구현 → vaul(Drawer) (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** RN 은 `@gorhom/bottom-sheet` 를 쓴다 — vaul 은 웹 라이브러리다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 2(공개 API·스킨 불변) · 3(부모 조건부 마운트 + 내부 지연 언마운트) — `components/organisms/BottomSheet` 가 라이브러리만 갈아끼운 채 같은 계약을 지킨다. 단 **스킨의 `border-t border-border` 는 [[ADR-179]] 결정 4 가 걷었다** — 다크에서 시트 몸통이 한 칸 위 표면으로 서면서 면이 경계를 만들기 때문이다.

## 무엇을 결정했었나 (요약)

자체 `createPortal` 바텀시트를 **vaul(Drawer)** 로 교체했다(자체 구현은 마우스 드래그 닫기·스냅 복귀·fling 이 없었다). 공개 API 와 시각 스킨은 그대로 두어 사용처를 안 고쳤고, 닫힘 애니메이션을 살리려 내부 `open` 상태로 언마운트를 지연했다.
