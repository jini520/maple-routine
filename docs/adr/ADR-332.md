## 맥락

파티 약속의 ＋ 가 한 번 약속 · 반복 약속 두 갈래를 고르게 되면서(ADR-331 정정 14) 펼치는 ＋ 가 두 화면에 선다.
가계부의 펼침판(`SpeedDial`)은 수입 · 지출 두 갈래에 박혀 있었다(프롭 `onSelectIncome` · `onSelectExpense`, 색 `rise-ink` · `fall-ink`).
사용자는 이 부품을 **앱 전체의 표준**으로 정하고 모양과 움직임을 다시 고르기로 했다.

시안은 여섯 모양(원 + 칩 · 알약 · 메뉴 카드 · 부채꼴 · 가로 알약 · 바닥 선반)에서 알약 · 메뉴 카드 · 부채꼴을 세 갈래씩 발전시켰고,
알약에 설명을 붙인 X2-가를 두 단계로 펼치는 안으로 다듬어 **X2-가2 · 위부터 계단**을 채택했다.

## 결정

### 결정 1. 펼치는 ＋ 는 부품 하나다. 갈래 목록을 받는다

`components/organisms/SpeedDial` 이 갈래를 프롭 목록으로 받는다. 갈래 하나는 이름 · 선택 설명 · 아이콘 · 접근성 이름 · 고르면 부를 함수다.
목록은 **위에서 아래 순서**이고 마지막이 ＋ 에 가장 가깝다. ＋ 의 접근성 이름(`기록 추가` · `약속 추가`)도 프롭이다.
가계부와 파티 약속이 이것을 쓰고, 앞으로 ＋ 에서 갈래를 고르는 화면도 이것을 쓴다. 갈래마다 모양을 달리하는 프롭은 두지 않는다.
화면마다 모양이 갈리면 표준이 아니기 때문이다.

### 결정 2. 모양: 같은 폭 알약, 아이콘은 왼쪽 옅은 주황 원

- 갈래 하나가 **알약 하나**다. 높이는 ＋ 지름(56)과 같고 바탕은 `surface`, 테두리 · 그림자는 없다. 스크림 위의 흰 면이라 떠 있음은 스크림이 만든다.
- 알약 왼쪽 안에 **옅은 주황 원**(지름 42, `primary-tint` 바탕 · `primary-ink` 아이콘)이 서고, 그 오른쪽에 이름(14 굵게)과 설명(11 흐리게, 있을 때만) 두 줄이다.
- **알약 폭은 모두 같고, 가장 긴 이름 · 설명에 맞춘다.** 왼쪽 원 자리 60 + 가장 긴 글자 폭 + 오른쪽 여백 16 이다.
  넉넉한 고정 폭을 두지 않는다(사용자 지시: "불필요하게 길게는 하지마. 가장 긴 것에 맞춰"). 문구가 짧아지면 알약도 짧아진다.
- 알약의 **오른쪽 끝은 ＋ 와 맞춘다.** 알약 사이와 맨 아래 알약과 ＋ 사이는 12 다.
- 갈래 색은 화면과 상관없이 **주황 하나**다. 가계부의 수입 빨강 · 지출 파랑 원은 걷는다(사용자 결정). 갈래는 아이콘 모양과 이름이 가른다.
- 펼치면 ＋ 는 45° 돌아 `×` 가 되고 주황 채움은 그대로다. 접근성 이름은 `닫기` 다.

### 결정 3. 움직임: 원이 먼저 솟고, 위 알약부터 펼쳐진다

＋ 를 누르면 두 단계다.

1. **아이콘 원만 솟는다.** 각 갈래가 원 크기(56)로 ＋ 자리에서 0.5 배로 출발해 제자리까지 올라온다. ＋ 에 가까운 것부터 40ms 계단이다.
   그래서 첫 순간에는 ＋ 위에 원이 세로로 한 줄 선다.
2. **맨 위 원부터 알약으로 펼쳐진다.** 원이 다 선 뒤 맨 위부터 50ms 계단으로 폭이 왼쪽으로 늘어나고, 아이콘은 알약 왼쪽 끝을 따라간다.
   이름 · 설명은 그 알약이 펼치기 시작한 뒤 120ms 에 나타난다. 솟는 방향(아래 → 위)과 펼치는 방향(위 → 아래)이 엇갈려 한 흐름으로 읽힌다.

| | 무엇이 | 시작 | 길이 | 곡선 |
|---|---|---|---|---|
| 펴기 | 스크림 · ＋ 회전 | 0 | 180 · 300ms | 직선 · 살짝 넘치는 스프링 |
| | ① 원이 솟음(0.5 → 1 배) | ＋ 에 가까운 것부터 0 · 40ms … | 300ms | 살짝 넘치는 스프링 |
| | ② 원이 알약으로(56 → 공통 폭) | 맨 위부터 `220 + (n − 1) × 40` · +50ms … | 320ms | 감속 |
| | 이름 · 설명 | ② + 120ms | 180ms | 직선 |
| 접기 | 이름 · 설명 | 0 | 70ms | 직선 |
| | 알약이 원으로 | 30ms | 150ms | 가속 |
| | 원이 ＋ 로 들어감 | 먼 것부터 150 · 175ms … | 150ms | 가속 |
| | 스크림 · ＋ 회전 | 150ms | 150ms | 직선 · 가속 |

- 접기는 펴기의 거울이고 더 짧다(약 300ms). 닫기가 열기만큼 길면 답답하다(ADR-170 결정 8 의 태도).
- 갈래를 고르면 판을 접고 바로 고른 함수를 부른다. 시트가 접힘과 겹쳐 올라온다.
- **움직임 줄이기**에서는 솟음 · 늘어남 · 회전을 끄고, 펼친 알약을 지연 없이 페이드로만 보인다.
- 값은 `SpeedDial/speed-dial-motion.ts` 가 갈래 수와 차례의 함수로 낸다. 애니메이션을 띄우지 않고 계단의 방향을 테스트로 붙든다.

### 결정 4. 가계부는 모양과 원 색만 바뀐다

가계부의 두 갈래는 이름 `수입` · `지출`(설명 없음), 접근성 이름 `수입 추가` · `지출 추가`, 아이콘 `ProfitIcon` · `ShoppingCartIcon` 그대로다.
바뀌는 것은 결정 2 · 3 의 모양과 움직임, 원 색이 주황이 되는 것뿐이다.

## 대가

- 원 + 칩(ADR-170 결정 7)보다 흰 면이 넓어 펼친 동안 목록을 더 가린다. 대신 누르는 면이 글자까지 넓고 설명을 둘 자리가 있다.
- 폭이 글자에서 나오므로 첫 그리기에 글자 폭을 재야 한다. 재기 전에는 알약이 원 크기에 머문다.
- 가계부에서 수입 · 지출의 색 구분이 펼침판에서 사라진다. 캘린더 칸의 두 줄 색은 그대로다.

## 기각

- 원 + 이름 칩(지금 가계부, X1) · 가로로 늘어나는 알약(X5) · ＋ 가 바닥 선반으로(X6).
- 알약에서: ＋ 에서 꺼내는 알약(X2-나) · 세로 캡슐 + 바깥 이름(X2-다). 아이콘이 ＋ 줄에 남는 펼침(X2-가1).
- 메뉴 카드에서: 칸이 나뉜 카드(X3-가) · ＋ 가 첫 줄이 되는 카드(X3-나) · 꼬리 달린 팝오버(X3-다).
- 부채꼴에서: 고른 호 + 아래 이름(X4-가) · 사분원 판(X4-나) · 궤도를 도는 원(X4-다).
- 펼치는 순서: 아래부터 계단 · 한꺼번에.
- 넉넉한 고정 폭(236). 가장 긴 글자에 맞춘다(결정 2).
