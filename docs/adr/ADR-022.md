# ADR-022: Live Update(OTA) — Capgo + GitHub Releases (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-137]] 이 `expo-updates` 로 프로토콜을 바꿨다(GitHub Releases 자체 호스팅만 그대로).
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 6(OTA 를 `native/live-update.ts` 어댑터 한 장 뒤에 둔다) — `native/ports.ts`·`native/adapters/rn-live-update.ts` 가 그 배치를 그대로 따른다.

## 무엇을 결정했었나 (요약)

@capgo 플러그인을 **클라이언트로만** 쓰고(매니지드 백엔드 미사용) 번들 zip 은 GitHub Releases 고정 태그에 자체 호스팅한다. 부팅 시 `latest.json` 조회 → 체크섬 검증 → 다음 재시작에 적용. OTA 대상은 JS/HTML/CSS 뿐이고, 배포는 `publish-live-update.mjs` 한 스크립트가 빌드·압축·체크섬·업로드를 한다.
