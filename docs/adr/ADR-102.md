# ADR-102: 접기 전 사전 스크롤을 걷어낸다 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 웹 스크롤 워크어라운드를 걷어낸 정리 작업이다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(접기는 상태만 바꾸고 스크롤을 건드리지 않는다) — `CharacterAccordion` 이 지금도 그렇다.

## 무엇을 결정했었나 (요약)

접기 전에 스크롤을 미리 옮기던 워크어라운드([[ADR-085]] 결정 2)를 **걷어냈다** — 근본 처방이 들어온 뒤로는 두 단계가 두 프레임으로 그려져 접히기 직전에 페이지가 튀는 비용만 남았다. **접기는 상태만 바꾸고 스크롤을 건드리지 않는다.**
