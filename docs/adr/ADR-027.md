> ⛔ **DEPRECATED — 폐기.** [[ADR-137]] 이 «대체» 로 명시했다 — `CapacitorUpdater` API 배선은 전부 죽었다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(부팅은 체크만) · 4(적용은 사용자 동의로만) · 6(셀룰러 경고) · 7(스토어 전용 업데이트 구분 `minNativeVersion`) — `features/live-update/store.ts`·`UpdatePromptModal`·`AppUpdateSection` 이 지금도 이 UX 를 그린다.

## 무엇을 결정했었나 (요약)

OTA 를 **사용자 동의형**으로 재설계했다 — 부팅은 체크만, 새 버전이 있으면 모달(버전·용량)로 알리고, 다운로드는 큐잉이 아니라 번들만 받아 두고, 사용자가 누를 때 적용한다. 매니페스트에 `size`·`minNativeVersion` 을 더해 「스토어 업데이트 필요」를 구분하고, 셀룰러면 데이터 경고를 띄운다.
