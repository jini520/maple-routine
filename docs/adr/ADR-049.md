# ADR-049: 보스 수익 헤더 정렬·유격 CSS 4종 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** px 단위 CSS 기하라 RN 에 그대로 옮겨진 수치는 없다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(새로고침은 제목 줄이 아니라 탭 줄) · 2(고가 드롭 뱃지가 줄 높이를 밀지 않는다) · 3(펼침 셸이 모서리를 잘라낸다) — `BossProfitScreen`·`HeadlineChips`·`CharacterAccordion`·`valuable-card-glow.ts` 가 지금도 이 배치다.

## 무엇을 결정했었나 (요약)

보스 수익 헤더의 정렬·유격 네 가지를 px 단위로 잡았다 — 새로고침을 제목 줄에서 탭 줄로 옮기고(높이 30px), 고가 드롭 뱃지를 `absolute` 로 띄워 줄 높이를 밀지 않게 하고, 펼침 셸에 `overflow: clip` 을 걸어 모서리 클리핑을 되살리고, 보스 행 높이를 89px 로 고정했다.
