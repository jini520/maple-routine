# ADR-079: stuck sticky 헤더의 레이어 고정 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 실기기에서 무효로 판명됐다([[ADR-120]]).
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 현행 `ThemeBackdrop` 주석이 «배경은 한 장으로 깐다» 의 계보로만 인용한다 — 규칙이 아니라 기록이다.

## 무엇을 결정했었나 (요약)

기간 이동 깜빡임을 **stuck sticky 헤더 레이어의 재생성**으로 보고 `will-change: transform` 으로 레이어를 고정하려 했다. 실기기에서 무효였다 — 페인트가 아니라 레이아웃(스크롤 클램프) 문제였다.
