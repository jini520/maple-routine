# ADR-081: 아코디언 펼침을 기간별로 기억 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 같은 날 자체 폐기했다(짝인 [[ADR-082]] 가 iOS 에서 불가능).
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.

## 무엇을 결정했었나 (요약)

아코디언 펼침을 **기간별로 기억**하려 했다(#27의 무조건 리셋을 대체). 같은 날 접었다 — 짝이 되는 스크롤 복원([[ADR-082]])이 iOS 에서 불가능해, 펼침만 기억해도 «보던 곳으로 다시 스크롤해야 하는 건 똑같다»(사용자 판단).
