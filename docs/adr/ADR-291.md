# ADR-291: 챌린저스가 아닌 월드의 캐릭터는 보스 수익에 시즌 보스 행을 세우지도 기록하지도 않는다

> 🟢 유효 · 2026-09-17 · **구현 완료**(2026-09-17) · 실기기 미검증 · 사용자 지정(2026-09-17) · **정정 1 구현 완료**(2026-09-17)

**관련**: [[ADR-274]](리프한 기간의 같은 처치) · [[ADR-280]](월드 표의 `challengers` 칸)
**문서**: `features/boss-profit.md` · `foundation/nexon-api.md`

## 맥락

챌린저스에서 일반 월드로 리프한 캐릭터의 보스 수익에 시즌 보스 메이린이 보인다는 제보가 들어왔다.

원인은 **리프 전 스케줄러 등록이 새 ocid 로 그대로 넘어오는 것**이다(넥슨 API 실측 2026-09-17).
챌린저스2 에서 엘리시움으로 리프한 캐릭터를 날짜별로 조회했다.

| 날짜 | 월드 | 메이린 하드 `registration_flag` | 다른 등록 |
|---|---|---|---|
| 09-11 (리프 뒤 첫 조회 가능일) | 엘리시움 | `true` | 데미안 하드 · 가디언 엔젤 슬라임 카오스 등 챌린저스 때 목록 그대로 |
| 09-12 ~ 09-16 | 엘리시움 | `false` | 데미안 · 가디언 엔젤 슬라임이 빠지고 스우 익스트림 · 찬란한 흉성 노멀이 들어왔다 |

월드는 이미 일반 월드인데 메이린이 등록된 채로 온다. 09-12 에 false 가 된 것은 다른 등록이 바뀐 날과
같아, 게임 안에서 등록을 다시 하면서 빠진 것으로 본다. 다시 하지 않으면 true 가 남을 수 있다.

보스 수익 자동 모드는 등록된 미완료 보스를 미완료 행으로 세운다(`selectBossProfitBosses`). 행 고르기
(`selectProfitDisplayBosses`)와 창 기록(`recordPeriod`)은 월드를 안 봤다. 그래서 새 캐릭터 카드에
메이린 미완료 행이 섰다. ~~스케줄러 화면은 `isChallengersWorld` 로 시즌 보스를 가려 거기서는 안 보였다.~~
틀렸다. 그 판정은 헤더의 시즌 배지에만 걸려 있었다(정정 1).

넥슨 API 는 등록하지 않은 일반 월드 캐릭터에게도 메이린을 `registration_flag: false` 로 목록에 넣어 준다
(09-12 실기기 백업의 엘리시움 캐릭터 여러 명). 메이린 완료는 한 달 전부터 API 가 처리하지 않는다(사용자
확인).

사용자는 저장된 기록은 그대로 두고, 앞으로 나올 시즌 보스까지 일반 월드 캐릭터에는 어떤 경우에도 행이
서지 않게 하라고 했다. 챌린저스 서버가 열릴 때마다 시즌 보스가 새로 나올 가능성이 높다.

## 결정

### 결정 1. 행을 고를 때 시즌 보스는 챌린저스 월드 캐릭터에만 남긴다

`selectProfitDisplayBosses` 가 캐릭터의 월드 key 를 받는다. 시즌 보스(`isSeasonBoss`)이면서 그 월드가
챌린저스(`isChallengersWorld`)가 아니면 처치 행도 미완료 행도 안 세운다. 자동 · 수동 두 모드가 같다.

- **보스 이름이 아니라 시즌 보스 분류로 거른다.** `weekly-bosses.json` 의 `eventWeekly` 에 새 시즌 보스를
  더하면 코드를 안 고쳐도 같은 규칙을 따른다.
- **월드를 모르면 안 세운다.** 스케줄러 화면의 판정(`features/boss-scheduler.md`)과 같다.
- 자동 기록(`autoRecordRows`)은 이 행에서만 쓰므로 함께 막힌다.

### 결정 2. 창 기록도 같은 조건으로 건너뛴다

`recordPeriod` 는 조회 원장의 완료 보스를 그 캐릭터의 캐시 월드와 함께 기록한다. 시즌 보스이면서 그
월드가 챌린저스가 아니면 기록하지 않는다. 월드를 모르면 이번 회차에 건너뛰고, 월드를 알게 된 뒤의
회차가 챌린저스 캐릭터의 처치를 기록한다(이미 있는 행 판정이 막지 않는다).

### 결정 3. 저장된 기록은 안 건드린다 (사용자 지정)

이관이 없다. 미완료 행은 기록되지 않으므로 이 원인으로 생긴 기록도 없다.

## 대가

- **월드를 모르는 챌린저스 캐릭터는 그동안 시즌 보스가 안 보인다.** 캐시에 월드가 들어오면 돌아온다.

## 기각

- **일반 월드로 저장된 시즌 보스 기록을 이관으로 지운다.** 이 원인은 미완료 행이라 기록을 남기지 않고,
  사용자가 기록은 건드리지 않기로 했다.
- **메이린 key 로 거른다.** 다음 시즌 보스마다 코드를 고쳐야 한다.

## 정정 1. 보스 스케줄러 목록 · today 남은 스케줄 · 수동 추적 시드도 같은 규칙을 따른다 (2026-09-17, 사용자 지정)

### 맥락

1.0.10(1) 을 받은 사용자에게서 메이린이 여전히 보인다는 제보가 들어왔다. 이 결정은 보스 수익만 막았다.

- **보스 스케줄러 화면과 today 의 남은 스케줄 위젯**은 `displayedBosses` 로 목록을 만든다. 자동 모드는
  `selectDisplayBosses` 가 등록된 보스를 월드와 상관없이 전부 세운다. `BossScreen` 의 `isChallengersWorld` 는
  `주간` 헤더의 시즌 완료 배지에만 걸려 있었다. 엘리시움 캐릭터에 메이린 하드 등록을 넣으면 목록에 메이린이
  나오는 것을 테스트로 재현했다.
- **수동 추적 시드**(`seedManualTrackedContent`)는 수동 모드로 바꾸거나 캐릭터를 더할 때 등록된 보스로
  멤버십을 채운다. 일반 월드 캐릭터에 메이린이 들어가면, 보스 관리 화면이 시즌 보스 줄을 숨겨 사용자가 뺄
  길이 없다.

사용자가 전부 고치라고 했다.

### 정정

#### 1. `displayedBosses` 가 챌린저스가 아닌 월드의 시즌 보스를 뺀다

자동 · 수동 두 모드 모두다. 월드를 모르면 뺀다. 보스 스케줄러 목록과 링, today 의 남은 스케줄이 이 함수
하나를 불러 함께 따른다.

#### 2. 수동 추적 시드가 챌린저스가 아닌 월드의 시즌 보스를 안 담는다

판정 월드는 그 동기화 결과의 `worldKey` 다. 이미 담긴 멤버십은 안 건드린다. `displayedBosses` 와 보스 수익이
보이지 않게 거른다.

### 대가

- **보스 관리 화면의 `registeredDifficultyByBoss` 는 그대로다.** 시즌 보스 줄 자체가 챌린저스 월드에서만 서므로
  일반 월드에서는 그 값이 쓰이는 자리가 없다.
