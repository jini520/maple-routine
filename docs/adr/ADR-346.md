# ADR-346: 프렌즈 조회를 서버가 모아 SSE 로 흘린다. 앱은 토큰을 안 든다

> ⛔ 폐기 · 2026-10-14 · [[ADR-347]] 이 흡수했다

**무엇을 결정했었나.** 앱이 작업 목록 하나를 보내고 서버가 필요한 페이지를 전부 돌아 결과를 SSE
이벤트로 흘리는 모양. [[ADR-320]] 결정 1·2(액세스 토큰을 앱에 넘긴다 · 프록시를 걷는다)를
뒤집었다. 1:1 중계가 아니라 모아 흘리는 것이라 우리 서버로 가는 요청이 124건이 아니라 1건이다.

용량을 전부 실측해 설계를 그 위에 올렸다 - 쪽 하나 870KB · 줄당 0.886KB · 56작업 0.3초 · 왕복
19~39ms · 동시 수가 창에 따라 40~84명 · 버스트는 푸시가 만들고 DAU 와 무관 · 집 업링크가
Oracle 의 1/27. 거기서 나온 것이 원본 줄을 그대로 내리는 것, 모아 두지 않고 흘리는 것, 역압을
지키는 것, 전역 상한과 미룸 알림, 회차를 끊는 것, Always Free 인스턴스 둘로 가르는 것,
`react-native-sse` 로 받는 것, nginx 에 그 경로의 자리를 따로 만드는 것이다.

**왜 폐기했나.** 서버 코드를 완전히 다시 쓰기로 했다(사용자 지정 2026-10-14). 이 문서의 결정은
대부분 코드 구조와 무관해 그대로 살지만, 로그인 설계([[ADR-345]])와 전제가 다른 시점에 쓰여 두
문서의 경계가 어긋났다. 하나로 합쳤다.

**결정과 실측 전부 [[ADR-347]] 로 옮겼다.** 전문은 git 히스토리에 있다.
