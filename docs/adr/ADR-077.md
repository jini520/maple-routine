# ADR-077: 드롭 히스토리를 중첩 라우트 + 오버레이로 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** RN 스택(`@react-navigation/native-stack`)이 중첩 라우트 + `fixed` 오버레이를 대체했다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — «하위 페이지로 가도 아래 화면을 언마운트하지 않는다» 는 계약 — `BossScreen`·`ContentScreen`·`features/boss-profit/store.ts` 가 스택 왕복에서 그대로 지킨다.

## 무엇을 결정했었나 (요약)

드롭 히스토리를 형제 라우트가 아니라 **`/profit` 의 중첩 라우트 + `fixed inset-0` 오버레이**로 얹었다. 형제였을 때는 이동마다 부모가 언마운트돼 아코디언 펼침·기간·스크롤을 전부 잃었고, 같은 언마운트가 iOS 에서 stuck sticky 헤더를 빈 화면으로 만들었다.
