# ADR-334: 넥슨 로그인은 스토어 1.0.12 에 꺼진 채로 싣고, 프로덕션 승인 뒤 OTA 로 켠다

> 🟢 유효 · 2026-10-04 · 사용자 결정 2026-10-04 · **구현 완료**(2026-10-04 · `features/auth/nexon-login-enabled.ts` · `SignInScreen` · `ApiKeyForm` · `SettingsScreen`)
>
> [[ADR-318]] 결정 5 와 [[ADR-321]] 결정 7 의 **내보내는 때**를 대체한다. 두 결정은 버튼과 로그인 화면을 다음 스토어 빌드에 묶어 켠 채로 내보낸다고 적었다.
> 넥슨 로그인 화면의 모양(ADR-321 결정 1~6 · 8)과 버튼 자리(ADR-318 결정 6)는 켜졌을 때 그대로다.

**관련**: [[ADR-296]] 결정 7(검수 통과 전에는 테스트 사용자만 로그인된다) · [[ADR-268]](심사 중 업데이트 잠금 목록) · [[ADR-279]](OTA 버전과 스토어 버전)
**문서**: `features/auth.md` · `foundation/release.md`

## 맥락

1.0.11 OTA 뒤 `main` 에는 넥슨 로그인 말고도 통계 탭 · 파티 스케줄 · 핑크빈 앱 아이콘이 쌓였다.
이 중 아이콘과 `expo-web-browser` · UIScene · keyboard-controller 는 지문을 바꿔 스토어 빌드로만 나간다.

넥슨 프렌즈 프로그램은 아직 프로덕션 단계 승인이 안 났다. 승인 전에는 등록된 테스트 사용자만 로그인된다.
버튼을 켠 채로 내보내면 나머지 사용자가 화면에서 제일 큰 버튼을 눌러 실패한다.
승인을 기다리며 스토어 빌드를 미루면 나머지 변경까지 묶여 못 나간다.

## 결정

### 결정 1. 켜고 끄는 것은 소스 상수 하나다

`src/features/auth/nexon-login-enabled.ts` 의 `NEXON_LOGIN_ENABLED` 가 `false` 다.
환경 변수(`EXPO_PUBLIC_*`)로 두지 않는다. OTA 번들을 굽는 셸에 따라 값이 조용히 달라질 수 있어서다.

### 결정 2. 꺼져 있으면 진입점 둘을 안 세운다

- 로그인 화면(`SignInScreen`)에서 넥슨 블록(소제목 · `게임 데이터 활용 로그인이란?` · 버튼)을 통째로 뺀다.
  머리 둘째 줄은 `API 키 입력이 필요해요.` 다. 로그인을 말하면 없는 수단을 찾게 된다.
- 더보기 탭(`SettingsScreen`) 맨 위 버튼을 안 세운다.

로그인이 이미 붙은 기기에서만 보이는 것(계정 · 데이터의 로그아웃 줄, 로그인 만료 모달)은 그대로 둔다.
꺼진 빌드에서는 로그인을 만들 길이 없어 일반 사용자에게는 안 보인다.

### 결정 3. 꺼져 있으면 키 블록은 펼친 채로 선다 (사용자 결정)

ADR-321 결정 8 이 키 블록을 접은 이유는 위에 넥슨이라는 주 경로가 있어서다.
넥슨이 빠지면 키가 유일한 경로라, 접어 두면 사용자가 한 번 더 눌러야 입력칸이 나온다.
그래서 `ApiKeyForm` 의 `collapsible` 이 `false` 면 머리는 누를 수 없는 제목이고 셰브론이 없으며 입력칸이 늘 보인다.
상수를 켜면 접힌 아코디언으로 돌아간다.

### 결정 4. 켜는 데 필요한 네이티브는 바이너리에 남긴다

나중에 켜는 것은 상수 한 줄을 `true` 로 바꾸는 **OTA** 다(1.0.12+1 또는 1.0.13).
OTA 는 같은 지문의 바이너리에만 가므로 아래를 1.0.12 바이너리에서 빼지 않는다.

- `ios/app/Info.plist` 의 `CFBundleURLSchemes`(`com.mapleroutine.app`)
- `android/app/src/main/AndroidManifest.xml` 의 같은 스킴 `intent-filter`
- `expo-web-browser`(`openAuthSessionAsync`)
- `SceneDelegate` 가 콜백 URL 을 `RCTLinkingManager` 로 넘기는 배선

흐름 코드(`features/auth/nexon-login.ts` · `server/nexon-auth.ts` · `NexonLoginButton`)도 번들에 그대로 둔다.

### 결정 5. 스토어 문구는 로그인을 말하지 않는다

1.0.12 의 설명 · 심사 메모는 1.0.8 처럼 `회원가입 없음 · API 키 필요` 다. 켜는 OTA 를 낼 때 이 문구를 함께 고친다.
켜진 뒤에는 로그인이 생기므로 계정 삭제 요건(App Store 5.1.1(v))도 그때 다시 본다.

## 대가

- 켜기 전까지 로그인 코드가 쓰이지 않은 채 번들에 실린다.
- 켜는 OTA 는 1.0.12 바이너리에만 간다. 그때까지 1.0.8 에 남은 기기는 스토어 업데이트로 먼저 넘어와야 한다.
