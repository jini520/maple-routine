# ADR-051: 메이플 ID 계정 선택 화면 경유 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-143]] 이 계정 선택 단계를 없앴다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.

## 무엇을 결정했었나 (요약)

계정 수와 무관하게 **항상 계정 선택 화면을 거친다**(1개여도 자동 확정하지 않는다). 저장은 사용자가 「계속하기」를 누르는 경로 하나로 일원화하고, 계정이 하나면 그 항목을 초기 하이라이트로 둔다.
