# ADR-122: 스크림 위 패널 테두리는 모드마다 반대 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** `data-mode` 선택자로 가르는 **방법**이 죽었다 — RN 에는 CSS 선택자가 없다.
> 결정 8 폐기 사실은 [[ADR-064]] 쪽에 남는다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — **모드마다 테두리 역할이 반대**라는 사실과, 그때 실기기에서 잡은 **값**(`in srgb` 합성 포함). 방법만 갈렸다 — `theme/theme-vars.ts` 가 선택자 대신 **값으로 풀어** 내리고, `organisms/Modal`·`PartySizeModal`·`AccountSelect`·`CharacterTrackingPicker` 가 그 값을 쓴다.

## 무엇을 결정했었나 (요약)

스크림 위 패널의 테두리가 **모드마다 역할이 반대**라(라이트에서만 배경색에 녹인다) 토큰만으로 못 풀고, 모드를 `data-mode` 로 CSS 에 노출해 선택자로 갈랐다. 테마 **이름**으로 분기하는 것은 금지([[ADR-064]] 결정 8 이 없앤 수동 목록이 되살아난다).
