# ADR-122: 스크림 위 패널 테두리는 모드마다 반대 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** CSS `data-mode` 전용 결정이라 RN 에 대응물이 없다. 결정 8 폐기 사실은 [[ADR-064]] 쪽에 남는다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.

## 무엇을 결정했었나 (요약)

스크림 위 패널의 테두리가 **모드마다 역할이 반대**라(라이트에서만 배경색에 녹인다) 토큰만으로 못 풀고, 모드를 `data-mode` 로 CSS 에 노출해 선택자로 갈랐다. 테마 **이름**으로 분기하는 것은 금지([[ADR-064]] 결정 8 이 없앤 수동 목록이 되살아난다).
