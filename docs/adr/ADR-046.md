### ADR-046: 보스 수익 — 총 수익 요약을 카드에서 "노-카드 헤드라인"으로 재설계(기간 전체 고가 드롭 뱃지 포함) (구현 완료, 2026-07-28)

> 🟡 **PARTIALLY SUPERSEDED — 일부 폐기.** 결정 5는 [[ADR-054]] 가 부분 폐기했다.
> 나머지 결정은 유효하다 — 인용 전 본문에서 해당 결정 번호를 확인할 것.

> 문서 순서: 이 결정도 [[ADR-045]]와 마찬가지로 브라우저 프리뷰(`/debug/boss-profit-total-card`)로 시안을 반복 조정해 확정했다. 다만 **실제 화면(`BossProfitScreen`) 구현에는 착수하기 전에** 이 문서를 먼저 작성했다(docs-first) — 프리뷰는 시안 탐색용 임시 라우트이고, 확정안 반영이 본 구현이다.

**배경**: 보스 수익 화면 상단의 "M월 N주차 총 수익"/"이번 달 총 수익" 요약 블록이 **아래 캐릭터 카드와 디자인이 겹쳐 단조롭다**는 사용자 요청. 원인은 명확했다 — 요약 카드(`rounded-[14px] bg-surface border border-border p-6 text-center`)와 접힘 캐릭터 카드([[ADR-023]] `rounded-[14px] bg-surface border border-border p-4`)가 **같은 카드 셸**이라, 화면 전체가 "동일한 흰 카드의 반복"으로 읽히고 요약이 목록 항목 하나처럼 묻혔다. 주간/월간은 같은 블록이 라벨만 바꿔 쓰는 구조라 한 곳만 고치면 둘 다 해결된다.

**결정**:
1. **요약은 카드가 아니라 헤드라인**: 총 수익 블록에서 카드 셸(배경·테두리·그림자·패딩)을 걷어내고 페이지 배경 위에 얹은 타이포 헤드라인으로 바꾼다. 아래 목록이 전부 카드이므로 요약이 **카드가 아니게** 되는 순간 "같은 셸의 반복" 문제가 원인째 사라진다(색만 바꾼 틴트 카드는 여전히 카드-대-카드 경쟁).
2. **구성 — 2행 + 헤어라인**:
   - 라벨행: `flex items-center justify-between gap-2` — 라벨 `text-xs font-semibold tracking-wide text-text-muted`("{기간} 총 수익") + **우측에 기간 전체 고가 드롭 뱃지**(있을 때만).
   - 금액행: `mt-1.5 flex items-center gap-2.5` — 코인 엠블럼(`h-8 w-8 rounded-full bg-primary/12 text-primary` + lucide `Coins` `h-[18px] w-[18px]`) + 금액 `text-xl font-extrabold leading-none tabular-nums text-primary`, 단위 "메소"는 `text-xs font-bold text-text-muted`로 격하.
   - 하단 `mt-3 h-px bg-border` 헤어라인 — sticky 헤더의 바닥 경계 역할(카드 테두리 대신 얇은 선 하나로 목록과 분리).
3. **위계는 색·크기로만**: 새 색을 만들지 않고 브랜드 `primary`(금액·엠블럼)와 기존 `text-muted`(라벨·단위)만 쓴다. 금액은 `text-lg` → `text-xl`(20px). 탐색 중 시도한 `text-2xl`/`30px`는 "사이즈가 너무 크다"는 피드백으로 반려.
4. **기간 전체 고가 드롭 뱃지 재사용**: [[ADR-045]]의 캐릭터 카드 배지(`.valuable-drop-badge` 골드 pill + `Sparkles` + 실제 획득 아이템 아이콘 최대 3 + `+N`)를 **그대로** 라벨행 우측에 재사용한다. 집계는 기존 `collectGroupValuableDrops`를 캐릭터 그룹 전체로 확장(`collectAllValuableDrops`)해 신규 판정 로직 없이 `isValuableDrop`([[ADR-038]])만 재사용한다. 드롭이 없는 기간엔 **뱃지를 렌더하지 않는다**(캐릭터 카드와 동일한 조건부 표시). 컴포넌트는 배치를 호출부가 정하도록 `className`·`aria-label`만 열고(카드=`absolute -right-1.5 -top-2 z-10`/"고가 드롭", 헤드라인=인라인/"이 기간 고가 드롭"), 뱃지 외형·아이콘 스택 규칙은 단일 구현으로 유지한다.
5. **보스 처치 수·캐릭터 수는 표시하지 않는다**: 탐색 중 KPI 스탯 스트립(처치 보스·캐릭터·고가 드롭 3타일)을 시도했으나 "보스 몇 마리·캐릭터 몇 개는 중요한 정보가 아니다"로 반려. **고가 드롭만** 장식 겸 정보로 남긴다.

**이유**: 요약과 목록이 같은 표면(카드)을 쓰면 크기·색을 어떻게 조정해도 "카드들 중 하나"로 읽힌다. 카드를 벗기는 편이 대비를 만드는 가장 값싼 수단이고, `design-system.md` 안티패턴(모든 카드 동일 라운딩·gradient-text·네온 글로우 장식)도 건드리지 않는다. 대신 노-카드는 밋밋해지기 쉬워, 이미 이 화면의 언어인 **골드 고가 드롭 뱃지**를 장식 앵커로 끌어와 "심플하지만 비어 보이지 않는" 상태를 만들었다(사용자 아이디어).

**반려된 시안(탐색 기록)**: ① 프라이머리 틴트 히어로 카드 ② 메소 골드 원장 카드 ③ 미니멀 강조(좌측 액센트 바) — 셋 다 "틴트 카드 + 아이콘 + 숫자"라는 같은 골격이라 반려. ④ 프라이머리 솔리드 밴드(반전 텍스트) ⑤ KPI 스탯 스트립 — 골격은 달랐으나 각각 과하고/불필요한 정보. 최종안은 ⑥ 노-카드 타이포에 코인 엠블럼·컬러 숫자·고가 드롭 뱃지(라벨행)를 얹은 조합.

**트레이드오프**:
- **월간 탭 집계 범위**: 뱃지 집계가 `bossRows` 기준이라 [[ADR-045]]와 동일하게 월간 탭에서는 "월간 보스" 드롭만 잡힌다(주차별 합계 행엔 보스 행이 없음). 기존 한계를 그대로 승계.
- **아이템 중복 미병합**: 여러 캐릭터가 같은 고가템을 먹으면 아이콘이 중복 표시될 수 있다(캐릭터 카드 배지와 동일 규칙 유지 — 기간 전체 집계라 중복 확률은 더 높다). 병합은 필요해지면 별도 결정으로.
- ~~**헤어라인 vs sticky 페이드 중복**~~ → **해소**: 애초에 위치가 달랐고(페이드는 `top-full`로 헤더 바깥 아래 32px, 헤어라인은 헤더 안 `pb-2` 위), 이후 [[ADR-047]] 결정 6으로 **페이드 오버레이 자체를 제거**해 헤어라인이 이 화면의 유일한 헤더-목록 경계가 됐다.
- **금액 텍스트 노드 분리**: 단위 "메소"를 별도 `<span>`으로 빼 격하했다. 숫자와 span 사이에는 `ml-*` 마진 대신 **실제 공백 문자**를 남긴다 — 마진만으로 띄우면 `textContent`가 "N메소"로 붙어 스크린리더가 붙여 읽는다. 다만 공백을 넣어도 testing-library `getByText`는 **직계 텍스트 노드만** 비교하므로 기존 단일 노드 가정 테스트(`getByText('8,000,000 메소')`)는 그대로 통과하지 못한다 → 해당 테스트를 `getByText('8,000,000')` + `toHaveTextContent('8,000,000 메소')`로 갱신했다.

**저장소**: 스키마·데이터 변경 없음(순수 표시 계층. `boss_profit_records`·`boss_drop_records`·`valuable-drops.json`은 읽기만).

**구현(2026-07-28, 구현 완료)**: TDD로 테스트 먼저(실패 확인) → 구현. `BossProfitScreen.tsx` — 총 수익 카드 블록을 헤드라인으로 교체, `collectAllValuableDrops` 추가(`collectGroupValuableDrops` 합집합), `ValuableDropBadge`에 `label`(필수)·`className`(선택) 개방해 카드/헤드라인 두 배치 공유, `Coins` 아이콘 추가. 테스트 3건 신규(헤드라인 뱃지 표시·미표시·기간 전체 집계 `+N`) + 기존 총액 단정 1건 갱신(단위 span 분리 대응). 시안 탐색용 임시 라우트 `/debug/boss-profit-total-card`와 `BossProfitTotalCardPreview.tsx`는 삭제 완료.
