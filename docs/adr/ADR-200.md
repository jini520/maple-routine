# ADR-200: atoms 는 배럴 하나로 내보내고, 쓰는 쪽은 한 줄로 가져간다

> 🟢 **ACTIVE — 유효.** 현행 RN 앱에 적용되는 결정이다.

**날짜**: 2026-09-02
**상태**: **구현 완료**(2026-09-02)
**관련**: [[ADR-094]](계층을 나눈 결정) · [[ADR-199]] 결정 1(같은 판단을 `Icon` 디렉터리에서 먼저 했다) · [[ADR-197]] 결정 4(lucide 배럴을 막은 근거)

## 맥락

atom 아홉을 전수로 훑고 나온 문제다. 쓰는 쪽이 아톰마다 한 줄씩 적고 있었다.

```tsx
import { Badge } from '../components/atoms/Badge/Badge'
import { Button } from '../components/atoms/Button/Button'
import { MapleSweepSpinner } from '../components/atoms/Spinner'
import { ProgressBar } from '../components/atoms/ProgressBar/ProgressBar'
import { Text } from '../components/atoms/Text/Text'
```

**98개 파일이 167줄을 쓰고 있었다.** 한 파일이 다섯 줄까지 쓴다. 경로가 두 모양이라 더 안 읽힌다.
`components/atoms/…`(app 쪽)와 `../../atoms/…`(molecules·organisms 쪽)이 섞인다. 디렉터리 이름이
컴포넌트 이름과 같아 `Badge/Badge` 처럼 두 번 나오는 것도 눈이 한 번 더 확인해야 한다.

## 결정

### 결정 1. `atoms/index.ts` 하나로 내보낸다

쓰는 쪽은 한 줄이다.

```tsx
import { Badge, Button, MapleSweepSpinner, ProgressBar, Text } from '../components/atoms'
```

167줄이 98줄이 됐다. 새 atom 은 배럴에 한 줄을 더한다.

**Metro 가 트리셰이킹을 안 하므로 배럴은 안 쓰는 것까지 그래프에 넣는다.** [[ADR-197]] 결정 4 가
lucide 배럴을 막은 근거가 그것이다. 여기서는 셈이 다르다. lucide 배럴은 아이콘 1,900개를 끌고
오지만(실측 3,365 모듈 5.5MB) 이 디렉터리에는 아홉이 살고 전부 앱이 실제로 그린다. RN 은 번들이
하나이고 이 저장소에는 `React.lazy` 가 없어서, 아홉은 어차피 같은 번들에 함께 들어간다.
[[ADR-199]] 결정 1 이 `Icon` 디렉터리에서 이미 같은 셈을 했다.

### 결정 2. 배럴에는 **컴포넌트만** 올린다

곁 파일의 값은 원래 경로로 가져간다. `Text/font-scaling` 의 `FONT_SCALE_MAX` 와 `Icon/maple-leaf` 의
`MAPLE_LEAF_PATH` 가 그렇다(`Spinner/spinner-base` 의 `useLoopedValue` 도 예였으나 `hooks/` 로
나갔다. [[ADR-199]] 정정 4).

배럴이 층의 **얼굴**이기 때문이다. 얼굴에 내부 사정이 섞이면 무엇이 공개된 것인지 안 읽힌다.
[[ADR-199]] 결정 1 이 `icon-base.tsx` 를 `Icon` 배럴에서 뺀 것과 같은 규칙이다.

타입은 컴포넌트를 쓰려면 필요한 것만 올린다. 지금은 `BadgeVariant` 와 `TextInputProps` 둘이다.

### 결정 3. atom 끼리는 배럴을 거치지 않는다

`Button` 이 `MapleSpinner` 를 쓸 때는 `../Spinner` 로 직접 간다. 배럴을 거치면 순환이 생긴다
(`index` → `Button` → `index`). [[ADR-199]] 정정 2 가 `Spinner` 와 `Icon` 사이에서 이미 정한 것을
층 전체로 넓힌 것이고, `require-cycle-policy.test.ts` 가 어긴 것을 잡는다.

## 검증

`npx tsc --noEmit` 이 배럴에 없는 이름을 전부 잡는다. 계층 규칙(`layer-dependencies.test.ts`)과
순환(`require-cycle-policy.test.ts`)은 그대로 통과한다.

## 트레이드오프

**깊은 경로 import 를 기계가 막지 않는다.** `atoms/Text/Text` 로 직접 가도 아무것도 안 걸린다
([[ADR-197]] 이 같은 트레이드오프를 안고 간다). 규칙은 이 ADR 과 배럴 파일 머리에만 있다.

**배럴을 부르면 아톰 아홉이 함께 평가된다.** `Text` 하나만 쓰는 화면도 `react-native-svg` 와
Reanimated 를 거치는 모듈들을 그래프에 넣는다. 지금은 아홉이 다 작고 앱이 다 쓰지만, 무거운 atom
이 생기면 이 셈을 다시 해야 한다.
