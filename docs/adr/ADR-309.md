# ADR-309: 기록을 여러 건 쓰는 반복은 끝날 때 판 알림을 한 번 보낸다

> 🟢 유효 · 2026-09-23 · 구현 완료(2026-09-23, 실기기 미검증) · 사용자 지정(고칠 자리)

**관련**: [[ADR-272]] 결정 5(판이 바뀔 때마다 그 주 창을 다시 채운다)
**문서**: `features/boss-profit.md` 의 `판 갈이는 stamp 하나`

## 맥락

수익·지출 탭에 처음 들어가면 앱이 보스 처치 기록을 받아 쓴다. 2026-09-23 main 에서 계측한 한 회차는 보스 기록 쓰기
(`upsertBossProfitRecord`)가 60번, 처치 날짜 쓰기(`setBossProfitDefeatedOn`)가 121번이었다.

저장 계층은 쓰기 한 번마다 판을 올리고 구독자를 부른다(`bumpRecordsRevision`). 판을 구독하는 보스 수익 화면
(`useMonthlyCrystalsUpToWeek`)과 아이템 가격 입력 버튼(`useUnpricedDropCount`)이 그때마다 다시 그려진다.

가격 입력 버튼은 하단바 위에 뜨려고 포털(`BottomBarOverlay`, `@gorhom/portal`) 안에 있다. 이 포털은 내용이 다시 그려질
때마다 effect 안에서 호스트로 갱신을 보낸다. 그래서 쓰기가 이어지는 동안 effect 안의 갱신이 287번 이어졌고, React 개발
빌드가 `Maximum update depth exceeded` 를 띄웠다. 경고는 개발 빌드에만 뜨지만, 쓰기 한 번에 두 화면이 다시 그려지는 일은
릴리스에서도 똑같이 일어난다.

## 결정

### 결정 1. 판 알림을 반복 단위로 모은다

`storage/record-revision-batch.ts` 의 `batchRecordWrites(write)` 안에서 오른 판은 구독자를 곧바로 부르지 않는다. 가장
바깥 `batchRecordWrites` 가 끝날 때 한 번 부른다.

- 판 수(`getBossProfitRecordsRevision` · `getBossDropRecordsRevision`)는 쓸 때마다 곧바로 오른다. 미루는 것은 알림뿐이다.
  그 사이 다른 이유로 다시 그려지는 화면은 새 판을 보고 다시 읽는다.
- 반복이 던져도 알린다. 던지기 전에 쓴 기록이 있을 수 있어서다.
- 반복 안에서 판이 안 올랐으면 안 알린다.
- 반복이 겹치면 마지막 반복이 끝날 때 한 번이다. 수익·지출 탭의 회차는 오늘 기록과 지난 기간 기록을 나란히 돌린다.

### 결정 2. 감싸는 자리는 기록을 여러 건 쓰는 반복 넷이다 (사용자 지정)

| 반복 | 자리 |
|---|---|
| 자동 기록 | `features/boss-profit/auto-record.ts` 의 `autoRecordRows` |
| 지난 기간 기록 | `features/schedule-window/records.ts` 의 `recordBossProfitFromWindow` |
| 드롭 정리 | `features/boss-profit/drops-loader.ts` 의 `loadDropsByRowKey` 에서 획득 불가 드롭을 지우는 반복 |
| 처치 날짜 | `features/boss-profit/defeat-dates.ts` 의 `runResolveDefeatDates` 에서 날짜를 적는 반복 |

처치 날짜는 쓰는 반복만 감싼다. 그 앞의 API 조회까지 감싸면 조회가 도는 수 초 동안 다른 곳의 알림까지 묶인다.

한 건만 쓰는 자리(가격 입력 · 직접 완료 · 파티 설정)는 그대로 곧바로 알린다.

## 구현 (2026-09-23)

| 자리 | 파일 |
|---|---|
| 알림을 모으는 반복 | `storage/record-revision-batch.ts` 의 `batchRecordWrites` · `notifyAfterBatch` |
| 판을 올리는 두 곳 | `storage/boss-profit.ts` · `storage/boss-drops.ts` 의 `bumpRecordsRevision` 이 `notifyAfterBatch` 로 알린다 |
| 감싼 반복 넷 | 결정 2 의 표 그대로 |

## 대가

- 반복이 도는 동안에는 다른 곳에서 쓴 기록의 알림도 반복이 끝날 때까지 미뤄진다. 반복 하나는 기기 DB 쓰기뿐이라 길어야
  몇 초다.
- 보스 수익 화면의 월간 결정석 칩과 가격 입력 버튼 배지는 반복이 끝난 뒤에 새 수로 바뀐다. 전에는 쓰기마다 바뀌었다.
- 판을 올리는 새 반복을 만들 때 `batchRecordWrites` 로 감쌀지를 그 자리에서 정해야 한다. 안 감싸면 쓰기마다 알린다.
