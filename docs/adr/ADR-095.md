# ADR-095: NEXON Open API Analytics 스크립트 삽입 (삭제됨 · REMOVED)

> 🗑 **REMOVED — 폐기하고 지웠다.**
> 스크립트는 `index.html` `<head>` 에 박는 방식이었고 그 파일이 캐패시터 앱과 함께 사라졌다
> ([[ADR-155]]). RN 에는 `<head>` 가 없어 같은 방식이 성립하지 않으며, 저장소 전체에서
> `analytics` 를 참조하는 코드가 **0건**이다.
> **이 번호를 구현 근거로 인용하지 말 것.** 다시 필요하면 새 결정을 쓴다(RN 에서의 방식을
> 처음부터 정해야 한다).
>
> 원문이 필요하면: `git show store-1.0.6-capacitor-sunset:docs/adr/ADR-095.md`
