# ADR-078: 기간 이동의 네이티브 왕복 줄이기 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 웹뷰↔네이티브 브릿지 왕복이 전제였다. 구현 완료로 확인된 적이 없다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(서로 독립인 조회는 병렬로 던진다) · 결정 2(호출부가 이미 읽은 프로필을 넘겨 캐시를 다시 안 읽는다). 웹뷰 브릿지는 없어졌지만 **SQLite 왕복에 같은 이유가 그대로 성립해** `features/boss-profit/store.ts` 가 지금도 이대로 짠다. 죽은 것은 «웹뷰↔네이티브 왕복» 이라는 전제뿐이다.

## 무엇을 결정했었나 (요약)

기간 `‹ ›` 이동의 깜빡임을 **웹뷰↔네이티브 브릿지 왕복 수를 줄여** 없애려 했다(조회 결과 재사용 + 체크 조회 병렬화). 설계만 확정됐고 구현 완료로 확인된 적이 없다 — 실제 원인은 [[ADR-080]] 이 찾아냈다.
