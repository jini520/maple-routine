# ADR-089 — 검은마법사 테마 추가: 카민 크림슨 + 초월체 라벤더

**날짜**: 2026-08-03
**상태**: 구현 완료 (배경 값 조정은 사용자 확인 대기)
**관련**: [[ADR-064]](38토큰·파생 규칙) · [[ADR-088]](테마 배경 이미지·틴트 오버라이드 선례) · [[ADR-087]](`rise`/`fall` 고정 휴) · [[ADR-009]](테마 등록·기본 다크) · [[ADR-006]](색 값은 사용자 확인)

## 맥락

여섯 번째 테마다. [[ADR-064]] 결정 10 이후 테마 추가는 `job-themes.json` 한 블록이므로
**결정할 것은 값뿐**이고, 이 문서는 그 값이 어디서 왔는지와 규칙을 덮은 한 자리를 남긴다.

사용자가 레퍼런스 6장을 줬다 — 일러스트 · 보스 본체 · 창조의 아아온(하수인) · 파괴의
얄다바오트(하수인) · 초월체 모드 · 보스 맵. 이미지에서 실제로 샘플링한 색은 이랬다
([[ADR-006]] 도메인 데이터라 추정이 아니라 픽셀에서 뽑았다).

| 출처 | 대표색 | OKLCH |
|---|---|---|
| 일러스트 | 검정 82% · 불티 `#E7B758` | H 82, 채도 있는 픽셀이 전체의 0.1% |
| 보스 본체 | `#D8072A` 진홍 아우라 · 금빛 로브 트림 | H 23.8 |
| 창조의 아아온 | `#E33CB9` 마젠타 | H 340 |
| 파괴의 얄다바오트 | `#D8072A` 진홍 · 보주 `#B36BE8` | H 23.8 / H 309 |
| 초월체 | `#A9A2E8` 라벤더 · 창백한 흰빛 | H 287 |
| 보스 맵 | `#DC4376` 카민 네온 격자 · 자흑 바탕 | H 4.6, 화면의 H 340~350(HSL)이 지배적 |

## 결정

### 1. 시드 3색 — 진홍이 아니라 **카민**이다

시안 3안을 실제 앱 화면 목업으로 그려 견줬고 사용자가 A를 택했다.

| 토큰 | 값 | 출처 |
|---|---|---|
| `primary` | `#E0245E` 카민 크림슨 | 보스 맵 네온 격자 + 본체 아우라 |
| `secondary` | `#A9A2E8` 라벤더 | 초월체 모드 |
| `third` | `#E85BC0` 핑크 | 창조의 아아온 |
| `mode` | `dark` | |

**본체의 진홍(`#D8072A`)을 그대로 쓰지 않은 이유가 이 결정의 요점이다.** 이 앱은 `error`(휴 27)와
`rise`(휴 26)를 브랜드 시드와 무관하게 **고정**한다 — "빨강 = 실패·상승"이 테마마다 다른 색이 되면
뜻을 잃기 때문이다([[ADR-064]], [[ADR-087]] 결정 5). 진홍은 OKLCH 휴 **23.8**이라 그 둘과 3° 안에
들어가고, 그러면 `기록하기` 버튼과 실패 토스트가 같은 색이 된다. 고정 휴 쪽을 옮기는 것은 답이
아니다(그 고정이 존재 이유다). 그래서 **primary 를 맵의 카민(H 10.6)까지 밀어 16°를 벌렸다** —
검은마법사의 붉은 인상은 남기고 경고색과는 갈린다.

`secondary` 를 초월체 라벤더로 둔 것도 자리에서 나왔다. 이 토큰이 앱에서 맡는 곳은 완료 배지와
성공 토스트라 붉은 계열이 오면 뜻이 어긋난다. 혼테일이 얼음 파랑을 보조로 쓴 것과 같은 이유의
차가운 대비다([[ADR-088]] 결정 1).

시안 B(순정 진홍 + 엠버 금)와 C(창조 마젠타 + 얄다 바이올렛)는 각각 위 충돌과 "앱 전체가 분홍이
된다"는 이유로 떨어졌다.

### 2. `secondaryTint` 만 파생 규칙을 덮는다 — 자주색 표면 + 라벤더 15% = 자두색

[[ADR-064]] 의 틴트 규칙은 `color-mix(accent 15%, surface)` 다. 검은마법사 표면은
`#1E1214`(H 8 자주 기운)이고 라벤더는 H 288이라, 15% 를 섞으면 **`#30252F` — 채도 0.024 에
휴가 329로 41° 끌려간 자두색**이 나온다. `surface2`(`#302224`)와 사실상 같은 색이라 완료 배지가
중립 pill 과 구분되지 않는다.

[[ADR-088]] 결정 2 와 **같은 실패 모드**다(혼테일: 갈색 표면 + 얼음 15% → 무채색). 처방도 같다 —
차가운 베이스 쪽에서 값을 잡아 `secondaryTint: #2D284A` 로 덮는다.

| | 채도 C | 휴 H | accent(H 288)에서 이탈 |
|---|---|---|---|
| 규칙 파생 `#30252F` | 0.024 | 329 | **41°** |
| 덮은 값 `#2D284A` | 0.061 | 289 | **1°** |

**진단은 대비가 아니라 색조로 한다.** `#30252F` 와 `surface2` 의 대비는 1.04:1 이라 "구분된다"고
읽히지만 실제로 안 보인다 — 두 색이 같은 명도대에 있고 색조까지 같기 때문이다. 대비비는 명도
차이만 재므로 이 실패 모드를 원리적으로 못 잡는다.

**이걸 전역 회귀 테스트로 세우지 않았다.** 같은 척도(틴트의 accent 휴 이탈)를 기존 5테마에 재보면
레테 `secondary` 가 115°, 엔젤릭버스터가 45° 다. 둘 다 `secondary` 채도가 낮아(C 0.06) 15% 를
섞으면 남는 채도가 0.008 수준이고, 그때 휴는 잡음이라 이탈 각도 자체가 뜻이 없다. 임계를 세우면
그 두 테마의 값을 다시 정해야 하는데 이 작업의 범위가 아니다. 규칙 자체는 그대로고, 덮는 자리는
테마별 값 결정으로 남긴다.

### 3. 배경 이미지는 보스 맵

[[ADR-088]] 결정 3 의 `background` 블록을 그대로 쓴다. 슬러그는 `blackmage-throne`
(`src/assets/themes/blackmage-throne.webp`, 800×323).

```jsonc
"background": { "image": "blackmage-throne", "size": "cover", "position": "center", "dim": 0.78, "fadeTop": "0px" }
```

`dim` 은 브라우저에서 0.86·0.78·0.70 을 견줘 잡았다. 처음 짚은 0.86(혼테일 0.82 보다 어둡게 —
붉은 네온 격자가 밝게 올라올 것을 예상)은 **그림이 거의 안 보였다**. 이 맵이 원래 어두운 데다
`cover` 가 800×323 을 세로로 긴 뷰포트에 맞추며 가운데를 크게 확대해 잘라내기 때문이다. 예상이
틀린 방향이었고, 0.78 에서 색이 올라오면서 카드 사이 여백의 텍스트 대비는 그대로였다.

**확정값은 `/debug/theme-background` 에서 사용자가 눈으로 맞춘다** — 그림을 고치는 게 아니라 값을
고치는 구조라 코드는 건드리지 않는다.

배경을 가진 테마가 혼테일 하나에서 **둘**이 됐고, 그 때문에 디버그 도구에 구멍이 생겨 함께 고쳤다 —
테마 전환 버튼이 "배경 **없는** 테마일 때만" 떠서 혼테일에서 검은마법사로 건너갈 수 없었다.
버튼을 항상 띄우고 현재 테마를 눌린 상태로 표시한다(배경 가진 테마가 하나뿐이던 시절엔 드러날 수
없던 결함이다). 배경 없는 네 테마는 여전히 CSS 자체가 안 나간다.

### 4. 기본 다크 테마는 혼테일 그대로

OS 다크 모드에서 저장된 선택이 없을 때 뜨는 테마는 계속 혼테일이다([[ADR-009]]).
검은마법사는 설정에서 고르는 선택지로 들어간다 — 기본값 변경은 별개 결정이다.

## 받아들인 미달

[[ADR-064]] 판단 순서대로 **색감이 먼저이고 대비는 참고**다. 생성 도구 리포트에서 기준선(4.5)
아래인 7건 중 눈에 띄는 것은 이렇다.

| 항목 | 값 | 판단 |
|---|---|---|
| `onSecondary` / `secondary` | 2.06:1 | 규칙대로 아이보리. 엔젤릭버스터 파스텔 핑크(2.02)와 같은 자리다 |
| `onPrimary` / `primary` | 4.06:1 | 아이보리가 카민 위에서 읽힌다 |
| `primaryInk` / `surface` | 3.98:1 | accent 원색 유지(가시성 하한 2:1 위) |
| `primaryInk` / `primaryTint` | 3.48:1 | 위와 같음 |

`text`·`textMuted` 는 `bg`·`surface` 양쪽에서 AA 위다(15.79 / 8.00 / 14.25 / 7.22).

## 결과

- `src/data/job-themes.json` 에 블록 하나 + `src/assets/themes/blackmage-throne.webp`.
- 제품 코드 변경 없음. 회귀 테스트는 `it.each(NAMES)` 라 새 테마가 자동으로 검사 대상에 들어간다
  ([[ADR-064]] 결정 11 — 테마가 늘어도 테스트는 안 는다). 실제로 18케이스가 새로 붙었다.
- 임시 디버그 라우트 `ThemeBackgroundPreview` 의 테마 전환 버튼만 손봤다(결정 3).
