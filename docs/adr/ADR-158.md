# ADR-158: ADR 원장에 상태 배지를 달고, 죽은 결정의 본문을 요약으로 줄인다

> 🟢 **ACTIVE — 유효.** 현행 RN 앱에 적용되는 결정이다.

**날짜**: 2026-08-21
**상태**: 결정 · **구현 완료**(2026-08-21)
**관련**: [[ADR-128]](RN 전환 — 이 문제를 만든 시대 경계) · [[ADR-155]](캐패시터 소스 삭제) ·
[[ADR-143]](계정 선택 폐지 — 이번에 잔재를 걷은 결정) · 문서: `docs/README.md` · `CLAUDE.md`

## 맥락

**세션이 죽은 정책을 근거로 코드를 되돌리는 일이 반복됐다**(사용자 보고). 원인이 셋이었고 전부
원장 쪽에 있었다.

1. **인덱스가 342KB 로 불었다.** `docs/ADR.md` 는 스스로 *"슬림 인덱스이니 전체를 컨텍스트에 올리지
   말 것"* 이라 적어 두고도 한 행이 41KB 인 요약을 쌓아 왔다. 인덱스만 열어도 죽은 정책이 통째로
   컨텍스트에 들어온다.
2. **상태 표기가 제각각이었다.** 157개 중 **63개는 상태 필드 자체가 없고**, 있는 것도
   `**상태**:` 와 `- 상태:` 두 형식이 섞였다.
3. **폐기 사실이 본문 산문에 묻혔다.** *"[[ADR-074]] 의 마크는 그 자리에서만 폐기"* 같은 문장이
   본문 중간에 있어, 인덱스만 보면 죽은 결정과 산 결정의 표정이 같다.

가장 큰 회귀 원인은 **시대 경계**다 — [[ADR-128]] 이 RN 으로 옮기고 [[ADR-155]] 가 캐패시터 소스를
지운 뒤에도, 그 시대의 DOM·CSS·@capgo·Vite 결정 수십 개가 유효한 결정과 나란히 서 있었다.

## 결정

**1. 배지 다섯을 파일 제목 바로 아래와 인덱스에 단다.**
🟢 유효 · 🟡 부분 폐기 · ⛔ 폐기 · ⚪ 미구현 · 🗑 삭제. 파일에서는 **제목 다음 첫 블록**이라
`head` 몇 줄로 판정된다.

**2. 판정은 산문이 아니라 코드로 한다.** 캐패시터 시대 ADR 26개를 지우려다, **코드 역인용 검사**로
그중 **22개를 현행 RN 코드가 지금도 근거로 인용**하고 있는 것을 발견했다(`storage/sqlite/db.ts` 의
`[[ADR-050]] 결정 2` = stale 커넥션 자가복구 등). 지웠으면 살아 있는 코드의 «왜» 가 끊겼다.
그래서 **인용처가 0인 것만 지우고**(6개), 나머지는 배너에 **🔗 «지금도 코드가 따르는 결정»** 줄을
달아 결정 번호와 파일까지 못박았다. **그 줄에 없는 것은 죽은 것이다.**

**3. ⛔·🗑 의 본문은 요약으로 줄인다.** 배지만으로는 부족하다 — 파일을 열면 그 정책이 그대로
컨텍스트에 실리고, 실리면 다시 구현된다. 「무엇을 결정했었나」 몇 줄만 남기고 맥락·계측·트레이드오프
전문은 **git 히스토리로 내렸다**(284KB → 29KB). 각 파일이 복구 명령을 적어 둔다.

**4. 살아 있는 문서 본문에서 죽은 ADR 로 가는 `[[…]]` 인용을 끊는다.** `features/`·`foundation/`·
`persistence/` 의 본문에서 157건을 제거했다. **예외는 각 문서의 `폐기된 정책 (history)` 절** —
거기가 죽은 것을 두라고 만든 자리다.

**5. 인덱스에는 한 줄만 넣는다.** 번호·배지·제목·대체 ADR. 요약을 이 표에 쌓지 않는다(그것이
342KB 를 만든 경로다).

**6. 결정을 뒤집을 때의 절차를 `CLAUDE.md` 에 넣는다** — 옛 ADR 의 배지를 🟡/⛔ 로 내리고, 대체
번호를 적고, **본문을 요약으로 줄인다.**

## 트레이드오프

- **원문을 보려면 git 이 필요하다.** 태그 `store-1.0.6-capacitor-sunset` 이 캐패시터 시대 트리를
  고정하고 있어 복구는 한 줄이지만, 「파일을 열면 다 있다」는 성질은 잃었다.
- **요약이 틀리면 조용히 틀린다.** 배지·요약은 사람이 매긴 판정이라 검증하는 테스트가 없다.
- **배지는 시점 기준이다**(2026-08-21 코드). 코드가 바뀌면 낡으므로 결정 6의 절차가 유일한 방어다.
