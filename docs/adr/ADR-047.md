# ADR-047: 펼친 캐릭터 카드 헤더를 sticky 로 고정 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-131]] «고정 영역 없음» 이 중첩 sticky 를 폐기했다 — sticky 오프셋 실측(결정 3)은 죽었다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 4(카드 안 z 층 순서) · 6(경계 페이드를 이 화면에서 뺀다) — `CharacterAccordion`·`CharacterIssue`·`PageHeader`·`ScreenScroll` 이 그 배치를 잇는다.

## 무엇을 결정했었나 (요약)

펼친 캐릭터 카드 헤더를 **중첩 sticky** 로 고정했다 — 오프셋은 페이지 헤더의 실측 높이, 배경은 불투명, 카드 안 z 층은 `드롭 아이콘 < 헤더 < 골드 링 < 고가 배지` 순. 펼침 셸의 `overflow-hidden` 을 걷고(스크롤포트를 만들어 sticky 를 무력화한다) 경계 페이드를 페이지 헤더에서 카드 헤더 아래로 옮겼다.
