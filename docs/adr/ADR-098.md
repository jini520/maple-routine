# ADR-098: 탭 이동의 스크롤 클램프 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 문서 스크롤 클램프 처방이라 RN 에 대응물이 없다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1(`useScreenNavigate` 공용화) · 2(공용 `PageHeader`) · 3 — `BossScreen`·`ContentScreen`·`SettingsScreen`·`PageHeader` 가 그 공용화를 잇는다.

## 무엇을 결정했었나 (요약)

[[ADR-085]] 의 `fixed` 헤더 + 실측 spacer 처방을 **스케줄러 4화면으로 넓혔다**. 딸려 나온 것 셋 — 라우트 이동은 스크롤을 먼저 0으로(`useScreenNavigate`) · 헤더를 공용 `PageHeader` 로 · 설정 화면도 같은 규약.
