# ADR-025: 스플래시 — 네이티브 하나로 통일 + MIUI force-dark (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-138]](Expo prebuild)이 자산·구성을 대체했다. 색 split(`values-night` `#D06100`)·비트맵은 RN 에 없다 — 한 색 `#F58B0F` 다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — «첫 렌더 전 깜빡임을 스플래시로 덮는다» 는 목적 — `index.ts`→`boot-splash.ts`(붙들기)와 `AppShell`(최소 표시 1초)이 그대로 잇는다.

## 무엇을 결정했었나 (요약)

스플래시를 **네이티브 한 장**으로 통일하고(HTML 부트 스플래시를 두지 않는다) 아이콘은 투명 배경 락업을 썼다. MIUI/HyperOS 다크모드 force-dark 대응으로 배경색을 `values-night` 로 갈라 라이트 `#FB8101` / 다크 `#D06100` 을 줬다.
