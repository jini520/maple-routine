# ADR-085: 헤더를 스크롤에서 떼어낸다 (fixed + 실측 spacer) (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** [[ADR-131]] 이 `fixed` 헤더 + 실측 spacer 구조를 통째로 걷어냈다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 1·2 의 관측(스크롤 스레드가 되돌려 보내는 옛 오프셋)이 `PageHeader`·`CharacterAccordion` 주석의 «왜 여기서 재지 않는가» 근거로 남는다.

## 무엇을 결정했었나 (요약)

깜빡임의 진짜 원인은 **스크롤 스레드가 되돌려 보내는 옛 오프셋**이었다. 그래서 클램프를 만들지 않고 **헤더를 스크롤 맥락에서 떼어냈다** — `sticky` 를 `fixed` 로 바꾸고 흐름에는 실측 높이의 spacer 를 둔다(측정은 `useLayoutEffect`).
