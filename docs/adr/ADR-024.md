# ADR-024: OTA 버전 형식 수정 + 베타 채널 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** 베타 채널과 `import.meta.env` 주입은 [[ADR-137]] 이 폐기했다(Metro 에 `import.meta` 가 없다).
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 세 자리 버전 형식 검증 — `native/live-update.ts` 의 파서가 이 ADR 이 늦게 발견한 버그를 지금도 막는다.

## 무엇을 결정했었나 (요약)

네이티브 `versionName` 을 세 자리(`1.0.0`)로 통일해 `x.y.z` 파싱이 맞물리게 했다(2단이라 OTA 가 한 번도 작동하지 않았다). 베타 채널은 **런타임 토글이 아니라 빌드 시점 분리**로 두고(별도 매니페스트 URL·릴리스 태그), 배포 스크립트에 `--beta` 를 더했다.
