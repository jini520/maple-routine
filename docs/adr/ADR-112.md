# ADR-112: spacer 실측 — ResizeObserver 한 경로의 한 프레임 어긋남 (폐기 · DEPRECATED)

> ⛔ **DEPRECATED — 폐기.** `ResizeObserver` 도 실측 spacer 도 RN 에 없다.
> **새 구현의 근거로 인용하지 말 것.** 본문은 아래 요약으로 줄였다 — 죽은 정책이 컨텍스트에
> 실리지 않게 하기 위해서다.
>
> 🔗 **지금도 코드가 따르는 것** — 결정 3(훅 API 는 `RefObject` 가 아니라 콜백 ref) — `ItemRevenuePopover`·`PageHeader` 가 그 형태를 쓴다.

## 무엇을 결정했었나 (요약)

`fixed` 헤더의 spacer 실측이 **`ResizeObserver` 한 경로뿐이면** 헤더 높이를 바꾸는 상태 전환마다 한 프레임 어긋난다(RO 콜백의 `setState` 가 다음 프레임에 렌더된다). 처방 — 측정 전용 layout effect 를 deps 없이 따로 두고 RO 는 렌더 밖 변화 담당으로 남긴다. 공용 훅으로 추출하고 API 는 콜백 ref.
