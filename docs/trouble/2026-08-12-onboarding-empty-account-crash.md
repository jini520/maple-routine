# API 키 입력 후 「화면을 표시하지 못했습니다」 (2026-08-12)

[[ADR-127]] · 테스터 보고(갤럭시 S21, 2026-08-12 14:00).

**재현 기기 없이 코드로 규명한 기록이다.** 재현 조건(캐릭터가 0명인 메이플 ID)을 가진 계정이 테스터
쪽에만 있어, 사슬은 **재현 테스트로** 확정하고 실기기 확인은 남겨 뒀다.

## 증상

테스터가 보낸 화면 셋이고, 스크린샷 시각이 서술 순서와 어긋난다(1:51 검정 → 1:53 주황 → 1:56 폴백).

| 화면 | 시각 | 보고된 조작 |
|---|---|---|
| 「화면을 표시하지 못했습니다」 폴백 | 1:56 | 설치 → API 키 입력 |
| 완전한 검정 | 1:51 | 재설치 → 업데이트 모달에서 `나중에` |
| 브랜드 주황 전체 화면 | 1:53 | 〃 |

세 화면 모두 **더 진행되지 않았고**, 앱을 지우고 다시 깔아도 같은 자리에서 멈췄다.

## 원인

`AccountSelectionList` 의 렌더 한 줄이 던진다. 전문은 [[ADR-127]] 맥락에 있고, 요약하면
**캐릭터가 0명인 메이플 ID → 대표 캐릭터 `null` → 빈 배열로 `pickRepresentativeCharacter` 호출 → throw**
→ [[ADR-065]] 결정 5 의 전역 에러 바운더리.

`submitApiKey` 가 목록을 그리기 **전에** 키를 저장하므로 재시작해도 `deriveResumeTarget` 이 같은 단계로
되돌린다([[ADR-086]] 결정 1) — 그래서 영구다.

## 같은 크래시가 세 화면으로 보인 이유

`App.tsx` 의 스플래시 타이머가 `MIN_SPLASH_MS`(1초) 뒤에 `#boot-cover` 를 걷는데, 렌더가 던지면 바운더리가
그 트리를 언마운트하며 **타이머를 취소한다** — 걷을 주체가 사라진다([[ADR-117]] 결정 3 이 지적한 그 사슬).

- **폴백이 보인 경우**: 크래시가 1초보다 늦었다(키를 직접 입력한 첫 시도 — 입력 시간이 있어 항상 늦다).
- **주황에 갇힌 경우**: 크래시가 1초보다 일렀다. 저장된 키로 재개하는 부팅이라 입력 대기가 없고,
  캐릭터가 0명이면 프로브가 즉시 settle 해 목록이 곧바로 그려진다 — **네트워크 지연에 따라 1초 경계를
  넘나든다.** 그래서 같은 조작이 실행마다 다른 화면으로 보였다.
- **검정**: 확정하지 못했다. 웹뷰가 아무것도 그리지 않은 순간(폴백의 `다시 시작` → 리로드 구간 등)으로
  보이지만 추정이고, **logcat 이 있어야 단정할 수 있다.**

⚠️ **[[ADR-117]] 은 이 세 화면 중 둘을 이미 고쳤는데 테스터에게는 적용되지 않았다** — 배포 중인 APK 가
versionCode 19(2026-08-04)이고 그 수정은 1.0.3(OTA)에 들어갔다. 내장 번들에는 8초 실패 안전 타이머도,
`ErrorBoundary` 의 `hideSplashScreen()` 도 없다. **네이티브 재빌드 전까지 새 설치자는 계속 이 상태다.**

## 확인 방법

테스터 API 키로 `GET /maplestory/v1/character/list` 를 직접 호출해 `character_list: []` 인 `account_list`
항목이 있는지 본다. 사슬을 끊는 자리는 `nexon/character/__tests__/normalize.test.ts` 가 지킨다
(캐릭터 0명 계정 제외 · 전 계정 0명이면 빈 배열).

**`AccountSelectionList` 쪽에는 테스트를 두지 않았다** — 던지는 그 폴백은 [[ADR-127]] 결정 1 이 **계약을
바꾸지 않기로 한 자리**다(인자가 항상 1명 이상이라는 불변식을 위에서 지킨다). 여기에 "빈 계정을 줘도
안 던진다"를 적으면 기각한 대안(렌더 폴백만 고치기)을 테스트가 요구하게 된다.

## 복구 안내(이미 갇힌 사용자)

**OTA 만으로는 안 풀린다** — 업데이트 모달(`UpdatePromptModal`)이 `AppShell` 안, 즉 에러 바운더리 **안**이라
크래시하면 모달도 함께 사라진다. 순서가 중요하다:

1. 앱 삭제(저장된 키가 지워진다) → 재설치
2. 실행하면 API 키 입력 화면에서 멈춘다 — **여기서는 크래시하지 않는다**
3. 업데이트 모달이 뜨면 **`나중에` 가 아니라 받는다**
4. 적용·재시작 뒤에 API 키를 입력한다
