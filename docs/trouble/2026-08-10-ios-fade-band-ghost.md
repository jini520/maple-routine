# 2026-08-10 — iOS 실기기에서 경계 페이드가 잔상으로 남는다 (찍히지 않는 버그를 가르는 법)

- 결론: [[ADR-123]] — 경계 페이드에서 `backdrop-filter` 를 뺐다 (이슈 #191).
- 기기: iPhone 17 / iOS 26.5 / Capacitor WKWebView.

## 증상

당겨서 새로고침을 하면 당겨진 자리에 흐릿한 띠가 잔상처럼 남는다. 라이트 테마에서 뚜렷하고
다크 테마에서는 잘 안 보인다.

## 이 버그가 어려웠던 이유

**관측 도구가 전부 막혀 있었다.**

| 시도 | 결과 |
|---|---|
| 스크린샷 | 안 찍힘 — 볼륨/전원 버튼이 **하나만 눌려도 띠가 먼저 사라진다** |
| 화면녹화 | 안 찍힘 |
| iOS 시뮬레이터 | 재현 안 됨 (합성 경로가 실기기와 다르다) |
| Safari 탭에 구조 재현 | 재현 안 됨 (WKWebView 와 환경이 다르다) |

사용자 스크린샷 2장을 픽셀로 재 봤을 때 밴드 구간 50행이 **정확히 `#f2f0e2` 하나**(편차 0)였다.
±3레벨을 40배 증폭해도 균일한 단색 면뿐 — **캡처된 프레임에는 정말로 아무것도 없다.**

## 헛다리 넷 (전부 실측으로 반증)

시뮬레이터에 앱 구조를 그대로 옮긴 재현 페이지로 갈랐다. 넷 다 정상 렌더였다.

1. WebKit 이 `backdrop-filter` 에 `mask-image` 를 무시한다 → 마스크가 블러를 정상 감쇠
2. 관성 스크롤 중·직후 백드롭 스냅샷이 스탈 → 모든 프레임에서 밴드 색 = 아래 카드 색
3. `TabLayer` 의 `transform` 부여→**완전 제거**([[ADR-120]] 결정 7) 후 레이어 잔존 → 기준 프레임과 픽셀 동일
4. 앱 백그라운드→포그라운드 복귀 후 리페인트 누락 → 정상

곁가지로 하나 더 재 봤다 — 균일한 배경 위의 그라데이션 밴드는 **같은 색을 칠하는데도 ±1 레벨로
흩어진 93종의 색**을 만든다(밴드 없을 때 51종·99.3% 일치 → 있을 때 93종·60.3%). 실재하는 성질이지만
±1 레벨의 휘도차가 밝은 배경 0.95% / 어두운 배경 7.78%로 **사용자 관찰과 방향이 반대**라 원인이 아니다.

## 갈라낸 방법

**추론을 멈추고 실기기의 실제 앱 안에서 하나씩 뺐다.**

임시 변형 스위치(`src/lib/debug-fade-variant.ts` + 호출부 3곳)를 앱에 넣어 **재빌드 없이** A→B→C→D 를
전환하게 만들고 사이드로딩했다. 스위치는 **`TabLayer` 바깥**에 뒀다 — 헤더 안이나 탭 레이어 안에
넣으면 그 자체가 합성 레이어 구성을 바꿔 관측 대상을 오염시킨다.

| | 구성 | 결과 |
|---|---|---|
| A | 현재 그대로 | 잔상 있음 |
| **B** | **`backdrop-blur-sm` 제거** | **정상** |
| C | 당길 때만 밴드 숨김 (블러 유지) | 불충분 — 스크롤 없는 화면에서 가끔 샘 |
| D | 밴드 없음 | 정상 |

`CURRENT_PROJECT_VERSION` 을 11→12 로 올려야 OTA 번들이 새 빌드를 가리지 않는다
(검증 전용 범프는 커밋 전에 되돌린다).

## 교훈

- **"촬영이 안 된다"는 증상이 아니라 진단이다.** 캡처 행위가 강제 리페인트를 걸어 낡은 합성 레이어를 갱신시켜 버린다. 프레임버퍼가 깨끗한데 눈에 보인다면 화면에 나가는 것이 합성 단계에서 낡았다는 뜻이다.
- **시뮬레이터와 Safari 는 WKWebView 의 합성 문제를 재현하지 못한다.** 이 계열([[ADR-079]]·[[ADR-085]]·[[ADR-098]])은 처음부터 실기기로 가는 편이 빠르다. 여기서 재현 하네스를 두 번 만들었고 둘 다 버렸다.
- **재현되지 않는 환경에서 추론을 쌓지 말 것.** 관측이 가설을 반박하면 계측 도구를 바꿔야지 가설을 더 정교하게 만들 일이 아니다. 이번엔 헛다리 넷을 지나서야 실기기로 갔다.
- **원인 메커니즘을 끝까지 밝히지 않아도 고칠 수 있다.** WKWebView 가 백드롭 스냅샷을 언제 갱신하는지는 모르는 채로 끝났다 — 레이어를 만들지 않으면 그 질문이 사라진다.
- **완화가 아니라 사슬의 첫 고리를 끊을 것.** C(당길 때 숨김)는 특정 상황만 막았고 실제로 다른 데서 샜다.
