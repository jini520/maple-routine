# Architecture Decision Records (인덱스)

> 결정 원장. **각 ADR 전문은 [`adr/`](./adr/) 에 파일 하나씩** 있다. 이 파일은 **슬림 인덱스**다 —
> 필요한 결정만 `adr/ADR-NNN.md` 로 열고, 전체를 컨텍스트에 올리지 말 것. `[[ADR-NNN]]` 은 경로가
> 아닌 논리적 참조라 그대로 쓴다. 새 결정은 `adr/` 에 파일을 추가하고 이 표에 **한 줄**만 넣는다 —
> 요약을 이 표에 쌓지 말 것(그렇게 해서 이 파일이 한때 342KB 까지 불었다).

## 이 표를 읽는 법 (먼저 읽을 것)

**ADR 을 인용하기 전에 상태 배지를 먼저 본다.** 배지는 2026-08-21 현행 코드를 기준으로 매겼고,
각 `adr/ADR-NNN.md` 파일 제목 바로 아래에도 같은 배지가 박혀 있다.

| 배지 | 뜻 | 파일에 무엇이 있나 |
|---|---|---|
| 🟢 유효 | 현행 RN 앱이 이 결정대로 돈다 | 전문. 근거로 인용해도 된다 |
| 🟡 부분 폐기 | 일부 결정이 뒤집혔다 | 전문 + 배너의 «살아 있는 것» — 확인한 뒤 인용 |
| ⛔ 폐기 | 더 이상 유효하지 않다 | **요약 몇 줄만**(정책 본문은 git 히스토리로 내렸다) |
| ⚪ 미구현 | 결정만 있고 코드가 없다 | 전문. 착수 전에 다시 읽을 것 |
| 🗑 삭제 | 폐기하고 본문을 지웠다 | 묘비 한 문단. 원문은 git 태그 `store-1.0.6-capacitor-sunset` |

> **죽은 결정은 «읽을 수 있게» 두지 않았다.** ⛔ 28개는 «무엇을 결정했었나» 요약 몇 줄로 줄여
> 두었다(284KB → 29KB) — 파일을 열어도 그 정책을 다시 구현할 만큼의 내용이 나오지 않는다.
> 살아 있는 문서 본문에서 이 번호들로 가는 **`[[…]]` 인용도 끊었다**(157건).

> **⛔ 라고 전부 죽은 것은 아니다.** 웹뷰 시대 ADR 중 21개는 «결정 몇 개» 가 RN 코드로 그대로
> 넘어왔다(예: ADR-050 의 SQLite 커넥션 자가복구는 `storage/sqlite/db.ts` 가 지금도 건다). 그런
> 파일은 배너에 **🔗 줄**로 못박아 뒀다 — **그 줄에 없는 것은 죽은 것이다.**

## 현행 기준선 (baseline) — 2026-08-21

**이 저장소는 Expo React Native 앱 하나다.** [[ADR-128]] 이 RN 으로 옮겼고 [[ADR-154]]·[[ADR-155]] 가
캐패시터 앱을 끝내고 소스를 지웠다. 그래서 **아래 것들은 저장소에 존재하지 않는다** — 어떤 ADR 이
이것들을 전제로 말하고 있으면 그 문장은 죽은 것이다:

| 없는 것 | 지금은 | 결정 |
|---|---|---|
| Capacitor · WebView · `capacitor.config.ts` | React Native (Expo, Hermes) | [[ADR-128]]·[[ADR-155]] |
| Vite · `index.html` · `main.tsx` · `src/index.css` | Metro · `index.ts` · `global.css`+nativewind | [[ADR-128]]·[[ADR-155]] |
| DOM · CSS 기하 (`sticky`·`fixed`·문서 스크롤·`ResizeObserver`) | RN 뷰 · `ScreenScroll` 셸 · 고정 영역 없음 | [[ADR-131]] |
| @capgo OTA · `publish-live-update.mjs` | `expo-updates` + 자체 매니페스트 Worker | [[ADR-137]]·[[ADR-154]] |
| vaul(Drawer) · React Router · 자체 스택 전환 | `@gorhom/bottom-sheet` · `@react-navigation` | [[ADR-128]]·[[ADR-120]] |
| 자체 구현 당겨서 새로고침 훅 | RN `RefreshControl` | [[ADR-130]] |
| 계정(메이플 ID) 선택 단계 · 예열 | 캐릭터 선택 화면의 계정 드롭다운 | [[ADR-143]]·[[ADR-144]] |
| vitest · 렌더 트리 스냅샷 | jest 하나 | [[ADR-156]]·[[ADR-157]] |

예외 하나: `storage/adapters/capacitor-*` 와 `modules/capacitor-storage`, [`migration/data.md`](./migration/data.md) 는
**지금도 유효하다** — RN 앱이 캐패시터 시절에 저장된 기기 데이터를 계속 읽어야 하기 때문이다([[ADR-155]]).

## 철학

로컬 우선(local-first). 백엔드/로그인 없이 기기 안에서 완결되는 최소 구현을 우선 선택하고,
알림·백그라운드 사운드처럼 JS 만으로 불가능한 기능만 네이티브 어댑터에 의존한다([[ADR-003]]·[[ADR-005]] —
이 경계가 RN 전환을 가능하게 만든 원인이다). Nexon Open API 연동([[ADR-007]])도 사용자 개인이 발급받은
API 키를 기기에 저장해 직접 호출하는 방식이라 이 원칙을 벗어나지 않는다. 게임 밸런스에 따라 자주
바뀌는 수치 데이터는 로직과 분리해 유지보수 비용을 낮춘다([[ADR-006]]).
