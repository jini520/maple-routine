# 통계 (Stats)

> **범위**: 수익·지출 그룹의 셋째 하위 탭. 보스 수익과 가계부의 기록을 기간 단위로 모아 보는 화면이다. 기록을 쓰지 않고 읽기만 한다.
> **여기 없는 것**: 기록을 적고 고치는 일은 [cashbook.md](./cashbook.md) · [boss-profit.md](./boss-profit.md) 가 한다. 보스 표의 `alias` 는 [../foundation/game-data.md](../foundation/game-data.md) 가 든다.
> **관련 ADR**: [[ADR-330]](이 화면의 결정 전부) · [[ADR-333]](추이 막대 고르기 · 내역의 사냥 · 버프 묶음 · 단상) · [[ADR-169]](하위 탭) · [[ADR-170]](리셋 주) · [[ADR-237]](미완료 보스 행)
> **상태**: 구현 완료(2026-09-29, 이슈 #352). iOS 시뮬레이터 확인 · 실기기 미검증.

## 기간

머리에 `주간 · 월간` 세그먼트, 그 아래에 가계부와 같은 기간 줄이 선다. 주간은 목요일 리셋 주다. 카드는 기간을
따로 갖지 않는다. 카드마다 기간이 다르면 한 화면에서 서로 다른 기간을 말하게 되기 때문이다([[ADR-330]] 결정 2).

## 카드

차례대로 선다([[ADR-330]] 결정 3).

| 카드 | 모양 | 누르면 |
|---|---|---|
| 순 수익 | 큰 숫자(수입 − 지출) + 수입 · 지출 각주 | |
| 추이 | 주간 8주 · 월간 6개월 순수익 막대(0 선 위아래), 오른쪽 끝이 고른 기간. `순수익 · 수익 · 지출` 세그먼트, 아래 줄은 구간 평균 | 막대: 그 막대만 진하고 값 말풍선. 다시 누르면 풀린다 |
| 캐릭터별 | `순수익 · 수익 · 지출` 탭, 캐릭터마다 0 축 가로 막대, 오른쪽에 상위 셋 단상(캐릭터 전신 그림) | |
| 수입 내역 | 반원 도넛. 넷까지 조각, 나머지는 `그 외`. 갈래는 보스 결정석 · 보스 드롭 · 아이템 판매 · 사냥 · 기타 | `그 외`: 묶인 항목 팝오버 · `사냥`: `사냥 메소` · `솔 에르다 조각` 팝오버 |
| 지출 내역 | 수입 내역과 같은 모양 | `그 외` 같음 · `버프`: `보스 버프` · `사냥 버프` 팝오버 |
| 보스별 수익 | 초상 타일 가로 스크롤(폭 88), `난이도별 · 보스별` | |
| 누적 순수익 | 큰 숫자 + 시작 날짜 알약 + 누적 선 | 선 위 기간: 그 기간까지의 누적 말풍선(처음엔 없고 다시 누르면 닫힌다) · 알약: 달력에서 시작 날짜 고르기(기억한다) |

### 추이 막대 고르기

처음에는 아무 막대도 안 골랐다. 막대가 모두 진하고 말풍선이 없다. 막대를 누르면 그 막대만 진하고 말풍선이 뜬다.
같은 막대를 다시 누르면 풀린다. 기간이나 세그먼트가 바뀌어도 풀린다([[ADR-333]] 결정 2). 누적 순수익의 점과 말풍선도 같다. 기간이나 시작 날짜가 바뀌면 풀린다.

주간 추이의 주는 `n월 m주차` 로 부른다. 기간 줄과 같은 셈(`weekOfMonthLabel`, 주 키인 목요일이 든 달의 몇째 주)이다. 축은 `10월` · `1주차` 두 줄이다. 한 줄로는 여덟 칸에 안 들어간다(2026-10-02 사용자 지정).


### 나눠 보이는 조각

조각 하나가 갈래 여럿을 품으면 이름 끝에 `›` 가 붙고, 누르면 `그 외` 와 같은 팝오버가 나눈 줄을 보인다([[ADR-333]] 결정 3 · 4).

- 수입 `사냥` = 손입력 `사냥` + `솔 에르다 조각`. `사냥 메소` 는 사냥 기록 금액에서 그 기록의 조각 값(조각 수 × 조각 가격)을
  뺀 것이고, `솔 에르다 조각` 은 그 조각 값과 정산 기록의 합이다.
- 지출 `버프` = 버프 갈래 전체. 기록의 항목 key 로 선택 목록의 묶음(`보스 버프` · `사냥 버프`)을 찾아 나눈다. 0 인 줄은 안 선다.
- 보스 드롭(드롭 기록의 판매)과 손입력 `아이템 판매` 는 다른 조각이다.

### 글자와 숫자

- 흑자 · 적자라는 말은 쓰지 않는다.
- 캐릭터별 카드의 %는 수익 · 지출 탭에만 금액 앞에 적는다. 순수익 탭은 합계가 0 에 가까운 기간에 %가 튀어서 적지 않는다.
- 도넛 조각 안에는 항목 · % · 금액을 세 줄로 적는다. 좁은 조각은 반원 오른쪽에 선으로 이어 적는다.
- 보스 타일은 `alias` 를 쓴다. 긴 넷만 줄였다(`세렌` · `칼로스` · `가엔슬` · `메이린`). 이름 아래에 `n회 처치` 를 적는다.
- 난이도별 보기는 작은 난이도 배지(`Badge` `size="mini"`)를 초상 아래 테두리에 반쯤 걸친다.

### 겉모양

톤 채움 + 테두리 없는 카드다([[ADR-333]] 결정 9). 카드는 페이지 좌우 여백(16px) 안에 서고 모서리는 14px 다(앱 공용
`Card` 와 같은 둥글기). 실선 테두리는 없다. 카드 사이는 페이지 바탕색 8px 틈이다. 섹션 바탕은 라이트에서 `card-body` 45% + `surface` 55%, 다크에서 `surface-2` 60% +
`card-body` 40% 다.

### 그래프가 자라는 방법

화면에 들어오면 그래프가 진행값(`reveal.ts` 의 `useRevealProgress`)으로 자란다. **움직이는 도형을 `ClipPath` 안에 두지 않는다.**
안드로이드의 react-native-svg 는 클립 안 도형이 바뀌어도 다시 그리지 않아서, 첫 프레임(진행값 0)의 빈 클립에 굳고 그래프가 통째로
안 보인다(2026-10-04, 1.0.12 갤럭시 릴리스 빌드에서 수입 · 지출 내역 · 누적 순수익). 고정된 클립(누적의 0 선 위 · 아래)은 괜찮다.

- 수입 · 지출 내역: 조각마다 자기 경로(`d`)를 쓸기 각도까지만 그린다(`SweepSlice`).
- 누적 순수익: 그래프를 감싼 뷰의 폭을 늘린다(`overflow: hidden`). 0 선도 함께 드러난다.

## 불러오는 중

값을 모르는 동안 카드 본문 자리에 스켈레톤(`atoms/Skeleton`)이 선다(2026-09-29, 사용자 지정). 아직 안 읽은 기간을
`0 메소` 와 빈 그래프로 그리면 기록이 없다는 말로 읽히기 때문이다.

- **언제**: 기기 DB 첫 읽기(`loadStatsDays`)가 끝나기 전, 그리고 층이 **아직 안 받은 지난 날**을 받는 동안
  (`useLedgerData` 의 `status === 'filling'`, 진행률 모달이 함께 선다)이다. 당김도 여기 든다.
- `collecting` 으로 막지 않는다. 층은 받아 둔 달로 옮겨도 회차를 돌려 `collecting` 을 켜는데, 통계는 18개월치를
  이미 들고 있어 그 값이 맞다. 그것으로 막으면 값이 먼저 섰다가 스켈레톤이 뒤늦게 덮는다(2026-09-29 사용자 보고).
- **어디**: 기간 줄과 카드 제목은 그대로 서고 카드 본문만 바뀐다. 제목 옆 세그먼트와 누적 카드의 날짜
  알약은 알약 모양 막대로 자리를 잡는다. 제목 줄 높이가 같아야 값이 들어올 때 아래 카드가 안 밀린다.
- **그래프는 모양을 따른다**(사용자 지정). 통네모는 그래프로 읽히지 않는다. 추이는 눈금 다섯과 0 선
  위아래 막대 여덟, 수입 · 지출 내역은 반원 고리와 오른쪽 항목 글자, 캐릭터별은 가로 막대와 단상 블록,
  누적 순수익은 오른쪽으로 오르는 면이다. 도넛 구멍과 누적 곡선 위쪽은 스켈레톤을 섹션 바탕색으로 덮어
  만든다. 덮개를 펄스 밖에 두어야 한 번에 깜빡이고 구멍으로 고리 색이 안 비친다.
- 스켈레톤은 `app/stats/StatsSkeleton.tsx` 한 파일이 든다. 카드 모양을 고치면 이 파일의 높이도 함께 볼 것.

## 무엇을 세나

- 금액은 가계부의 메소 축과 같다. 메포는 사용자가 넣은 시세로 환산해 넣고, 캐시는 뺀다(`incomeMesoOf` · `spendMesoOf`, [[ADR-330]] 결정 13).
- 캐릭터를 고르지 않은 기록(`ocid` NULL)은 캐릭터별 카드에서만 빠지고 나머지 카드는 센다([[ADR-330]] 결정 7). 그래서 캐릭터별 합계가 순 수익과 다를 수 있다.
- 강화 지출은 기록에 적힌 이름 그대로 캐릭터별에 세운다. 개명 전 기록은 옛 이름으로 따로 선다(가계부와 같다, [[ADR-330]] 결정 14).
- 강화 금액은 가계부와 같은 `enhancementCostOf` 로 읽을 때 매기고, 못 매긴 줄은 합계에서 뺀다([[ADR-330]] 결정 15).
- 보스 금액은 내 몫 결정석이고 미완료 행은 빠진다([[ADR-237]]).
- 단상의 캐릭터 그림은 단상 블록에 겹쳐 내려 블록 앞에 그린다. 그림 칸이 발끝에서 잘려 발이 블록 뒤로 숨던 것을 고쳤다([[ADR-333]] 결정 7).
- **주간 보기의 보스별 수익에는 월간 보스가 안 선다**(2026-09-30 사용자 지정). 보스 표에서 주기가 월간인 보스(`findBoss(key).cycle`, 지금은 검은 마법사)다. 한 달에 한 번 잡는 보스가 주간 타일에 서면 그 주만 튀어 주마다 비교가 안 된다. 순 수익 · 추이 같은 합계에서는 안 뺀다. 그 주에 실제로 번 돈이라서다. 표에 없는 key 는 주기를 몰라 그대로 둔다.
- `spend_records.tariff_meso` 는 `meso_amount` 안에 이미 있어 더하지 않는다. `income_records.meso_amount` 는 수수료를 뗀 값이다.
- 집계는 `features/stats/` 의 순수 함수이고 저장소는 `storage/` 어댑터로 읽는다([[ADR-330]] 결정 12).
