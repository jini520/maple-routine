# MVP 등급 (MVP Grade)

> **범위**: 메이플 ID 마다 MVP 등급을 받아 두는 일. 그 등급이 경매장 수수료 기본값과 스타포스 비용을 정한다.
> 등급을 묻는 모달(고르기 · 확인)과 주간 확인, 설정에서 바꾸는 자리.
> **여기 없는 것**: 수수료를 실제로 떼는 계산은 각 기능 문서가 갖는다. 아이템 판매 · 조각 · 사냥 · 강화 지출은
> [cashbook.md](./cashbook.md), 드롭 판매가는 [item-drop.md](./item-drop.md) · [boss-profit.md](./boss-profit.md),
> 파티 모달의 송금 수수료는 [boss-scheduler.md](./boss-scheduler.md).
> **관련 문서**: [../foundation/game-data.md](../foundation/game-data.md) ·
> [../persistence/sqlite.md](../persistence/sqlite.md) · [app-entry.md](./app-entry.md) · [settings.md](./settings.md)

## 등급과 혜택 ([[ADR-306]] 결정 1)

| 등급 | 경매장 수수료 | 스타포스 할인 |
|---|---|---|
| 일반 | 5% | 없음 |
| 브론즈 | 5% | 없음 |
| 실버 | 3% | 3% |
| 골드 | 3% | 5% |
| 다이아 | 3% | 10% |
| 레드 | 3% | 10% |
| 블랙 | 3% | 10% |

- **메이플 ID 마다** 받는다. 열쇠는 `character/list` 의 `account_id` 다.
- **일곱을 하나씩 받고 등급 그대로 저장한다.** 혜택이 같은 등급끼리 묶지 않는다. 사용자는 자기 등급 이름을 알고,
  실제 등급을 저장해야 혜택이 바뀌어도 기록이 맞는다.
- 고르지 않으면 `일반` 이다.

## 날짜의 등급 ([[ADR-306]] 결정 2 · 3 · 4)

등급은 `(시작 날짜, 등급)` 줄로 메이플 ID 마다 쌓인다. 스타포스 비용이 읽을 때 계산이라, 등급 하나만 두면
등급이 바뀐 날 지난 지출이 통째로 움직인다.

- 기록의 날짜에 맞는 등급은 **그 날짜 이하에서 가장 늦은 시작 날짜**의 것이다.
- **첫 시작 날짜보다 앞선 기록은 등급이 없다.** 스타포스는 할인 없이 세고 수수료 일괄 적용에서 빠진다. 등급이 빈 줄
  (`등급 없음`, 첫 기록 앞에 끼워 넣은 기간의 끝을 닫는 줄)부터 다음 줄 전까지도 같다.
- **고를 수 있는 가장 이른 주는 가계부가 갈 수 있는 가장 이른 주다**(`historyFloorDateKey`, 18개월 전 달 1일이 든 주의 목요일).
  주를 고르는 자리 셋이 모두 따른다. 가계부가 그보다 앞을 안 보여 주어 그 앞의 등급은 쓸 곳이 없다.
- **시작 날짜는 늘 목요일**이다. MVP 등급이 매주 목요일에 바뀌기 때문이다. 기록의 날짜는 그 날이 든 주의 목요일로 바꿔 찾는다.
  달력은 **주를 고른다.** 격자는 일요일에서 시작하고, 어느 날을 눌러도 그 날이 든 주(목~수)가 두 줄에 걸친 **칠한 띠**로 선다.
  아래에 `선택한 주` 와 그 범위를 적는다.
  저장되는 값은 그 주의 목요일이다. 기본값은 **이번 주**이고 앱을 쓰기 전 주여도 된다. 이번 주 뒤는 못 고른다.
- 기록이 어느 ID 의 것인지는 캐릭터 소속 기록(`character_accounts`)으로 찾는다. 스타포스 줄은 **이름**만 들고 있어
  이름으로 찾고, 옛 이름을 지우지 않는다.
- **소속을 모르는 스타포스 줄**은 그 날짜에 등급을 가진 ID 들 가운데 **가장 높은 등급**으로 센다. 후보는 그 줄을
  받아 온 넥슨 계정의 ID 들이다.

## 스타포스 비용 ([[ADR-306]] 결정 5)

```
시도 비용 = floor(rounded × (100 − 이벤트) × (100 − MVP) / 10000)
최종      = 시도 비용 + (파괴 방지면 rounded × 200%)
```

이벤트 할인과 **곱한다.** 반올림은 할인보다 앞이고 MVP 할인 뒤에 다시 하지 않는다. 파괴 방지 추가분은 할인을 안 받는다.
**PC방 할인은 안 센다**(앱이 알 길이 없다). 식은 [cashbook.md](./cashbook.md) 의 강화 지출이 부른다.

## 수수료 기본값 ([[ADR-306]] 결정 6 ~ 10)

수수료 줄은 `수수료` 라벨 · **`자동` 체크박스** · 값 자리이고, 새 기록의 기본은 **켜짐**이다(시안 다).

- **켜면** 값 자리에 그 자리 캐릭터가 속한 ID 의, 그 기록 날짜의 **등급 명패와 요율**이 선다(`[명패] 3%`). 설명 줄은 없다.
  **등급 기록이 바뀌면 자동인 기록은 모두 다시 계산된다.** 기록 날짜에 등급이 없으면 일반(5%)이다.
  가계부 폼(아이템 판매 · 조각 정산 · 사냥)은 새 기록이 캐릭터가 빈 채로 열려, 캐릭터를 고르기 전에는 값 자리에 흐린 글자로
  `캐릭터를 선택해 주세요` 가 선다. 요율을 찾을 메이플 ID 가 아직 없어서다.
- **끄면** 세그먼트 `없음 · 3% · 5%`(파티 모달은 `0% · 3% · 5%`)에서 고른다. 고른 요율은 등급이 바뀌어도 그대로이고, 줄 아래에
  `직접 고른 요율이라 등급이 바뀌어도 그대로예요.` 가 선다.
- 자리는 아이템 판매 · 조각 정산 · 사냥 폼 둘의 조각 판매 · 드롭 판매가(판매 · 분배) · 파티 모달의 송금 수수료다.
  판매 분배금 계산기는 안 건드린다.
- 다시 계산해 요율이 달라진 기록이 있으면 `자동 수수료 기록 N건을 다시 계산했어요` 토스트가 뜬다.
- 아이템 판매는 **캐릭터를 골라야** 저장된다. 캐릭터 없이 적힌 옛 행은 대표 캐릭터의 ID 등급으로 계산한다.
- 송금 · 분배 수수료도 기본값은 **내 등급**이다. 받는 쪽이거나 파티원이 판 드롭이면 실제 요율이 다를 수 있어 사용자가 체크박스를 끄고 고른다.
- **기존 사용자의 첫 확인 화면에 체크박스로 일괄 적용을 묻는다**(따로 모달이 없다). 대상은 첫 시작 날짜 이후 수수료가 빈
  아이템 판매 · 조각 정산 · 사냥의 조각 몫 · 드롭 판매가다. 직거래 행도 붙으므로 사용자가 `없음` 으로 고친다.
- **일괄 적용과 다시 계산은 이어서 하는 작업이다**([[ADR-307]]). 0.3초 넘게 걸리면 진행률 모달이 서고, 앱이 중간에 닫히면
  다시 열 때 재진행 확인이 뜬다. 끝나면 완료 토스트(`지난 기록 N건에 수수료를 적용했어요` · `자동 수수료 기록 N건을 다시 계산했어요`)가 뜬다.

## 묻는 자리 ([[ADR-306]] 결정 11 · 12)

**추적 캐릭터가 속한 메이플 ID 중 등급 이력이 없는 것이 있으면 그 ID 들로 선택 흐름을 띄운다.** 이 규칙 하나가 온보딩
(캐릭터 설정의 `계속하기` 뒤) · 업데이트 뒤 기존 사용자 · 나중에 추적에 든 새 ID 를 함께 덮는다.

```
선택 흐름   [고르기] --다음--> [확인] --맞아요--> 저장
                ^                |
                +------수정------+

주간 흐름   [확인] --맞아요--> 끝
               |
              수정 --> [고르기(바꾼 ID 에만 시작 주 줄)] --다음--> [확인]
```

- **주간 확인**은 목요일 리셋으로 주가 바뀌면 뜬다. 확인 화면의 `앞으로 등급은 직접 바꿀게요` 를 켠 사용자에게는 안 뜬다.
- **설정**(`AppSettingsScreen`)의 `MVP 등급` 행이 **목록 페이지**(ID 마다 지금 등급 한 줄 · 매주 확인 스위치)를 열고,
  거기서 **ID 이력 상세 페이지**(연도로 끊은 타임라인 · 줄을 누르면 고치기)로 들어간다. 등급 변경과 기록 고치기는 **바텀시트**다. 지난 기간을 끼워 넣는 것은 이력 머리의 `+ 추가` 다. 시작 주와 종료 주를 고르고(기간 알약 하나, 달력 위 `시작 주 | 종료 주` 탭),
  종료 주 다음 주부터는 그 기간을 감싸던 등급이 다시 이어진다. 끝이 닫힌 기간이라 지난주까지만 고르고, 지금 기록 안의 지난 몇 주도
  된다(이번 주가 든 기간은 `등급 변경`). 첫 기록보다 앞선 기간이면 종료 뒤는 `등급 없음` 이다.
- **재는 때는 셋이다.** 앱이 열릴 때(온보딩의 `계속하기` 뒤 포함) · 앱으로 돌아올 때 · 캐릭터 관리에서 저장한 뒤. 모달은 바깥 탭이나
  뒤로가기로 안 닫힌다. 설정 목록에는 추적 캐릭터의 ID 가 먼저, 이력만 남은 ID 가 뒤에 선다. 기록 고치기의 주는 앞뒤 기록 사이다
  ([[ADR-306]] 구현).
