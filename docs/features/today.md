# today

앱을 켜면 처음 보이는 화면이다. 4열 격자 위에 위젯 열 개를 놓아, 지금 할 일과 이번 주 결과를 요약해
보여 준다. 왜 이렇게 만들었는지는 [[ADR-058]] 에 있다.

## 화면 구성

```
PageHeader            today · 갱신 시각 · 캐릭터 관리 버튼
[결산 안내 줄]         결산 중일 때만
[직접 완료 안내 줄]    서버가 직접 완료를 열었을 때만
[공지 배너]            새 앱 공지가 있을 때만
WidgetGrid            px-4 pt-2
```

세 줄은 격자 래퍼 밖에 전폭으로 놓인다. 보여 줄 내용이 없으면 아무것도 그리지 않는다. 갱신 시각 줄은
[[ADR-061]], 당김 인디케이터는 [[ADR-064]] 에 있다.

## 격자

| 값 | 크기 |
|---|---|
| 열 수 | 4 |
| 열 폭 | `(창폭 − 32 − 12×3) / 4`. 360dp 에서 73 |
| 행 높이 | 82 |
| 타일 간격 | 12 |
| 좌우 여백 | 16. 화면의 래퍼가 준다 |

## 기본 배치

```
(0,0)  4x1     대표 캐릭터
(0,1)  2x1     초기화 카운트다운      (2,1)  2x1  주간 결정석 판매 한도
(0,2)  4×auto  다음 파티 스케줄        보여 줄 회차가 없으면 빠진다
(0,3)  4×auto  계정 및 메이플 ID 공유 컨텐츠
(0,4)  4×auto  남은 스케줄
(0,5)  4×auto  주간 보스 수익
(0,6)  2x1     이번 주 최고가          (2,6)  2x1  가격 미입력
(0,7)  4x1     아이템 드롭 가뭄
```

`row` 는 `4×auto` 타일을 1행으로 치고 적는다. 실제 높이가 그보다 크면 그만큼 아래 타일이 내려간다.

위젯을 더할 때는 `types.ts` 의 `WidgetId`, `registry.ts` 의 한 줄, `layout.ts` 의 좌표 한 줄을 고친다.
셋이 어긋나면 `widget-registry.test.ts` 가 잡는다.

## 위젯

굵은 것이 기본 배치가 쓰는 크기다. 나머지 크기도 각 위젯이 그릴 수 있다.

| id | 내용 | 크기 | 누르면 | 값의 출처 |
|---|---|---|---|---|
| `representative-character` | 대표 캐릭터: 초상화 · 월드 엠블럼 · 닉네임 · 길드 · 레벨 · 직업 · EXP | **4x1** · 4x2 · 2x2 | 없음 | `character-basic-cache` · 캐릭터 선택 스토어 |
| `reset-countdown` | 일일 · 주간 · 월간 초기화까지 남은 시간. 일일은 초까지 1초마다 | **2x1** · 2x2 · 4x1 · 1x1 | 없음 | 뷰모델의 `resets` |
| `crystal-limit` | 월드별 주간 결정석 판매 한도. 링과 `N개 남음` | **2x1** · 4x1 · 2x2 · 1x1 | 보스 수익 탭 | 보스 수익 스토어 `currentWeekRows` |
| `next-party-schedule` | 시작 전인 가장 가까운 파티 회차 하나 | **4×auto** | 파티 스케줄 탭과 그 회차 상세 | 파티 스케줄 스토어 |
| `shared-contents` | 몬스터파크 · 메이플 유니온 · 에픽 던전의 공유 진행 | **4×auto** | 없음(`?` 팝오버만) | 컨텐츠 스케줄러 스토어 |
| `remaining-schedule` | 캐릭터별 남은 퀘스트 · 보스. 일간 · 주간 · 월간 탭 | **4×auto** | 없음(행마다 펼침) | 컨텐츠 · 보스 스케줄러 스토어 |
| `weekly-boss-profit` | 이번 주 총 수익, 결정석 · 아이템 비율 막대, 캐릭터 상위 셋(`1st` · `2nd` · `3rd`) | **4×auto** · 4x3 · 4x2 · 2x2 · 2x1 | 보스 수익 탭 | 보스 수익 스토어 `currentWeekRows` |
| `top-valuable-item` | 이번 주 기록한 판매가 중 가장 큰 아이템. 4x2 는 다섯까지 | **2x1** · 4x2 · 2x2 · 1x1 | 아이템 가격 입력 | 드롭 히스토리 스토어 |
| `unpriced-drops` | 가격을 아직 안 적은 드롭 건수. 2x2 는 이름 셋까지 | **2x1** · 2x2 · 1x1 | 아이템 가격 입력 | 드롭 히스토리 스토어 |
| `valuable-drought` | 아이템 드롭이 없던 주 수와 단계별 문구 | **4x1** · 2x2 · 2x1 | 없음 | 드롭 히스토리 스토어 `drought` |

### 빈 상태

| 위젯 | 그리는 것 |
|---|---|
| 대표 캐릭터 | 추적 캐릭터가 없을 때만 그 사실을 한 줄로 알린다 |
| 주간 보스 수익 | `0 메소` 와 `아직 이번 주 기록이 없습니다` |
| 이번 주 최고가 | `가격이 입력된 아이템이 없습니다` |
| 가격 미입력 | `전부 기록했습니다`. `기록하기 ›` 가 사라진다 |
| 주간 결정석 판매 한도 | `집계할 기록이 없습니다` |
| 아이템 드롭 가뭄 | `아직 아이템 드롭 기록이 없습니다` |
| 공유 컨텐츠 | 타일은 남고 빈 체크박스 줄이 보인다 |
| 다음 파티 스케줄 | 타일이 빠지고 아래가 올라온다 |

남은 스케줄은 캐릭터 단위 실패를 행에 표시한다. 조회할 수 없는 캐릭터는 `조회 불가`, 동기화가 실패한
캐릭터는 `동기화 실패` 배지를 달고 맨 아래로 간다. 주간 보스 수익은 조회 불가 캐릭터를
목록과 총액에서 모두 뺀다([[ADR-058]] 결정 28). 대표 캐릭터가 조회 불가면 EXP 대신 배지가 보인다.

### 남은 스케줄과 공유 컨텐츠

남은 스케줄은 공유 컨텐츠를 세지 않는다. 공유 컨텐츠는 캐릭터 수와 관계없이 항목마다 한 줄이다.
남은 스케줄의 행을 누르면 그 탭의 항목 이름이 타일 안에서 펼쳐지고, 한 번에 한 행만 열린다.

| | 남은 스케줄 | 공유 컨텐츠 |
|---|---|---|
| 기준 | 캐릭터마다 한 줄 | 항목마다 한 줄 |
| 탭 · 열 | 일간 · 주간 · 월간 탭([[ADR-058]] 결정 23) | 두 열([[ADR-058]] 결정 24) |
| 완료 | `CLEAR` 배지. 대상이 없던 캐릭터도 같다 | 체크박스와 취소선. 누를 수 없다 |
| 순서 | 실패는 맨 아래, 그 탭에 남은 개수가 많은 순, 같으면 캐릭터 관리 순서 | `sharedGroupOrder`. 줄 수가 가장 비슷해지는 곳에서 두 열로 나눈다 |
| 수치 | `퀘스트 N개` · `보스 N개`. 합계는 없다 | 진행 횟수 `n/max`. 에픽 던전 제목 줄에 주간 한도 `n/3` |
| 누르면 | 그 행이 펼쳐진다 | `?` 만 눌러 표시 기준을 본다 |

`?` 를 누르면 아래 두 줄이 뜬다.

```
에픽 던전과 메이플 유니온은 메이플 ID 기준입니다.
몬스터파크와 익스트림 몬스터파커는 마지막에 접속한 캐릭터 기준입니다.
```

## 조회

| 언제 | 무엇을 |
|---|---|
| 마운트 | 컨텐츠 스토어 `loadTrackedOcids()` |
| 포커스 | 드롭 기록(리비전이 바뀌었을 때만) · 직접 완료 · 공지 배너(기기) · 파티 스케줄 |
| 당김 | 컨텐츠 · 보스 · 보스 수익 스토어 `refresh()` · 드롭 기록 · 공지 배너(서버). 끝나면 대표 한 명의 프로필을 캐시에서 다시 읽는다 |
| 다음 KST 자정 | 화면을 다시 렌더한다 |

캐릭터 설정을 마치고 처음 들어와 캐시가 하나도 없는 동안에는, 동기화가 400ms 넘게 걸리면
`체크리스트를 불러오고 있어요` 모달과 진행률을 띄운다([[ADR-058]] 결정 26).

## 결산 안내 줄

넥슨이 스케줄러 기록을 결산하는 동안 머리글 바로 아래에 띠 한 줄이 보인다. 결산 중인지는 서버가 정하고,
스케줄러 데이터를 갱신할 때 함께 묻는다.

```
스케줄러 데이터를 결산 중입니다.
일부 데이터가 갱신되지 않을 수 있습니다.
```

| 누르면 | 무엇이 |
|---|---|
| `X` | 이번 결산 동안 줄을 닫는다. 다음 결산에는 다시 보인다 |
| 그 밖 | FAQ 시트 `스케줄러 결산` 이 열린다 |

가계부와 통계에도 같은 줄이 보이고, 둘째 줄만 `오늘 잡은 보스 수익은 결산이 끝난 뒤 반영됩니다.` 로
다르다. 한 화면에서 닫으면 세 화면 모두 그 결산 동안 보이지 않는다. 서버 값을 못 받아도 보이지 않는다.
