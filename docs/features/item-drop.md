# 아이템 드롭

보스에서 먹은 아이템을 기록하고 판매 가격을 매기는 기능이다. 보스 수익 화면의 보스 행에서 드롭 기록 시트를
열어 기록하고, 가격은 시트 안이나 `아이템 가격 입력` 화면에서 넣는다. 전 기간의 기록은 히스토리 화면에서 본다.
고가 아이템을 먹으면 전체화면 연출이 나오고, 보스 수익 카드에 골드 강조가 붙는다.

이렇게 만든 이유는 [[ADR-044]](기록 · 가격 · 히스토리)와 [[ADR-045]](연출 · 강조)에 있다. 기록한 금액이
보스 수익 합계에 들어가는 방식은 [[ADR-040]], 드롭 표 · 상자 표 · 드롭 아이템 표의 데이터 규약은
[[ADR-019]] 에 있다.

## 드롭 기록 시트

보스 수익 화면에서 보스 행을 누르면 열린다. 저장은 `추가 완료 · n개` 버튼이 하고, 그 보스 · 기간의 기록을 통째로
다시 쓴다.

| 부분 | 동작 |
|---|---|
| 머리 | 보스 이름, `드롭 연출` 토글, `획득한 아이템을 선택하세요`, 난이도 배지. 완료 행은 처치 난이도 배지 하나, 미완료 행은 난이도 버튼 여러 개 |
| 장비 · 소비 | 72px 타일을 분류마다 한 줄로 가로 스크롤. 누르면 기록, 다시 누르면 해제 |
| 고정 | 난이도별 상자에 그림과 `N개`. 고를 수 없다 |
| 상자 타일(점선 테두리) | 누르면 결과 고르기 화면. 결과를 고른 뒤 다시 누르면 해제 |
| 타일 표시 | 값을 매기면 내 몫 알약, 기록 안함이면 `기록 안함` 칩, 반지면 위쪽에 `lvN` |
| 확인 줄 | 고른 것이 있으면 늘 보인다. 문구는 아래 표. `가격 입력` · `가격 수정` 버튼 |

난이도 토글은 보여 주는 아이템만 바꾸고, 저장은 늘 행 난이도로 한다([[ADR-044]] 결정 2).

### 상자 결과 고르기

| 상자 | 고르는 것 |
|---|---|
| 백옥 · 흑옥의 보스 반지 상자 | 반지 11종 중 하나, 그다음 레벨 |
| 녹옥 · 홍옥의 보스 반지 상자 | 반지 11종 또는 `기타`, 그다음 레벨 |
| 생명의 보스 반지 상자 | 반지 9종 또는 생명의 연마석. 연마석은 레벨 없이 기록 |
| 혼돈 · 메이린의 칠흑 장신구 상자 | 장신구 7종 중 하나. 레벨 없음 |

레벨 범위는 상자마다 `drop-boxes.json` 이 정한다. `이 결과로 기록` 을 누르면 시트로 돌아온다.

### 확인 줄 문구

| 상태 | 제목 | 아래 줄 | 버튼 |
|---|---|---|---|
| 한 건, 안 매김 | `{이름}이(가) 선택되었습니다` | `판매 가격을 입력할까요?` | `가격 입력` |
| 여러 건, 안 매김 | `{이름} 외 n건이 선택되었습니다` | `판매 가격을 입력할까요?` | `가격 입력` |
| 일부 매김 | `{이름}의 가격을 입력했습니다` 또는 `{이름} 외 n건의 가격을 입력했습니다` | `미입력 n건 · 판매 가격을 입력할까요?` | `가격 입력` |
| 다 정함 | `모든 아이템의 가격을 입력했습니다` | `가격 입력 n건 · 기록 안함 n건` | `가격 수정` |

조사는 이름의 받침을 보고 하나만 쓴다.

## 가격 입력 카드

시트의 `가격 입력` 과 가격 입력 화면의 행 · `미입력 n건 이어서 입력` 이 연다. OS 숫자 키보드 위에 뜬다.

| 부분 | 내용 |
|---|---|
| 머리 | 아이템 그림 · 아이템 이름 · `캐릭터 · 보스` |
| 금액 | 자릿수 전체 표기, 아래에 억 · 만 환산. 칩 `+100만 +1000만 +1억 +10억 +100억` |
| 분배 | `기본`(인원) · `비율`. 값을 안 매긴 드롭의 처음 값은 처치 기록 → 그 기간만 고친 값 → 보스 관리의 파티 설정 → 1인 순서로 찾은 인원과 결정석 비율([[ADR-076]]) |
| 수수료 | 판매 · 분배 수수료와 `자동`([[ADR-050]]) |
| 버튼 | `기록 안함` · `이전` · 확인 |

확인 버튼 글자는 입력할 것이 하나면 `닫기` · `완료`, 중간이면 `다음(n/m)` · `저장 후 다음(n/m)`, 마지막이면
`n개 입력 완료` 다. 칸이 비었으면 아무것도 쓰지 않고 넘어간다([[ADR-044]] 결정 11).

## 아이템 가격 입력 화면

| 부분 | 동작 |
|---|---|
| 입구 | 보스 수익 주간 탭의 떠 있는 버튼(보는 주를 넘긴다), today 의 `이번 주 최고가` · `가격 미입력` 타일(넘기는 값이 없어 이번 주) |
| 기간 이동 | `‹` `›` 로 한 칸씩. 끝에서는 잠긴다 |
| 요약 | `이 주 아이템 수익`, 내 몫 합계, 오른쪽에 가격을 입력한 건수 `n건` |
| 이어서 입력 | 미입력이 있으면 요약 아래 `미입력 n건 이어서 입력`. 미입력 기록만 차례로 연다 |
| 목록 | 캐릭터별 카드. 줄마다 그림 · 이름 · 수량 · 난이도 · 보스 · 나눈 몫, 오른쪽 알약 |
| 알약 | 내 몫(채움) · `기록 안함`(회색) · `입력`(점선) |
| 줄 누르기 | 그 기록 하나로 가격 카드 |

주 키로 열면 그 주에 해당하는 월간 보스(검은 마법사)의 드롭도 함께 보여 준다. 이 화면은 기간 키 목록으로 앞뒤 두 달치를
한 번에 읽어 두고, 기간을 옮기면 다시 읽지 않는다([[ADR-044]] 결정 18). 저장에 실패하면 `가격을 저장하지 못했습니다`
토스트를 띄운다.

### 떠 있는 버튼

보스 수익 주간 탭의 오른쪽 아래에만 나온다. 지름 56, 오른쪽 16, 하단바 위 12 로 가계부의 ＋ 와 같은 위치다. 원 안에서
고통의 근원 · 거대한 공포 · 컴플리트 언더컨트롤 그림이 2초씩 번갈아 나오고, 넘어갈 때 흐려진다.
오른쪽 위 빨간 배지는 보고 있는 주의 미입력 건수이고, 10건부터 `9+` 다.

## 히스토리

`/profit/drops` 화면이고 제목은 `히스토리` 다. 지금은 앱 안에서 이 화면으로 가는 진입점이 없다([[ADR-044]] 결정 14).

| 부분 | 동작 |
|---|---|
| 맨 위 요약 | 마지막 고가 드롭 이후 지난 주 수에 따른 단풍잎과 문구, 아래 줄 `마지막 에픽 빔! {기간} · {아이템}`. 고가 기록이 없으면 안 그린다 |
| 기간 구분 | 양옆 선 사이의 기간 라벨과 그 아래 날짜 범위. 최신 기간이 위 |
| 기록 한 줄 | `{캐릭터}님이 {보스}({난이도})에서 {아이템}을(를) 획득하였습니다.` 상자 결과는 `{상자}를 열어` 를 넣는다 |
| 고가 기록 | 아이템 이름에 골드 배경과 그림, 줄 글자색이 진하다 |
| 빈 상태 | `아직 기록된 드롭이 없습니다`, `보스 수익으로` 버튼(뒤로 가기) |
| 실패 | `히스토리를 불러오지 못했습니다`, `다시 시도` |

미획득 단계는 0주 · 1주 · 2주 · 3주 · 4주 이상의 다섯이고, 단계마다 문구 여러 개 중 하나를 화면을 열 때 고른다
([[ADR-044]] 결정 16).

## 고가 드롭 연출

드롭 기록 시트에서 고가 아이템을 새로 기록하면 뜬다. `드롭 연출` 토글이 꺼져 있으면 뜨지 않는다.

| 순서 | 화면 |
|---|---|
| 1 | 어두운 배경 위에 버스트 16장(22.5fps) |
| 2 | 버스트 8번째 장에서 아이템이 튀어나오고, 빛기둥 `pre` 8장(21fps) 뒤 `loop` 24장(17.25fps) 반복 |
| 3 | 화면을 누르면 `end` 7장(18fps) 뒤 닫힘. 안드로이드 뒤로가기는 바로 닫힘 |

아래쪽에 `화면을 터치하면 닫힙니다` 가 적힌다. 장 위치와 배율, 깜빡임을 막는 방식은 [[ADR-045]] 에 있다.

## 고가 드롭 강조

| 위치 | 표시 |
|---|---|
| 보스 수익 캐릭터 카드 | 폰 기울기를 따라 면 위를 떠다니는 오로라 빛(펼치면 본문 바탕까지, 움직임 줄이기에서는 정지), 머리 오른쪽 위 아이템 표시(그림 셋과 나머지 `+N`), 오로라 금액 |
| 보스 수익 보스 행 | 고가 아이템을 먹은 행 칸에 한 단계 약한 빛 |
| 보스 수익 총 수익 카드 | 그 기간 전체의 고가 드롭 표시 |
| 히스토리 | 고가 기록 줄의 아이템 이름 골드 배경 |

완료한 보스 행의 기록만 강조 대상이다.

## 저장

| 저장소 | 내용 |
|---|---|
| SQLite `boss_drops` | 드롭 기록 한 건이 한 행. 묶음은 기간 행(`period_id`)이고 차례는 `drop_index`, 행 식별자는 uuid `id` 다. 아이템 key · 상자 key · 반지 레벨, 상태(`record_status`) · 금액 · 가격을 매긴 시각 · 분배 방식 · 인원 · 비율 · 수수료. 가격부터 수수료까지는 `completed` 일 때만 있다. 캐릭터 · 보스 · 난이도 · 기간 · 월드는 기간 행(`boss_party_periods`)과 조합 행(`boss_parties`)에서 읽는다. 이름은 저장하지 않고 key 로 찾는다 |
| Preferences `dropEffect` | 연출 켜기(`on`) · 끄기(`off`). 없으면 켜짐 |

기록이 지워지는 경우는 넷이다. 시트에서 고칠 때, 완료 행에서 처치 난이도로 못 얻는 기록을 정리할 때([[ADR-044]] 결정 8),
처치 난이도 확정 이관에서 빠질 때([[ADR-040]]), 잡지 않은 보스에 남았을 때다. 마지막 경우에는
`잡지 않은 보스의 아이템 기록 n건을 정리했어요` 토스트가 뜬다([[ADR-044]] 결정 17).

가격 칸의 뜻은 [[ADR-044]] 결정 9 · 10 에 있다. 테이블 구조는 [[ADR-078]], 옛 데이터 이관은 [[ADR-007]] 에 있다.
