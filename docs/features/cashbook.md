# 가계부

수입과 지출을 날짜별로 모아 달력으로 보여 주고, 손으로 적고 고치는 화면이다. 수익·지출 그룹의 둘째 하위 탭이다.
달력과 기간은 [[ADR-046]], 저장과 금액 기준은 [[ADR-047]], 입력 시트는 [[ADR-048]], 사냥 수입은 [[ADR-049]], 목록과 기간 이동 줄의
생김새는 [[ADR-095]] 에, 솔 에르다 조각 정산을 합친 사냥 전리품 판매는 [[ADR-117]], 헥사 매트릭스 · 강화 레벨 기억 · 헥사 강화에 보관한 조각을 쓰는 것은 [[ADR-137]], 강화 건을 가계부에서 빼는 것은 [[ADR-160]] 에 그렇게 만든 이유가 있다.

## 무엇을 보여 주나

| 원천 | 저장 위치 | 여기서 고치나 |
|---|---|---|
| 손으로 적은 지출 | `cashbook_entries`(`entry_type = 'spend'`) | 예 |
| 손으로 적은 수입 | `cashbook_entries`(`entry_type = 'income'`) | 예 |
| 보스 결정석 | `boss_party_periods` 의 `cleared` 행(보스 수익 탭이 적는다) | 아니오. 누르면 그날 잡은 보스가 펼쳐진다([[ADR-047]] 결정 13). 가계부에서 빼지 않는다. 결정석을 팔지 않은 처치는 보스 수익 탭의 분배 방식 `제외` 로, 주간 결정석 판매 한도를 넘긴 처치는 판정으로 0 메소가 되고, 0 이 된 결정석은 이 줄의 목록과 `n마리` 에서 빠진다([[ADR-038]] 결정 12 · [[ADR-042]] 결정 15) |
| 아이템 판매 | `boss_drops`(보스 수익 탭이 적는다) | 아니오. 누르면 판 아이템이 펼쳐진다([[ADR-047]] 결정 13) |
| 강화 사용 내역 | `enhancement_totals`(넥슨 API 에서 받아 합계로 저장한다) | 아니오. 누르면 장비별 금액이 펼쳐지고, 스타포스는 그날 첫 성과 끝 성도 선다([[ADR-100]] 결정 8). 편집 상태에서 장비 한 줄씩 가계부에서 뺀다([[ADR-160]]) |

합계는 메소 기준이다. 메포는 시세로 메소로 바꿔 더하고, 캐시는 더하지 않고 하루 목록에서 `원` 으로 따로 적는다.
지출의 메포는 메소마켓 수수료(기록에 적힌 요율, 지금 1%)를 뗀 시세로 바꾼다. 메포를 쓰려면 메소를 팔아야 하고,
메소마켓은 메소를 팔 때 받는 메포에서 수수료를 떼기 때문이다. 수입의 메포는 메소를 사는 쪽이라 수수료가 없다([[ADR-047]] 결정 17).

강화 합계는 받을 때 비용을 매겨 저장하므로, 계산 코드나 비용 표를 고쳐도 지난 합계는 저절로 바뀌지 않는다. 그 기간은
환경 변수 `EXPO_PUBLIC_ENHANCEMENT_RECOMPUTE` 로 다시 매기기 요청을 걸어 넥슨 API 에서 다시 받는다([[ADR-100]] 결정 4).

## 화면

```
가계부                        [주간 | 월간]
(결산 안내 줄)
        ‹   이번 주   ›  »
        8월 20일 ~ 8월 26일
[ 순 수익 +5,700만 메소     수익 +8,500만 ]
[                          지출 −2,800만 ]
  목  금  토  일  월  화  수
  (칸마다 수익 줄 · 지출 줄 · 열지도)
8월 21일 (목)
  수입 / 지출
  줄 목록
                                     [＋]
```

| 부분 | 동작 |
|---|---|
| 주간 · 월간 | 들어오면 주간이다. 주간은 목요일에 시작하는 리셋 주, 월간은 일요일에 시작하는 달력 월이다 |
| 기간 이동 | 공용 `PeriodStepper`. control-track 캡슐 위에 surface 원 화살표가 얹히고, 이름(`이번 주` · `8월 3주차`)과 날짜가 가운데에 한 줄로 선다([[ADR-095]] 결정 4). 올해가 아니면 주간 이름 앞에 연도가 붙는다. 옮기면 고른 날이 그 기간의 첫날로 간다 |
| `다음` · `»` | 이번 주 · 이번 달에서 꺼진다. `»` 는 보는 기간과 고른 날을 오늘로 옮긴다([[ADR-041]]) |
| `이전` | 조회 한도(1년 6개월 전 그 달, 주간은 그 달 1일이 들어 있는 주)에서 꺼진다 |
| 기간 합계 | 격자가 그린 칸을 그대로 더한다. 순 수익을 크게 적고 수익 · 지출을 그 옆에 작게 적는다 |
| 날짜 칸 | 수익 · 지출 두 줄을 줄여 적고, 0 이면 비운다. 바탕은 그날 수익에 비례해 네 단계로 칠한다(기준은 그 달) |
| 격자의 앞뒤 달 칸 | 날짜만 흐리게 적는다. 누르면 그 날이 골라지고, 그 달이 한도 안이면 보는 달도 옮긴다 |
| 고른 날 | 날짜 제목 아래 수입 · 지출 합계 카드 한 줄과, 줄마다 테두리 없는 카드인 목록([[ADR-095]] 결정 1 · 2). 읽는 동안에는 둘 다 비워 둔다 |
| 당겨서 새로고침 | 동기화 · 처치 날짜 채우기 · 강화 사용 내역 받기를 데이터 공급자에 요청한다 |
| 다른 화면이 기록을 쓸 때 | 표의 판이 올라 `ledgerDays` 쿼리가 무효화되고, 보고 있으면 그 자리에서 다시 읽는다([[ADR-046]] 결정 15) |
| KST 자정 | 보는 기간과 고른 날이 오늘로 옮긴다([[ADR-046]] 결정 9) |
| 결산 안내 줄 | 넥슨이 결산 중이면 머리 아래에 나온다. 둘째 줄이 `오늘 잡은 보스 수익은 결산이 끝난 뒤 반영됩니다.` 다([[ADR-058]]) |
| 갱신 시각 | 제목 아래에 실시간 데이터를 받은 시각이 나온다. 스케줄 회차와 오늘이 포함된 강화 조회 중 늦은 쪽이다([[ADR-061]] 결정 9) |

| 줄 | 첫 줄 | 둘째 줄 | 누르면 |

| 보스 드롭 판매 | `캐릭터 · 보스 드롭 판매` | `n건` | 판 아이템이 펼쳐진다 |

손으로 적은 줄의 `캐릭터` 자리에는 메이플 ID 기록이면 그 ID 의 이름(`메이플ID-da9b2f21`)이 선다([[ADR-101]] 결정 8). 캐릭터도 메이플 ID 도 없는 옛 기록은 제목만 선다([[ADR-161]] 결정 6).
헥사 매트릭스와 아이템 구매는 그날 같은 캐릭터의 기록이 둘 이상이면 한 줄로 합친다. 헥사 스킬과 헥사 스탯도 한 줄에 든다.
기록이 하나면 위 표의 헥사 매트릭스 · 아이템 구매 줄 그대로이고, 캐릭터가 없는 옛 기록은 합치지 않는다. 합친 줄은 묶인 기록 가운데 먼저 적은 기록의 자리에
선다. 줄 왼쪽 그림은 헥사 매트릭스가 갈래 카드의 헥사 매트릭스 그림이다. 아이템 구매는 기록 금액이 큰 기록부터 보아 그림이
있는 첫 아이템의 그림이고, 금액이 같으면 먼저 적은 기록이 앞이다. 모두 그림이 없으면 `ShoppingCartIcon` 이다. 펼친 칸은
기록마다 하나이고 적은 순이다. 칸에는 그 기록의 그림 · 이름 · 둘째 줄(레벨이나 수량) · 금액 · `›` 가 서고, 그림이 없는 기록은
이름부터 선다([[ADR-047]] 결정 18). 합치는 것은 하루 목록뿐이고 today · 통계는 그대로다.
제목 · 이름 · 단위는 서버 표가 들어 관리 화면에서 고친다. 갈래마다의 규칙은 [[ADR-096]] 결정 3 에 있다. 줄 왼쪽 표식은
게임 그림이고, 그림이 없으면 수입 `ProfitIcon` · 지출 `ShoppingCartIcon` 이다.
펼친 내용은 그 줄의 카드 안 card-inset 칸에 서고, 결정석 줄의 보스는 원형 초상 아래에 난이도 배지가 붙는다([[ADR-095]] 결정 3). 합친 줄은 기록 하나가 card-inset 칸 하나다.
한 번에 한 줄만 펼쳐지고, 날이나 기간을 바꾸면 접힌다.

### 가계부에서 빼기

강화 줄은 펼친 판 머리 오른쪽에 `편집` 이 있다. 누르면 `완료` 로 바뀌고, 장비 줄을 누를 수 있다. 누른 줄은 그
자리에서 가계부에서 빠지고 바로 저장되며, 한 번 더 누르면 되돌아온다. 뺀 줄은 편집 상태가 아니어도 흐리게 보인다.
전부 뺀 줄은 줄째 흐리고 금액이 0 이다. 뺀 건은 가계부 · today 이번 주 수익 · 통계에서 함께 빠진다.

결정석 줄과 보스 드롭 판매 줄은 가계부에서 뺄 수 없다. 결정석을 팔지 않은 처치는 보스 수익 탭에서 분배 방식을
`제외` 로 고르면 0 메소가 되고 결정석 줄에서 빠진다([[ADR-038]] 결정 12). 드롭은 보스 수익 탭에서 가격을 지운다([[ADR-160]]).

## 입력

떠 있는 ＋ 를 누르면 `수입` · `지출` 이 펼쳐지고, 고르면 시트의 첫 화면에서 분류를 고른다.

today 빠른 이동의 `사냥` · `전리품 판매` 칸으로 오면 분류를 고르는 화면 없이 그 분류의 수입 폼이 바로 열린다. 가계부는 오늘이 든 주로 열리고 시트도 오늘 날짜로 열린다. 분류를 다시 고르는 누르개는 없다([[ADR-089]] 결정 9).

| 시트 | 분류 | 폼 |
|---|---|---|

- 분류와 항목 타일은 테두리 없는 카드 안에 하나씩 `card-inset` 칸으로 선다(항목 격자는 묶음 줄마다 카드 하나). 폼의 줄은 테두리 없는 카드 하나 안에 줄마다 `card-inset` 칸으로 서고, 큰 숫자는 그 카드 아래에 선다([[ADR-048]] 결정 2 · 4).
- 캐릭터 칸은 수입 기타 · 지출 컨텐츠 · 지출 이벤트·BM · 지출 기타에서 캐릭터나 메이플 ID 를, 지출 버프 · 주문서 · 심볼 강화 · 아이템 구매에서 캐릭터를 골라야 저장된다. 이 분류들에는 `선택 안함` 이 없고, 새 기록은 빈 칸으로 열린다. 메이플 ID 보기는 캐릭터 뒤에 메이플 ID 이름 글자로 선다. 캐릭터 없이 적힌 옛 기록은 메이플 ID 를 고를 수 있는 분류에서 그 넥슨 계정의 메이플 ID 가 하나뿐이면 그 ID 로 옮기고, 남은 기록은 대표 캐릭터에게 붙인다. 메이플 ID 분류는 대표 캐릭터의 메이플 ID 에, 캐릭터 분류는 대표 캐릭터에 붙는다([[ADR-161]] 결정 1 · 5, [[ADR-101]] 결정 28 · 29).
- 큰 숫자는 언제나 합계이고 직접 입력할 수 없다. 금액은 각 칸을 누르면 뜨는 입력 카드에서 입력한다.
- 아이템 판매의 판매 대금 · 단가, 아이템 구매의 구매 비용 · 단가, 지출 항목의 개당 가격은 입력 카드에서 단위(`기본` · `만` · `억`)를 골라 소수점까지 친다. 고른 단위는 칸마다 기기에 기억된다([[ADR-082]] 결정 13).
- 아이템 구매 · 판매의 아이템 칸은 입력 카드 안 목록에서 고른다. 찾기 규칙과 목록은 인벤토리 넣기와 같고, 목록에 없는 이름도 친
  그대로 받는다. 종류 칸은 목록에 없는 이름을 쳤을 때만 서고, 목록에서 고르면 아이템의 종류로 적는다. 고른 아이템은 key 로 저장하고 이름은 아이템 표에서 찾는다([[ADR-048]] 결정 18).
- 특수스킬 반지는 목록에서 `리스트레인트 링 Lv.4` 처럼 레벨마다 한 줄로 서고, 고른 줄의 레벨이 기록에 남는다.
- 구매의 `인벤토리에 보관` 을 켜면 산 수량이 구매 캐릭터의 메이플 ID · 월드 인벤토리에 들어간다. 체크는 늘 서고 꺼진 채 시작하며, 목록에서 고른 아이템 · 캐릭터 · 그 캐릭터의 메이플 ID 를 갖추기 전에는 흐리게 눌리지 않는다. 보관한 구매를 고치거나 지우면 인벤토리도
  따라 바뀌고, 이미 판 것보다 적게 만드는 저장은 되돌아간다.
- 날짜는 시트 머리에서 바꾼다. 조회 한도의 첫날부터 오늘까지이고, 심볼 강화는 2026-09-17 부터다.
- 고칠 때는 적을 때 쓴 시트가 그 기록으로 채워져 열린다. 분류와 항목은 바꿀 수 없고, 삭제는 그 시트의 바닥 줄에 있다.
- 사냥 전리품 판매의 아이템은 서버 전리품 표가 정한다. 열린 이벤트가 없으면 세그먼트에서 `이벤트` 칸이 빠진다. 여러 아이템을 한 번에 치고, 개수를 친 아이템만 아이템마다 한 줄로 한 번에 저장한다. 조각 칸은 `솔 에르다 조각` 갈래로 저장해 옛 정산 기록과 같다. 서버 갈래 표에 `사냥 전리품 판매` 줄이 없으면 그 카드 대신 `솔 에르다 조각` 카드가 서고, 누르면 조각 칸 하나뿐인 같은 폼이 열린다([[ADR-117]]).
- 심볼 강화 · 헥사 스킬의 강화 전은 그 캐릭터의 기억한 레벨로 선다. 기억은 캐릭터 관리에서 추적을 시작할 때 넥슨 값으로 채우고, 기록을 저장 · 고치기 · 지우기 할 때 옮긴다. 폼에서는 넥슨을 부르지 않고, 기억이 비어 있을 때만 한 번 받아 채운다([[ADR-137]] 결정 3).
- 헥사 매트릭스의 지출은 개당 가격을 곱할 개수 × 개당 가격이다. 곱할 개수는 필요 조각에서 교환 불가를 빼고, `보관 중인 조각 사용` 을 켜고 지출 체크(`보관 중인 조각도 지출로 기록하기`)를 끄면 보관에서 가져온 개수도 뺀다. 곱할 개수가 없으면 개당 가격 입력이 꺼지고 0 메소로 저장한다. 개당 가격은 빈 칸으로 열린다. 헥사 코어는 캐릭터 직업의 실제 코어를 종류별로 묶어 고른다([[ADR-137]] 결정 17).
- 보관은 강화한 캐릭터의 메이플 ID · 월드의 기타 조각(인벤토리에 넣은 조각)이 먼저다. 그다음은 강화한 캐릭터, 그다음은 같은 메이플 ID · 같은 월드의 캐릭터를 캐릭터 관리 순서로 가져온다([[ADR-209]] 결정 8). 메이플 ID 나 월드를 모르면 자신의 보관만 쓴다. 필요 조각 칸은 줄인 수와 취소선 원래 수를 보이고, 어느 캐릭터의 보관인지는 보이지 않는다. 새 폼의 두 체크는 직전에 새 헥사 기록을 저장한 때의 상태로 열린다([[ADR-137]] 결정 13 ~ 16).
- 조각의 `보유` 는 그 날과 뒤 모든 날의 남은 개수 가운데 가장 작은 값이다. 정산 폼 · 사냥 전리품 판매의 캐릭터 목록 · 헥사 폼이 같은 값을 읽는다. 조각 장부를 바꾸는 저장(사냥 · 정산 · 헥사)은 모두 장부가 0 아래로 내려가는지 검사를 거친다([[ADR-049]] 결정 11 · 17).
- 사냥 기록은 뒤의 정산 · 헥사 강화가 가져간 개수 아래로 줄일 수 없다. 고치거나 지워 조각이 모자라게 되면, 그 조각을 가져간 헥사 강화를 고친 날짜에 가까운 것부터 강화한 캐릭터의 메이플 ID · 월드의 기타 조각, 그다음 같은 메이플 ID · 같은 월드의 다른 캐릭터 보관으로 옮긴다. 가져온 개수는 그대로라 금액이 안 바뀌고 창도 뜨지 않는다. 정산은 옮기지 않는다. 옮기고도 모자라면 저장하지 않고 `조각을 사용한 기록이 있어 고칠 수 없습니다`(삭제는 `조각을 사용한 기록이 있어 지울 수 없습니다`) 토스트를 띄운다. 수정으로 연 사냥 기록의 조각 개수 카드는 설명 줄에 `최소 n개` 를 보이고, 그보다 적게 치면 `입력` 이 안 눌린다. 조각 가격을 채웠거나 캐릭터 · 날짜를 바꾸면 최소 개수는 서지 않는다([[ADR-049]] 결정 17).
- `주간 보스 수입 이전` 의 체크 박스는 시트 날짜가 든 주의 보내는 캐릭터 결정석 몫(보스 수익 주간 탭 카드의 결정석 몫과 같은 값)을 금액 칸에 채운다. 금액을 손으로 고치면 꺼지고, 수정으로 열면 꺼진 채 저장한 금액이 선다.
- `주간 보스 수입 이전` · `메소마켓 환전 수수료` 로 적은 기록은 `기타` 줄로 서고, 누르면 적을 때 쓴 그 시트가 열린다. 메소마켓 환전 수수료는 수입으로 저장된 기록도 지출 시트의 그 폼으로 연다.
- 저장이 실패하면 시트를 닫지 않고 토스트를 띄운다.
