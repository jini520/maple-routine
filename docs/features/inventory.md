# 인벤토리

팔지 않고 가진 아이템을 게임 인벤토리처럼 칸으로 모아 보는 화면이다. 수입·지출 그룹의 네 번째 하위 탭이다. 칸에는 미입력 보스 드롭,
보관한 솔 에르다 조각, 다른 경로로 얻어 넣은 아이템이 선다. 칸을 누르면 팔거나 기록을 고친다. 왜 이렇게 만들었는지는 [[ADR-209]] 에 있다.

## 화면

| 자리 | 내용 |
|---|---|
| 머리 | `인벤토리` 와 FAQ 물음표 |
| 탭 | `전체` · `장비` · `소비` · `기타` · `캐시`. 판에 붙고, 고른 탭은 판과 같은 색이다 |
| 격자 | 한 줄 다섯 칸. 아이템이 없는 자리도 빈 칸으로 채워 하단바 위까지 이어진다 |
| 칸 | 아이템 그림, 왼쪽 아래 개수(장비는 없음), 왼쪽 위 얼굴, 오른쪽 위 경로 글자(솔 에르다 조각의 `사냥` · `기타`), 오른쪽 아래 특수스킬 반지의 레벨 배지(`lv4`) |
| 떠 있는 `+` | 아이템 넣기 시트를 연다 |

- 보스 드롭은 드롭 하나가 칸 하나이고 얼굴은 드롭을 가진 캐릭터다. 기간을 가리지 않고 가격을 안 매긴 드롭이 모두 선다.
- 사냥 조각은 한 칸이고 보유가 1개 이상인 캐릭터의 보유만 더한다. 얼굴이 없다.
- 넣은 아이템은 메이플 ID · 월드마다 칸이 따로 선다. 얼굴은 그 메이플 ID · 월드의 대표 캐릭터다. 앱의 대표 캐릭터가 거기 있으면
  그 캐릭터, 없으면 조회 가능한 캐릭터 가운데 레벨이 가장 높은 캐릭터, 모두 조회 불가면 레벨이 가장 높은 캐릭터다.
- 칸의 종류는 아이템 목록(`items` 칸)의 종류다. 반지 상자에서 나온 반지는 드롭 기록에 소비로 남아 있지만 장비 탭에 선다. 목록에 없는
  아이템만 드롭 표의 종류나 저장된 종류를 쓴다.
- 장비는 칸 · 판매 시트 · 삭제 확인 어디에도 수량을 적지 않는다.
- 칸의 차례는 종류 차례이고, 같은 종류 안에서는 처음 나온 아이템이 앞이다. 같은 아이템의 칸은 붙어 선다.

## 칸을 누르면

| 칸 | 팝오버 글자 | 누르면 |
|---|---|---|
| 보스 드롭 | `판매` · `기록 안함` | 판매는 가격 입력 카드. 기록 안함은 확인 없이 바로 `skipped` 로 적는다 |
| 사냥 조각 | `판매` | 가계부 `사냥 전리품 판매` 시트 |
| 넣은 아이템 · 기타 조각 | `판매` · `수정` · `삭제` | 판매 시트 · 수정 시트 · 삭제 확인. 넣은 장비는 `수정` 이 없다 |

- 판매 시트는 아이템 블록(그림 · 이름 · 메이플 ID · 남은 개수) 아래에 단가 · 수량(장비는 판매 대금), 수수료, 판 날짜를 받는다.
  저장하면 그 메이플 ID 의 `item_sale` 기록이 한 줄 생기고 판 날짜의 가계부에 선다. 남은 것보다 많이는 팔 수 없다.
- 판 기록은 이름 칸을 비우고 `item_key` 만 적는다. 가계부 줄과 통계는 아이템 표에서 이름을 찾는다(`recordedItemNameOf`).
  서버에서 이름을 고치면 옛 기록도 새 이름으로 선다.
- 수정 시트는 그 칸에 지금 남은 개수만 고친다. 판 기록은 그대로다. 가계부 구매로 보관한 개수는 줄이지 못하고, 그 구매 기록을 고쳐 바꾼다.
- 삭제는 확인 창(배지 없는 `NoticeModal`)을 거쳐 남은 것만 지운다. 판 · 헥사 강화에 쓴 기록은 그대로다. 가계부 구매로 보관한 것은 보관이
  풀려 그 구매 기록의 보관 스위치가 꺼지고, 지출 기록은 남는다.

## 아이템 넣기

- 메이플 ID · 월드, 아이템, 수량(장비는 없음) 차례다. 날짜는 받지 않는다. 종류는 고르지 않고 고른 아이템의 종류로 적는다.
- 수량 칸은 아이템을 고른 뒤 그 아이템이 소비 · 기타 · 캐시일 때만 선다.
- 특수스킬 반지는 목록에서 `리스트레인트 링 Lv.4` · `Lv.3` · `Lv.2` · `Lv.1` 처럼 레벨마다 한 줄로 서고, 고른 줄의 레벨이 칸의 배지로 선다.
- `메이플 ID · 월드` 칸의 보기는 두 줄이다. 첫 줄은 메이플 ID 이름, 둘째 줄은 월드 아이콘과 그 메이플 ID · 월드의 대표 캐릭터
  이름이다. 같은 메이플 ID 라도 월드가 다르면 보기가 따로 선다.
- 아이템 칸을 누르면 입력 카드가 뜨고, 친 글자가 이름 안에 차례대로 들어 있는 아이템이 종류를 가리지 않고 카드 안 목록에 선다. 한 줄을
  누르면 그 아이템으로 정한다. 목록에 없는 이름은 넣을 수 없다.
- 같은 메이플 ID · 월드에 같은 아이템을 다시 넣으면 그 줄의 개수가 는다. 장비는 줄이 하나 더 생긴다.
- 넣을 수 있는 아이템은 게임 데이터 `items` 칸에서 상자 · 데스티니 무기 · 제네시스 무기 · 아스트라 보조무기(보조무기 가운데 key 가
  `astra_` 로 시작하는 것)를 뺀 전부다. 가계부 아이템 고르기(#912)도 같은 것을 뺀다.
  장신구는 `장비` 로 적는다. 게임에서도 장비 탭에 든다.

## 저장

- 가계부 `아이템 구매` 에서 `인벤토리에 보관` 을 켠 아이템도 그 캐릭터의 메이플 ID · 월드 칸에 더해진다([[ADR-048]] 결정 18).
- `inventory_items` 한 줄이 메이플 ID · 월드의 아이템 하나다(장비는 하나가 한 줄). 특수스킬 반지는 `ring_level` 에 레벨을 든다. 남은 개수는 저장하지 않는다. 넣은 개수에
  그 줄을 가리키는 구매 품목의 수량을 더하고 판매 품목(`cashbook_entry_items.inventory_item_id`)의 수량을 빼고, 기타 조각은 그 메이플 ID · 월드의 조각 사용
  (`cashbook_entry_fragment_uses` 의 `other` 줄)을 뺀다.
- 헥사 강화는 강화한 캐릭터의 메이플 ID · 월드의 기타 조각을 먼저 쓰고, 그다음 사냥 조각을 쓴다.
- 판매 · 헥사 강화가 남은 개수를 0 아래로 내리면 저장이 되돌아간다(`InventoryShortageError`). 조각 장부 검사와 같은 자리에서 본다.
- 데이터 삭제의 가계부 그룹이 이 표도 지운다.
