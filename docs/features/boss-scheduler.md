# 보스 스케줄러

주간 보스와 월간 보스의 진행 상태를 캐릭터별로 보여 주는 화면과, 무엇을 추적할지 고르고 파티 인원을 정하는
보스 관리 화면이다. 보스 스케줄러는 스케줄러 그룹의 `보스` 하위 탭이고, 보스 관리는 설정에서 여는 하위
페이지다. 왜 이렇게 만들었는지는 아래 ADR 에 있다.

| ADR | 다루는 것 |
|---|---|
| [[ADR-036]] | 어떤 보스를 어떤 순서로 보여 주는지, 필터, 빈 상태, 보스 관리 화면의 목록 |
| [[ADR-037]] | 완료 판정, 주간 12마리 한도와 마감, 직접 완료 |
| [[ADR-038]] | 파티 인원과 결정석 분배 비율 |
| [[ADR-039]] | 보스 카드의 생김새와 일러스트 크롭 |
| [[ADR-093]] | 보스 관리 화면 리디자인과 난이도 고르개 통일 |

## 보스 스케줄러 화면

헤더 제목 줄 오른쪽에 솔로 · 파티 필터가 있고, 그 아래에 갱신 시각이 있다. 내용은 초상화 레일 아래에 고른
캐릭터의 보스 카드 목록이다. 목록을 아래로 당기면 넥슨에서 다시 받아 온다. 들어올 때 · 포커스 · 복귀의 자동 조회는
컨텐츠 스케줄러와 같다([[ADR-142]] 결정 5). 직접 완료는 포커스마다 기록 판과 기간을 견줘 바뀌었을 때만 다시 읽는다.

| 부분 | 보여 주는 것 |
|---|---|
| 초상화 레일 | 추적 캐릭터. 진행 링은 주간 하나이고 완료와 마감을 함께 센다 |
| `월간` 섹션 | 월간 보스 카드(지금은 검은 마법사). 카드가 없으면 제목도 없다 |
| `주간` 섹션 | 주간 보스 카드. 제목 오른쪽에 시즌 배지(챌린저스 월드)와 `n/12` |
| 솔로 · 파티 필터 | `전체` · `솔로` · `파티`. 두 섹션에 함께 걸린다 |

### 어떤 보스가 나오는가

| 모드 | 카드로 나오는 보스 |
|---|---|
| 자동 | 게임에 등록한 난이도. 등록이 없으면 완료한 난이도 |
| 수동 | 앱에서 추적하는 보스 · 난이도. 완료는 동기화 결과에서 찾는다 |

두 모드 모두 챌린저스가 아닌 월드의 캐릭터에는 시즌 보스를 보여 주지 않고, 유효 기간이 끝난 보스도 보여 주지
않는다. 순서는 보스 표 차례 → 난이도이고 완료해도 바뀌지 않는다. 일간 보스는 다루지 않는다.

### 보스 카드

| 위치 | 내용 |
|---|---|
| 왼쪽 | 난이도 배지, 보스 이름, 2인 이상이면 `n인` 배지 |
| 오른쪽 | `진행 불가` · `마감` · `완료` 중 하나. 아직 안 잡았으면 비어 있다 |
| 배경 | 보스 일러스트가 왼쪽에서 오른쪽으로 녹아든다 |

카드를 누르면 파티 모달이 열린다. 보스 표에 없는 보스는 API 이름으로 나오고 누를 수 없다.

### 빈 상태

| 경우 | 문구 | 버튼 |
|---|---|---|
| 추적 캐릭터 0명 | `표시할 캐릭터가 없습니다` | `캐릭터 선택하기`: 설정 탭을 캐릭터 고르기가 열린 채 연다 |
| 수동 모드, 보스 없음 | `추적할 보스가 없습니다` | `보스 관리`: 보스 관리 화면을 연다 |
| 자동 모드, 보스 없음 | `등록된 보스가 없습니다` | 없음 |
| 필터가 전부 가림 | `이 조건에 해당하는 보스가 없습니다` | `필터 초기화`: 필터를 `전체` 로 |
| 조회할 수 없는 캐릭터 | 조회 불가 안내 | 캐릭터 관리로 이동 |

## 보스 관리 화면

`←` 가 있고 하단바가 없는 하위 페이지다. 여는 곳은 설정 `캐릭터 · 테마` 카드의 `보스 관리` 줄, 보스 수익
헤더의 `보스 관리` 버튼, 보스 스케줄러의 수동 모드 빈 상태 버튼이다. 초상화 레일에는 진행 링이 없고, 두께 2 의 빈 링만 선다.

목록은 지금 기간에 고를 수 있는 보스이고, 스케줄러와 같이 `월간` 위 `주간` 아래다. 시즌 보스는 챌린저스 월드
캐릭터일 때만 나온다. 섹션 제목은 레귤러 글자이고, 수동 모드의 `주간` 제목 오른쪽에 추적 수 `n/12` 배지가 붙는다.

보스 행은 테두리 없는 카드 하나다. 초상화 오른쪽에 보스 이름을 두고, 그 아래 줄 왼쪽에 난이도 고르개, 오른쪽 끝에
파티 요약(`변경` · 배지)을 둔다.

| 모드 | 행에서 하는 일 |
|---|---|
| 수동 | 카드를 눌러 추적을 켜고 끈다. 추적 중인 행은 초상화에 링과 체크가 붙고 고르개와 파티 요약이 선다. 추적하지 않는 행은 이름만 흐린 글자로 선다 |
| 자동 | 추적 없이 파티만 정한다. 모든 행에 고르개와 파티 요약이 선다 |

자동 모드는 레일 아래에 `모든 보스 보기` 카드 줄이 있다. 설명은 `끄면 스케줄러에 등록한 보스만 보여요` 이고 기본은 꺼짐이다.
꺼져 있으면 등록한 보스만 나온다. 등록이 하나도 없으면 꺼져 있어도 전체다.

수동 모드에서 주간 보스를 12개 고르면 나머지 주간 보스 행의 내용이 흐려진다. 흐린 행을 누르면
`주간 12개를 모두 선택했어요` 안내가 뜬다. 시즌 보스와 월간 보스는 계속 고를 수 있다.

## 파티 모달

보스 카드, 보스 관리 화면의 `변경`, 보스 수익 행의 `변경` 이 같은 모달을 연다. 값은 `적용` 을 눌러야
저장되고, 닫으면 버린다.

| 부분 | 내용 |
|---|---|
| 위쪽 | 주기, 보스 이름, 난이도(보스 카드에서 열면 고르개, 다른 곳에서 열면 배지), 오른쪽 일러스트 띠, 닫기 |
| `분배 방식` | `기본` · `비율` |
| `기본` 일 때 | `파티 인원` 스테퍼와 `최대 n명` 배지 |
| `비율` 일 때 | `결정석` 비율 카드(내 비율 · 합)와 송금 수수료(`자동` 또는 `0%` · `3%` · `5%`) |
| 아래 | `적용` |

어디서 열었는지에 따라 저장하는 곳이 다르다.

| 연 곳 | 저장하는 곳 |
|---|---|
| 보스 카드 · 보스 관리 | 파티 설정(`boss_parties` 의 분배 칸). 다음 기록부터 쓰인다 |
| 보스 수익 완료 행 | 그 기록 한 건(`boss_party_periods` 의 `cleared` 행) |
| 보스 수익 미완료 행 | 그 기간만 쓰는 값(`boss_party_periods` 의 `open` 행). 처치하면 그 기록의 값이 된다 |

세 곳 모두 같은 분배 칸(`split_mode` · `party_size` · `my_share` · `shares_total` · `split_fee_percent` · `split_fee_auto`)을
쓴다([[ADR-078]]).

결정석 내 몫을 세는 식은 [[ADR-038]] 결정 7 에 있다.

## 직접 완료

넥슨이 완료를 주지 않는 보스는 보스 수익 화면에서 사용자가 완료로 적을 수 있다. 어떤 보스를 열지는 서버가
정한다(`GET /v1/manual-completion`). 이 화면에는 적는 버튼이 없지만, 적은 완료는 카드의 `완료` 배지, `n/12`,
마감, 레일의 링에 자동 기록과 똑같이 반영된다. 보스 수익에서 적고 돌아오면 화면이 포커스를 받을 때 다시 읽는다.

열린 보스가 있으면 today 헤더에 `직접 완료할 수 있는 보스가 있어요.` 줄이 뜬다. 누르면 FAQ 가 열리고, 닫으면
그 주 동안 뜨지 않는다. 자세한 규칙은 [[ADR-037]] 결정 8 ~ 15 에 있다.
