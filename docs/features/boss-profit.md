# 보스 수익

처치한 보스의 결정석과 드롭 판매 수익을 캐릭터별로 보여 주는 화면이다. 수익·지출 그룹의 첫째 하위 탭이고,
주간 · 월간으로 지난 기간을 오가며 볼 수 있다. 여기서 쓴 기록(`boss_profit_records`)은 가계부 · 통계 ·
today 도 읽는다. 왜 이렇게 만들었는지는 [[ADR-040]] (기록) · [[ADR-041]] (기간) · [[ADR-042]] (금액 표시) ·
[[ADR-043]] (화면 배치)에 있다.

이 문서에 없는 것:

- 스케줄러가 어떤 보스를 보여 주는지, 시즌 보스 판정은 [[ADR-036]] 에 있다. 보스 수익의 행을 고르는 규칙은 [[ADR-040]] 결정 17, 월간 보스가 들어가는 주는 [[ADR-041]] 결정 12 에 있다.
- 주간 12마리 · 월드 90개 한도와 직접 완료는 [[ADR-037]] 에 있다.
- 파티 인원 · 비율과 결정석 몫을 나누는 식은 [[ADR-038]] 에 있다.
- 드롭 기록 · 드롭 가격 입력 · 아이템 가격 입력 화면은 [[ADR-044]], 고가 드롭 강조는 [[ADR-045]] 에 있다.
- 넥슨 조회와 창 동기화는 [[ADR-021]], 기간 상태 다섯은 [[ADR-022]], 결정석 가격표는 [[ADR-019]] 에 있다.
- 잡지 않은 보스에 남은 드롭을 지우는 규칙은 [[ADR-044]] 에 있다.

## 금액

| 금액 | 어떻게 세나 |
|---|---|
| 보스 행 | 결정석 몫(`payoutMeso`) + 그 행의 드롭 판매 몫. 미완료 행은 `미완료`, 가격을 모르면 `가격 미확정` 배지 |
| 캐릭터 카드 | 행의 합. 월간 탭은 월간 보스 행 + 주차 합계 |
| 총 수익 | 카드 금액의 합 |
| 주차 합계(월간 탭) | 그 주의 주간 보스 결정석 + 드롭. 월간 보스 몫은 넣지 않는다 |

- 결정석 몫은 기록할 때 정해 `payout_meso` 에 남고, 드롭 몫은 읽을 때 더한다.
- 미완료 행의 드롭, 가격을 안 적은 드롭, `기록 안함` 드롭은 금액에 넣지 않는다.
- 자세한 기준은 [[ADR-042]] 결정 1 에 있다.

## 기록

| 언제 | 무엇을 |
|---|---|
| 동기화에서 완료가 확인될 때 | 그 기간 · 난이도로 한 줄을 적는다. 파티 인원은 그 기간 값 → 파티 설정 → 1 순서로 정한다 |
| 동기화를 건너뛴 진입 | 캐시가 지금 기간이면 캐시 단계에서 적는다 |
| 처치 난이도가 정해질 때 | 다른 난이도 키에 적은 드롭을 확정 난이도로 옮긴다 |
| 창 동기화가 끝난 뒤 · 가계부에 들어올 때 | 날짜 없는 기록의 처치 날짜를 찾는다 |
| 월드 리프한 기간에 같은 처치가 두 캐릭터에 생겼을 때 | 옛 캐릭터 기록을 지우고 드롭을 새 기록으로 합친다 |

기록하지 않는 경우와 그 이유는 [[ADR-040]] 결정 2 에 있다.

## 화면

```
보스 수익                         보스 관리 [주간|월간]
                      hh:mm:ss 기준
[  ] [‹] 이번 주 / 10월 16일 ~ 10월 22일 [›] [>>]
이번 주 총 수익 [결정석 칩]                 [고가 드롭]
[메소] 12,345,678,900 메소          [자세히 보기 ⌄]
──────────────────────────────────────────
[캐릭터 카드]
[캐릭터 카드]
                                     (아이템 가격 입력 버튼)
```

| 항목 | 보여 주는 것 | 누르면 |
|---|---|---|
| `보스 관리` | 글자 버튼 | 보스 관리 화면(`BossManage`)을 연다 |
| 주간/월간 | 세그먼트 | 그 탭의 지금 기간으로 간다 |
| `‹` `›` | 이전 · 다음 화살표 | 기록이 있는 가장 가까운 기간으로 간다 |
| `>>` | 겹화살표. 지금 기간이면 흐리다 | 지금 기간으로 간다 |
| 결정석 칩 | 주간 탭 `34 / 90 · 1개`, 월간 탭 `3개` | 월드가 둘 이상이면 월드별로 펼친다 |
| `자세히 보기` | | 총 수익 내역 상자(결정석 · 아이템 · 합계, 상위 10건) |
| 캐릭터 카드 헤더 | 초상과 처치 진행 링 · 이름 · 금액 | 펼친다. 아이템이 섞인 금액을 누르면 카드 내역 상자(상위 5건) |
| 보스 행(주간) | 난이도 · 보스 · 드롭 아이콘 · 파티 배지 · 금액 | 드롭 시트, 파티 변경, 직접 완료, 금액은 행 내역 상자 |
| 월간 보스 열람 행(월간) | `n인 · n월 n일 완료` · 금액 | 아이템이 섞이면 금액이 내역 상자를 연다. 그 밖에는 고칠 수 없다 |
| 주차 줄(월간) | 주차 이름 · 날짜 · 금액 또는 상태 | `failed` 면 `다시 시도`. 아이템이 섞이면 금액이 내역 상자를 연다 |
| 아이템 가격 입력 버튼(주간) | 칠흑 아이템 그림 · 미입력 건수 배지 | 보고 있는 주로 아이템 가격 입력 화면을 연다 |

- 목록을 아래로 당기면 `LedgerLayer` 가 실시간 조회와 창 동기화를 다시 돌린다(`reload(['live', 'window'])`).
  어느 기간에서든 되고, 보던 기간을 떠나지 않는다. 당김 동작은 [[ADR-064]] 에 있다.
- 제목 아래의 `hh:mm:ss 기준` 은 실시간 데이터를 마지막으로 받은 시각이다. 지난 기간을 봐도 바뀌지 않는다.
- 동기화 전체 실패와 일부 캐릭터 실패는 토스트로 알린다. 일부 실패는 이름 대신 인원 수를 적는다.
- 추적 캐릭터가 없으면 `추적 중인 캐릭터가 없습니다` 와 `캐릭터 선택하러 가기`(설정 탭으로 가며 선택 창을
  연다)를 보인다. 추적 목록을 아직 안 읽었으면(`null`) 이 화면을 그리지 않는다.
- 카드 순서는 사용자가 캐릭터 관리에서 정한 추적 순서다. 추적에서 뺐지만 기록이 있는 캐릭터의 카드도 보인다.
- 수익·지출 그룹을 떠나면 주간 · 이번 주로 돌아온다.

## 기간 상태

지난 기간은 기록에서만 그린다. 기록이 없을 때 무엇을 보이는지는 그 기간의 상태가 정한다.

| 상태 | 카드가 없을 때 | 주차 줄(월간) |
|---|---|---|
| `recorded` | | 금액 |
| `confirmedEmpty` | `아직 처치한 보스가 없습니다` | `0 메소` |
| `notCollected` | `아직 처치한 보스가 없습니다`. 집계 전인 날이 있으면 `0 메소` 요약 | `집계 전` |
| `outOfRange` | `아직 처치한 보스가 없습니다` | `조회 불가` |
| `failed` | `이 기간을 불러오지 못했습니다` · `다시 시도` | `다시 시도` |

진행 중인 주는 `진행 중`, 아직 안 온 주는 `예정` 이다. 추적하지 않는 캐릭터의 이번 주와 앞으로의 주는
`조회 불가` 다. 판정 순서는 [[ADR-041]] 결정 5 · 7 에 있다.
