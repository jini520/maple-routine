# 거래 내역

아이템을 사고판 기록을 한 목록에 모아 보는 하위 페이지다. 가계부 머리의 `거래 내역` 버튼이 연다. 판매 · 구매, 기간, 캐릭터,
아이템 이름으로 좁혀 찾고, 기록을 누르면 읽기 전용 상세 시트가 열린다. 왜 이렇게 만들었는지는 [[ADR-228]] 에 있다.

## 관련 소스

| 파일 | 하는 일 |
|---|---|
| `app/trade-history/TradeHistoryScreen.tsx` | 머리 · 판매/구매 세그먼트 · 필터 카드 · 날짜 제목으로 묶은 목록 |
| `app/trade-history/TradeDetailSheet.tsx` | 읽기 전용 상세 시트와 `거래로 이동` |
| `features/trade-history/` | 기록 모으기 · 줄 세우기 · 필터 · 쿼리. 가계부와 같은 저장소 읽기(`storage/income.ts` · `storage/spend.ts` · `storage/boss-drops.ts`)를 거친다 |
| `components/molecules/SearchField/` | 아이템 검색 칸. 돋보기와 입력이 선 `card-inset` 칸 |
| `components/molecules/DateSelect/` | 기간 칸의 날짜 알약, 상세 시트의 화살표 없는 날짜 알약 |
| `app/cashbook/sheet-fields.tsx` 의 `SelectRow` | 캐릭터 칸. 가계부 시트의 캐릭터 칸과 같다 |
| `app/inventory/InventorySaleSheet.tsx` 의 `InventoryItemBlock` | 상세 시트 맨 위의 아이템 블록 |
| `app/boss-profit/drop-price-card.ts` | 보스 드롭 판매의 `거래로 이동` 이 여는 가격 입력 카드 |
| `navigation/routes.ts` · `navigation/RootNavigator.tsx` | 하위 페이지 `TradeHistory`, 가계부 라우트의 열 기록 파라미터 |

## 담는 기록

| 기록 | 판매 · 구매 | 날짜 |
|---|---|---|
| 아이템 판매(인벤토리 판매 포함) | 판매 | 적은 날 |
| 사냥 전리품 판매(조각 · 소비 · 이벤트, 옛 솔 에르다 조각 정산 포함) | 판매 | 적은 날 |
| 사냥 기록의 조각 판매(조각 가격을 넣은 사냥 기록) | 판매 | 사냥한 날 |
| 보스 드롭 판매 | 판매 | 처치한 날 |
| 아이템 구매 | 구매 | 적은 날 |
| 지출 항목 구매(주문서 · 버프 · 이벤트·BM · 컨텐츠) | 구매 | 적은 날 |

- 수입 · 지출의 `기타` 는 담지 않는다. `주간 보스 수입 이전` · `메소마켓 환전 수수료` 도 `기타` 로 저장된다.
- 기록 하나가 한 줄이다. 가계부 하루 목록처럼 아이템 구매를 합치지 않는다.

## 화면

```
←  거래 내역                 [전체 | 판매 | 구매]
   (갱신 시각)
[ 기간        [8월 14일 ⌄] ~ [11월 14일 ⌄] ]
[ 캐릭터                       전체      ⌄ ]
[ 🔍 아이템 검색                            ]
11월 14일 (토)
  판매  [그림] 주문의 흔적 3,000개          ›
              단풍잎               +9,975만
              [메모] 작업장 남은 흔적 정리
```

| 부분 | 동작 |
|---|---|
| 판매 · 구매 | 머리 오른쪽 `Segment`(`lg`) `전체 · 판매 · 구매`. 처음은 `전체` |
| 기간 | 카드 맨 위 칸. 날짜 알약 둘이 시작일 · 끝일을 고르는 달력을 연다. 처음은 오늘부터 3개월 전 같은 날까지이고, 고를 수 있는 날은 가계부 시트와 같은 조회 한도(`historyFloorDateKey`)부터 오늘까지다. 시작일은 끝일보다 늦을 수 없다 |
| 캐릭터 | 드롭다운. 처음은 `전체`. 거래 기록이 있는 캐릭터만 캐릭터 관리 순서로 서고, 메이플 ID 기록은 그 뒤에 메이플 ID 이름으로 선다 |
| 아이템 검색 | 치는 대로 좁힌다. 고른 아이템 이름과 직접 친 아이템 이름만 찾고, 지출 항목 이름과 메모는 찾지 않는다 |
| 목록 | 최신 날짜가 위이고 날짜 제목 아래에 그날 기록이 모인다. 같은 날은 나중에 적은 기록이 위다. 올해가 아닌 날짜는 연도가 붙는다 |

네 필터는 함께 걸린다. 페이지를 열 때마다 처음 값으로 선다.

## 목록의 줄

| 부분 | 내용 |
|---|---|
| 맨 왼쪽 | `판매`(수입 색) · `구매`(지출 색) 글자 |
| 윗줄 | 아이템 그림 · 아이템 이름 · 개수. 장비 · 장신구는 개수가 없다. 이름이 길면 개수는 남고 이름만 말줄임한다 |
| 둘째 줄 | 캐릭터(메이플 ID 기록은 메이플 ID 이름)와 오른쪽 끝의 금액 |
| 메모 칸 | 메모가 있으면 본문 전체가 줄 카드 안 `card-inset` 칸에 선다 |

- 그림과 금액은 가계부 하루 목록 줄과 같다. 보스 드롭의 금액은 분배와 수수료를 뗀 몫이다.
- 지출 항목 구매의 윗줄은 하루 목록 둘째 줄과 같은 `항목 이름 n단위` 다.
- 사냥 기록의 조각 판매는 윗줄이 `솔 에르다 조각 n개` 이고, 금액은 판 조각의 몫(개수 × 개당 가격)만이다.

## 상세 시트

줄을 누르면 열린다. 기록을 고치거나 지우는 버튼은 없다.

| 부분 | 내용 |
|---|---|
| 머리 | 기록 이름(`아이템 판매` 등)과 화살표 없는 날짜 알약. 날짜는 누를 수 없다 |
| 칸 카드 | 아이템 블록(그림 · 이름 · 개수, 아래 줄은 캐릭터), 그 아래 그 기록을 적은 폼의 금액 칸(단가 · 수수료 등). 칸은 누를 수 없다 |
| 금액 | `AmountFigure` |
| 메모 | 메모가 있을 때만 `메모` 라벨과 본문 |
| 버튼 | `거래로 이동` |

## 거래로 이동

| 기록 | 가는 곳 |
|---|---|
| 손으로 적은 기록 | 가계부 탭으로 가서 그 날짜를 고르고, 그 기록의 수정 시트를 연다 |
| 사냥 기록의 조각 판매 | 가계부 그 날짜에서 그 사냥 기록의 수정 시트 |
| 보스 드롭 판매 | 가계부 그 날짜에서 그 드롭 한 건의 가격 입력 카드 |

고친 뒤에는 가계부에 남는다. 거래 내역 페이지는 스택에서 빠진다. 다시 열면 고친 기록이 반영되어 있다.
