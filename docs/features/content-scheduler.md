# 컨텐츠 스케줄러

추적 중인 캐릭터마다 일간 · 주간 컨텐츠의 진행 상태를 보여 주는 화면이다. 수동 모드에서 무엇을 추적할지 고르는
컨텐츠 관리 화면과, 컨텐츠 · 보스 스케줄러가 함께 쓰는 자동 · 수동 추적 모드도 여기서 다룬다. 왜 이렇게 만들었는지는
아래 ADR 에 있다.

| ADR | 다루는 것 |
|---|---|
| [[ADR-032]] | 응답을 캐릭터 캐시 · 월드 원장 · 계정 원장과 합치는 규칙, 지난 날짜로 채우기 |
| [[ADR-033]] | 컨텐츠 카드 종류, 완료 판정, 요구 레벨, 에픽 던전 주간 한도, 길드 잠금 |
| [[ADR-034]] | 자동 · 수동 추적 모드, 추적 목록, 시드, 컨텐츠 관리 화면, 탭 상태 |
| [[ADR-035]] | 레일 아래 간격과 첫 카드의 높이 |

추적 캐릭터를 고르는 일은 [[ADR-028]], 고른 캐릭터를 화면끼리 함께 쓰는 일은 [[ADR-030]], 초상화 레일은 [[ADR-031]],
API 동기화와 진입 재조회는 [[ADR-021]], 실패를 알리는 방법은 [[ADR-022]] 가 다룬다. 보스 쪽은 보스 스케줄러 문서에 있다.

## 스케줄러 화면

| 위치 | 내용 |
|---|---|
| 헤더 | 제목 `컨텐츠 스케줄러`, 아래에 데이터 갱신 시각. 오른쪽에 수동 모드일 때만 `컨텐츠 관리`, 그 옆에 `일간 · 주간` 탭 |
| 초상화 레일 | 추적 캐릭터를 캐릭터 관리에서 정한 순서로 보여 준다. 링 왼쪽 반은 일간, 오른쪽 반은 주간 진행률이다 |
| 카드 목록 | 고른 캐릭터의 지금 탭 항목. 카드 종류는 [[ADR-033]] 결정 3 · 4 |

- 탭은 스토어가 기억하고 있어서 다른 탭에 다녀와도 유지된다. 앱을 다시 켜면 일간이다.
- 목록을 아래로 당기면 추적 캐릭터 전원을 다시 조회한다. 헤더에는 새로고침 버튼이 없다.
- 화면에 들어올 때는 `loadTrackedOcids` 가 조회하는데, 이번 실행에서 이미 동기화했고 모든 캐릭터 캐시가 10분 안이면
  조회하지 않는다([[ADR-021]]).
- 조회 중이어도 캐시가 있으면 캐시로 먼저 그린다. 캐시도 없으면 `불러오고 있어요` 로딩 카드를 그린다.

### 상태별 화면

| 상태 | 화면 |
|---|---|
| 추적 목록을 아직 안 읽음(`trackedOcids` 가 `null`) | 빈 상태로 판단하지 않는다 |
| 추적 캐릭터가 0명 | `표시할 캐릭터가 없습니다`. `캐릭터 선택하기` 를 누르면 설정 탭이 캐릭터 선택 창을 연 채로 열린다 |
| 고른 캐릭터를 조회할 수 없음 | 카드 대신 `CharacterUnavailableNotice` 와 캐릭터 관리로 가는 버튼 |
| 수동 모드, 탭에 추적 항목 없음 | `추적할 일간(주간) 컨텐츠가 없습니다` 와 `컨텐츠 관리` 버튼 |
| 자동 모드, 탭에 등록 항목 없음 | `등록된 일간(주간) 컨텐츠가 없습니다`. 등록은 게임에서 하므로 버튼이 없다. 데이터가 낡았으면(`isStale`) 빈 상태를 그리지 않는다 |
| 동기화 실패 | 토스트([[ADR-022]]). 캐릭터별 실패도 토스트다. 조회 불가만 토스트 대신 위의 안내를 띄운다 |

## 무엇을 보여 주나

| 모드 | 보이는 항목 | 값 |
|---|---|---|
| 자동 | 게임 스케줄러에 등록한 항목 | 병합 결과 |
| 수동 | 추적 목록에 있는 항목 | 동기화 결과에서 찾고, 없으면 컨텐츠 표 기본값 |

- 두 모드 모두 컨텐츠 관리 화면과 같은 순서로 보여 준다.
- 수동 모드는 시작 기간(`from`) 전인 컨텐츠를 그리지 않는다. 추적 목록에서 지우지는 않아서 기간이 되면 다시 보인다.
  자동 모드는 게임에 등록된 것만 보여 주므로 따로 거르지 않는다.
- 요구 레벨에 못 미치는 항목은 `진행 불가` 배지를 달고 링에서 빠진다.
- 에픽 던전은 주 3회를 채우면 남은 던전에 `마감` 이 붙는다.

## 응답을 합치는 방법

응답을 받을 때마다 아래 순서로 합쳐 `schedulerCache:{ocid}` 에 저장한다. 자세한 규칙은 [[ADR-032]] 에 있다.

1. 캐릭터 범위 항목은 이번 응답을 쓰고, 응답에서 빠진 항목은 캐시에서 진행값만 0 으로 되돌려 채운다.
2. 월드 · 계정 공유 항목은 섹션이 비지 않은 응답일 때 원장에 쓴다. 등록 여부는 원장의 `active` 를 쓰고, 한 번 참이면
   계속 참이다. 메이플 유니온 두 항목만 이번 응답의 등록 여부를 쓴다.
3. 결과에 없는 공유 항목은 원장에서 채운다. 원장이 지난 리셋 구간의 값이면 진행값만 0 으로 되돌린다.
4. 그래도 비어 있는 섹션이 있으면 어제부터 13일 동안의 응답으로 채운다.

## 컨텐츠 관리 화면

수동 모드 전용이고 루트 스택에 push 된다. 자동 모드에서는 바로 뒤로 간다.

| 위치 | 내용 |
|---|---|
| 헤더 | 뒤로 버튼과 `컨텐츠 관리` |
| 초상화 레일 | 링 없이 이름과 레벨만. 여기서 고른 캐릭터가 스케줄러에도 그대로 고른 캐릭터다 |
| 탭 | 들어올 때의 스케줄러 탭으로 시작한다. 여기서 바꿔도 스케줄러 탭은 그대로다 |
| 목록 | 컨텐츠 표 전체를 카테고리로 묶은 체크리스트. 묶음 제목에 `추적 수/전체 수`, 행 오른쪽에 참고 배지 |

- 행을 누르면 추적을 켜고 끄며 바로 저장한다. 실패하면 `추적 목록을 저장하지 못했습니다` 토스트가 뜬다.
- 시작 기간 전인 컨텐츠는 목록에 없다.
- 길드에 가입하지 않은 캐릭터는 길드 컨텐츠를 고를 수 없고, 행 위에 `길드 가입 시 진행 가능` 이 뜬다. 이미 추적 중인
  항목은 끌 수 있다.
- 주간 카테고리 순서는 에픽 던전, 몬스터파크, 길드, 아케인리버 지역 퀘스트, 주간 퀘스트, 무릉도장, 메이플 유니온이다.

## 추적 모드

모드는 설정의 `스케줄 관리 방법` 에서 바꾼다. 옵션을 고르고 `적용` 을 눌러야 바뀐다.

| 때 | 하는 일 |
|---|---|
| 자동 → 수동 적용 | 추적 캐릭터 전원의 추적 목록을 그때의 게임 등록으로 채우고, 끝나면 컨텐츠 · 보스 · 보스 수익 탭을 다시 읽는다 |
| 수동 모드에서 추적 캐릭터를 더함 | 더한 캐릭터만 추적 목록을 채운다 |
| 수동 → 자동 적용 | 추적 목록을 지우지 않는다 |
