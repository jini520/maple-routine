> **범위**: 제품 목표·대상 사용자·플랫폼 전제·MVP 제외 범위·전역 미해결 질문. 개별 기능의 요구사항은 각 `features/*.md`, 화면 톤·디자인은 [design-system.md](./design-system.md) 참고.
> **관련 소스**: 없음(제품 문서). **관련 ADR**: [[ADR-001]] [[ADR-002]] [[ADR-003]] [[ADR-007]] [[ADR-013]]. **관련 문서**: [architecture.md](./architecture.md), [nexon-api.md](./nexon-api.md).

## 목표
메이플스토리 플레이어가 일간/주간 콘텐츠 소진, 사냥 중 스킬 재사용 타이밍, 주간 보스 수익, 물욕템 드랍 기록을 캐릭터/계정 단위로 한 곳에서 관리하도록 돕는다. 매일 켜서 체크하는 "도구"로서의 대시보드다.

## 사용자
- 일간·주간 콘텐츠를 여러 캐릭터(본캐+부캐)에 걸쳐 반복 수행하는 유저
- 주간 보스 파티 수익을 캐릭터별/계정별로 파악하고 싶은 유저
- 장시간 사냥 중 솔 야누스 등 주기적 스킬 재사용을 놓치지 않아야 하는 유저

## 플랫폼
웹앱으로 개발 후 Android/iOS에 WebView 하이브리드 앱으로 패키징. 프레임워크는 Capacitor([[ADR-001]]) + Vite/React SPA([[ADR-002]]). 백그라운드 알림/상시 타이머가 핵심이라 순수 웹(PWA)만으로는 요구사항을 충족하지 못한다고 보고 네이티브 래핑을 전제로 한다.

**전제 조건 ([[ADR-007]])**: 스케줄러 기능을 쓰려면 사용자가 (1) 게임 클라이언트의 "스케줄러"에 추적할 퀘스트·보스를 먼저 등록하고, (2) `openapi.nexon.com`에서 본인이 발급한 개인 API 키를 앱에 입력해야 한다. NEXON Open ID(OAuth)는 "메이플스토리 파트너스" 승인이 필요한 제한 기능이라 사용하지 않으며, 앱 자체의 회원가입/계정 시스템도 두지 않는다. 온보딩 상세는 [features/onboarding.md](../features/onboarding.md).

## 디자인 방향
- 캐주얼하고 친근한 게임 컴패니언 톤. 마케팅 랜딩 느낌 배제, 정보 밀도 높은 리스트/카드 UI.
- **라이트 테마가 기본**. 다크는 보조 팔레트로 유지. 직업 고유 컬러 기반 다중 테마 지원 예정([[ADR-009]]).
- 세부 룰(색·컴포넌트·테마 토큰)은 [design-system.md](./design-system.md), [features/theme.md](../features/theme.md).

## MVP 제외 사항
- 앱 자체 회원가입/계정 시스템 및 클라우드 동기화 — 기록은 기기 로컬 저장 전용([[ADR-003]]). Nexon 개인 API 키도 기기에만 저장.
- NEXON Open ID(OAuth) 로그인 — 파트너스 승인 필요([[ADR-007]]).
- 별도 공개 웹 서비스(랜딩/정보 사이트) — 보류. Capacitor 앱(WebView) 우선.
- 메소/결정 시세 자동 연동 — 가격표는 정적 데이터 기반.
- 파티원 매칭·랭킹 등 소셜/커뮤니티 기능.
- 다국어 지원(한국어 우선).
- 데미지/스타포스 계산기 등 스케줄링·기록 이외 유틸리티.

## 전역 미해결 질문
- **상업적 이용 제한**: 넥슨 승낙 없이 API 데이터를 영리 목적으로 이용 불가(이용약관 제6조⑥). 현재 무료 개인용 MVP라 문제 없으나 유료화/광고 고려 시 별도 확인 필요.
- **직업 기반 테마 매핑**: 테마 이름과 실제 직업(전직)의 매핑, 테마 단위(대분류/세부 전직)는 미정 → [features/theme.md](../features/theme.md).
- **게임 수치 미확정분**: 일부 드랍 수량·시세가 `(추정)` 상태 → [game-data.md](./game-data.md), [features/item-drop.md](../features/item-drop.md).
