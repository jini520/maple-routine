# 제품

메이플 루틴이 무엇을 하는 앱이고 누구를 위한 것인지 정리한 문서다. 기능마다 자세한 내용은 각 기능 문서에 있다.

## 목표

메이플스토리 플레이어가 여러 캐릭터의 일간 · 주간 컨텐츠 진행, 보스 처치와 결정석 수익, 드롭 아이템, 메소
수입과 지출을 한 앱에서 확인하고 기록하게 한다. 매일 켜서 확인하는 도구라서, 첫 화면은 오늘 할 일과 이번 주
수익을 요약한 위젯 화면이다.

## 사용자

- 본캐와 부캐 여러 캐릭터로 일간 · 주간 컨텐츠를 반복하는 사람
- 주간 · 월간 보스를 파티로 잡고, 캐릭터별 · 기간별 수익을 알고 싶은 사람
- 보스 드롭과 강화 지출까지 포함해 메소 흐름을 기록하고 싶은 사람

## 기능

하단바 그룹 다섯 개로 나뉜다(`navigation/bar-groups.ts`).

| 그룹 | 화면 | 하는 일 | 문서 |
|---|---|---|---|
| today | 위젯 격자 | 대표 캐릭터 · 남은 컨텐츠 · 이번 주 보스 수익 · 결정석 판매 한도 · 리셋까지 남은 시간 · 다음 파티 약속 | `features/today.md` |
| 스케줄러 | 파티 스케줄 | 파티 보스 약속을 요일별로 적고 시작 전에 로컬 알림 | `features/party-appointments.md` |
| | 컨텐츠 | 일간 · 주간 컨텐츠 진행. 자동 모드(게임 스케줄러를 따른다)와 수동 모드 | `features/content-scheduler.md` |
| | 보스 | 주간 · 월간 보스 처치 현황 · 파티 인원과 분배 비율 | `features/boss-scheduler.md` |
| 수익·지출 | 보스 수익 | 결정석 수익 · 드롭 기록과 판매가 · 기간별 합계 | `features/boss-profit.md` · `features/item-drop.md` |
| | 가계부 | 월간 · 주간 달력. 보스 수익 · 드롭이 처치한 날에 들어오고, 수입과 지출을 손으로 적는다. 강화 지출은 넥슨 API 에서 읽는다 | `features/cashbook.md` |
| | 통계 | 기간별 순수익 · 추이 · 캐릭터별 · 내역 · 보스별 · 누적 | `features/stats.md` |
| 유틸리티 | 도구 목록 | 판매 분배금 계산기 | `features/utility.md` |
| 더보기 | 공지 · 설정 | 운영자 공지와 넥슨 공지 · 테마 여섯 · 추적 모드 · MVP 등급 · 캐시 데이터 삭제 · 연결 해제 | `features/settings.md` |

## 플랫폼과 전제

- React Native(Expo) 앱 하나로 Android 와 iOS 를 낸다([[ADR-005]]). 한국어만 지원하고, 스토어 배포 국가는 한국이다.
- 게임 데이터는 넥슨 Open API 로 읽는다. 앱을 쓰려면 사용자가 openapi.nexon.com 에서 발급한 개인 API 키를
  등록해야 한다([[ADR-024]]). 넥슨 로그인 코드도 들어 있지만, 넥슨 프렌즈 프로그램의 프로덕션 승인 전이라 꺼져
  있다(`NEXON_LOGIN_ENABLED = false`, [[ADR-025]]).
- 컨텐츠 · 보스 진행은 넥슨 스케줄러 API 가 주는 것만 보인다. 그래서 자동 모드에서는 사용자가 게임 클라이언트의
  스케줄러에 등록한 항목만 나온다.
- 기록의 원본은 기기에 있다([[ADR-004]]). 앱 자체의 회원가입은 없다. 우리 서버(mapleroutine.store)는 공지 ·
  게임 데이터 표 · 결산 안내를 내려주고, 사용자가 적은 드롭 판매가를 받는다([[ADR-016]] · [[ADR-018]]). 서버가
  꺼져도 기록하고 조회하는 기능은 기기에서 그대로 동작한다.
- 게임 수치(보스 표 · 결정석 가격 · 드롭 표)는 짐작해서 넣지 않고 사용자 확인을 받는다([[ADR-019]]).
- 넥슨 Open API 출처 표기 `Data based on NEXON Open API` 는 설정 화면 아래에 있다.

## 하지 않는 것

- 앱 자체의 회원가입과 클라우드 백업
- 메소 · 결정석 시세를 자동으로 가져오는 것. 메이플 포인트 · 캐시 환율도 사용자가 넣은 값만 쓴다
- 파티원 매칭 · 랭킹 같은 커뮤니티 기능
- 다국어
- 앱 안의 광고 노출. 광고 SDK 와 앱 ID 는 바이너리에 들어 있지만 지금 광고를 띄우는 코드는 없다([[ADR-014]])
- 판매 상품(인앱 구매 · 구독)

## 안내 사이트

스토어가 개인정보 처리방침 URL 과 지원 URL 을 요구해서 `mapleroutine.store` 에 안내 사이트를 둔다. API 키
발급 안내 · 문의 · 처리방침 페이지가 있다([[ADR-015]]). 앱 기능을 웹으로 옮긴 것은 아니다.
