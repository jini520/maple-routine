## 문의 전에 확인해 주세요

### 캐릭터가 목록에 보이지 않습니다

게임 클라이언트의 **스케줄러에 퀘스트·보스를 먼저 등록**해야 앱이 그 캐릭터의 진행 상태를 조회할 수 있습니다. 또한 넥슨 오픈 API는 최근 접속 기록이 없는 캐릭터의 정보를 제공하지 않는 경우가 있습니다.

### 데이터가 오늘 것과 다릅니다

넥슨 오픈 API는 **전날까지의 데이터를 기준일 단위로 제공**합니다. 실시간 반영이 아니며, 게임에서 방금 완료한 항목이 즉시 보이지 않는 것은 정상입니다.

### 기록을 지우고 싶습니다

앱 안에서 직접 지울 수 있습니다.

- **설정 → 캐시 데이터 삭제** — 지울 범위를 선택할 수 있습니다. "보스 수익·드롭 기록"은 **복구할 수 없습니다**
- **설정 → 앱 정보 및 계정 → 로그아웃** — 로그인만 풀고 초기 화면으로 돌아갑니다. 기록은 그대로 남습니다
- **앱 삭제** — 저장된 모든 데이터가 함께 제거됩니다

### 계정을 삭제하고 싶습니다

메이플 루틴은 드롭 아이템 판매가, 앱 사용 기록, 강화 합계에서 빠진 줄의 정보를 운영자 서버로 보냅니다([개인정보 처리방침](/privacy) 1-7 · 1-8). 이 값과 이용자를 가리는 값은 **앱 안의 계정 삭제**로 지웁니다.

1. 앱에서 **더보기 → 설정(톱니바퀴) → 앱 정보 및 계정**으로 갑니다.
2. **계정 삭제**를 누르고, 확인 창에서 한 번 더 **계정 삭제**를 누릅니다.
3. 서버가 요청을 받으면 로그아웃되어 초기 화면으로 돌아갑니다.
4. **30일 뒤** 계정이 지워집니다. 그 전에 같은 API 키나 넥슨 계정으로 다시 로그인하시면 삭제를 취소할지 여쭙니다.

| 계정 삭제 때 | 내용 |
|---|---|
| 바로 지워지는 것 | 로그인 세션 |
| 30일 뒤 지워지는 것 | 이용자를 가리는 값(API 키 해시 · 넥슨 계정 식별자) |
| 익명으로 남는 것 | 보낸 판매가 · 사용 기록 · 강화 정보. 이용자와의 연결이 끊겨 운영자도 누구의 것인지 알 수 없습니다. 사용 기록은 180일이 지나면 지워집니다 |
| 30일 뒤 함께 지워지는 것 | 옛 앱 버전이 보낸 보스 처치 · 가계부 · 강화 지출 기록 |
| 남는 것 | 기기에 저장된 기록. 지우시려면 같은 화면의 **데이터 삭제**를 이용하거나 앱을 삭제해 주세요 |

**메일로는 계정을 삭제할 수 없습니다.** 운영자는 API 키의 해시만 들고 있어서, 메일만으로는 어느 계정이 이용자의 것인지 찾을 수 없습니다. 이미 로그아웃하셨다면 같은 API 키를 다시 입력하거나 다시 로그인하신 뒤 계정 삭제를 실행해 주세요. 앱을 쓸 수 없는 사정이 있으면 support.mapleroutine@gmail.com 으로 알려 주세요.

### API 키를 바꾸거나 재발급하고 싶습니다

[openapi.nexon.com](https://openapi.nexon.com)에서 직접 재발급하신 뒤([발급 방법](/api-key)), 앱의 **설정 → 앱 정보 및 계정 → 로그아웃** 후 새 키로 다시 연결해 주세요. 기기를 양도하거나 폐기하기 전에도 로그아웃을 실행하시기를 권합니다.

## 버그를 신고하실 때

아래 정보를 함께 주시면 원인을 훨씬 빨리 찾을 수 있습니다.

- 앱 버전 (설정 화면 맨 아래에 표시됩니다)
- 기기와 운영체제 버전 (예: iPhone 15 / iOS 18)
- 문제가 발생한 화면과 그때 한 동작
- 가능하다면 화면 캡처

**API 키는 절대 공유하지 마세요.** 문의에 캡처를 첨부하실 때 키가 노출되지 않도록 가려 주시기 바랍니다.
