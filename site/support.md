# 문의

## 연락처

- **이메일**: support.mapleroutine@gmail.com
- **버그 신고·기능 제안**: [GitHub Issues](https://github.com/jini520/maple-routine/issues)

답변에는 수일이 걸릴 수 있습니다. 개인 개발자가 운영하는 앱인 점 양해 부탁드립니다.

## 문의 전에 확인해 주세요

### 캐릭터가 목록에 보이지 않습니다

게임 클라이언트의 **스케줄러에 퀘스트·보스를 먼저 등록**해야 앱이 그 캐릭터의 진행 상태를 조회할 수 있습니다. 또한 넥슨 오픈 API는 최근 접속 기록이 없는 캐릭터의 정보를 제공하지 않는 경우가 있습니다.

### 데이터가 오늘 것과 다릅니다

넥슨 오픈 API는 **전날까지의 데이터를 기준일 단위로 제공**합니다. 실시간 반영이 아니며, 게임에서 방금 완료한 항목이 즉시 보이지 않는 것은 정상입니다.

### 기록을 지우고 싶습니다

앱 안에서 직접 지울 수 있습니다.

- **설정 → 캐시 데이터 삭제** — 지울 범위를 선택할 수 있습니다. "보스 수익·드롭 기록"은 **복구할 수 없습니다**
- **설정 → 연결 해제** — API 키와 계정 선택을 지우고 초기 화면으로 돌아갑니다
- **앱 삭제** — 저장된 모든 데이터가 함께 제거됩니다

### 서버에 보낸 기록을 지우고 싶습니다

메이플 루틴은 드롭 아이템 판매가, 앱 사용 기록, 강화 합계에서 빠진 줄의 정보를 운영자 서버로 보냅니다([개인정보 처리방침](/privacy) 1-7 · 1-8). 이 값은 앱의 연결 해제나 앱 삭제로는 지워지지 않습니다. 지우려면 아래처럼 요청해 주세요.

1. 앱에 **연결 해제 전의 API 키가 그대로 있는지** 확인합니다. 운영자는 키의 해시만 들고 있어서, 키가 기기에 없으면 어느 기록이 이용자의 것인지 찾을 수 없습니다. 이미 연결 해제하셨다면 같은 API 키를 다시 넣어 주세요.
2. **support.mapleroutine@gmail.com** 으로 `서버 기록 삭제 요청` 이라는 제목의 메일을 보냅니다. 앱 설정 화면 맨 아래의 앱 버전을 함께 적어 주세요.
3. 운영자가 확인 방법을 답장으로 안내하고, 확인되면 그 이용자의 판매가 · 사용 기록 · 강화 정보를 모두 지운 뒤 알려 드립니다.

지운 뒤에도 탈퇴 기록은 남습니다. 같은 키로 돌아온 이용자를 같은 이용자로 잇기 위해서입니다. 사용 기록은 요청하지 않아도 180일이 지나면 지워집니다.

### API 키를 바꾸거나 재발급하고 싶습니다

[openapi.nexon.com](https://openapi.nexon.com)에서 직접 재발급하신 뒤([발급 방법](/api-key)), 앱의 **설정 → 연결 해제** 후 새 키로 다시 연결해 주세요. 기기를 양도하거나 폐기하기 전에도 연결 해제를 실행하시기를 권합니다.

## 버그를 신고하실 때

아래 정보를 함께 주시면 원인을 훨씬 빨리 찾을 수 있습니다.

- 앱 버전 (설정 화면 맨 아래에 표시됩니다)
- 기기와 운영체제 버전 (예: iPhone 15 / iOS 18)
- 문제가 발생한 화면과 그때 한 동작
- 가능하다면 화면 캡처

**API 키는 절대 공유하지 마세요.** 문의에 캡처를 첨부하실 때 키가 노출되지 않도록 가려 주시기 바랍니다.
