# API 키 발급 방법

메이플 루틴은 회원가입을 받지 않습니다. 대신 **본인이 직접 발급받은 넥슨 오픈 API 키**로 게임 기록을 조회합니다. 발급받은 키는 이용자의 기기에만 저장되며 운영자에게 전송되지 않습니다([개인정보 처리방침](/privacy)).

준비물은 **게임에 접속하는 넥슨 계정** 하나뿐이고, 아래 일곱 단계면 끝납니다.

> **API 키는 비밀번호와 같습니다.** 다른 사람에게 알려주지 마시고, 화면을 캡처해 공유하실 때는 키가 보이지 않도록 가려 주세요.

## 1. 넥슨 오픈 API에 로그인

[openapi.nexon.com](https://openapi.nexon.com) 에 접속해 오른쪽 위 **로그인**을 누릅니다. 게임에 접속하는 넥슨 계정으로 로그인해 주세요.

![넥슨 오픈 API 첫 화면에서 오른쪽 위 로그인 버튼](/images/api-key/01-login.png)

## 2. 마이 페이지 → 애플리케이션 등록

로그인하면 상단 메뉴가 열립니다. **마이 페이지**에 마우스를 올린 뒤 **애플리케이션 등록**을 누릅니다.

![마이 페이지 메뉴에서 애플리케이션 등록 항목](/images/api-key/02-register-menu.png)

## 3. 약관 동의 · 게임 · 단계 선택

- **약관**: 상자 안쪽을 **끝까지 스크롤**해야 아래 동의 체크박스가 활성화됩니다. 체크가 눌리지 않는다면 아직 다 내려가지 않은 것입니다.
- **게임**: **메이플스토리** 를 선택합니다. (게임당 3개까지 등록할 수 있습니다.)
- **단계**: **서비스 단계** 를 선택합니다.

> 개발 단계 키는 **초당 5건 · 하루 1,000건**으로 제한됩니다. 메이플 루틴은 여러 캐릭터를 한 번에 조회하기 때문에 개발 단계 키로는 도중에 막힐 수 있습니다. 반드시 **서비스 단계**로 받으세요.

![약관 동의 체크박스, 게임 선택 메이플스토리, 단계 선택 서비스 단계](/images/api-key/03-terms-game-stage.png)

## 4. 서비스 정보 입력

- **언어 · 서비스명**: `한국어(ko)` 를 두고, 서비스명에 **메이플루틴** 을 입력합니다.
- **설명**: 활용 용도를 한 줄로 적으면 됩니다. 자세히 쓰지 않아도 됩니다.

  > 메이플스토리 스케줄러 api를 활용하여 일간, 월간, 보스 스케줄 관리 및 보스 수익, 아이템 드랍 기록 애플리케이션.

- **개발환경**: **Web** 을 고르고, 서비스 URL에 `http://mapleroutine.store` 를 입력합니다.
- **태그 · 대표 이미지 · 스크린샷**: 항목 이름 앞에 필수 표시(빨간 점)가 없는 항목입니다. 비워 둔 채로 진행해도 됩니다.

다 입력했으면 맨 아래 **등록** 을 누릅니다.

![서비스명 메이플루틴, 활용 용도 설명, 개발환경 Web과 서비스 URL 입력 화면](/images/api-key/04-service-info.png)

## 5. 등록한 애플리케이션 열기

**내 애플리케이션** 목록으로 돌아옵니다. 방금 만든 **메이플루틴** 의 서비스명을 클릭합니다. App상태가 **정상** 이면 바로 사용할 수 있습니다.

![내 애플리케이션 목록에서 메이플루틴 행](/images/api-key/05-app-list.png)

## 6. API 키 복사

**기본정보** 탭의 **첫번째 API Key** 옆에 있는 복사 아이콘을 누릅니다.

![애플리케이션 상세 화면의 API Key 복사 아이콘](/images/api-key/06-copy-key.png)

## 7. 메이플 루틴에 붙여넣기

메이플 루틴 앱을 열면 나오는 입력란에 복사한 키를 붙여넣고 **확인** 을 누릅니다. 이후에는 다시 입력하지 않아도 됩니다.

![메이플 루틴의 API 키 입력 화면](/images/api-key/07-paste-in-app.png)

## 잘 안 될 때

### 약관 동의 체크가 눌리지 않습니다

약관 상자 **안쪽**을 끝까지 스크롤해야 체크박스가 열립니다. 페이지 전체가 아니라 약관 상자 안의 스크롤바를 내려 주세요.

### 애플리케이션을 더 등록할 수 없습니다

게임당 3개까지만 등록할 수 있습니다. 마이 페이지 → **애플리케이션 목록** 에서 쓰지 않는 것을 삭제하거나, 이미 등록해 둔 애플리케이션의 키를 그대로 쓰셔도 됩니다.

### 키를 넣었는데 캐릭터가 보이지 않습니다

게임 클라이언트의 **스케줄러에 퀘스트·보스를 먼저 등록**해야 앱이 그 캐릭터의 진행 상태를 조회할 수 있습니다. 자세한 내용은 [문의 페이지](/support)를 참고해 주세요.

### 키를 새로 받고 싶습니다

넥슨 오픈 API에서 재발급하신 뒤, 앱의 **설정 → 연결 해제** 후 새 키로 다시 연결해 주세요.
