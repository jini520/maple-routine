# 메이플 루틴

메이플스토리 플레이어를 위한 루틴 관리 앱입니다. 일간·주간 콘텐츠 소진, 주간 보스 수익, 물욕 아이템 드랍 기록, 사냥 중 스킬 재사용 타이밍을 캐릭터·계정 단위로 한 곳에서 관리합니다.

## 주요 기능

- **컨텐츠 스케줄러** — 게임 내 스케줄러에 등록한 일간·주간 콘텐츠의 진행 상태를 캐릭터별로 한눈에
- **보스 스케줄러** — 주간 보스 처치 현황과 파티 구성 관리
- **보스 수익** — 캐릭터별·기간별 결정석 수익 집계
- **물욕 아이템 드랍** — 획득 기록과 전 기간 히스토리
- **사냥 타이머** — 주기적 스킬 재사용 알림

## 이용 전 준비

이 앱을 쓰려면 두 가지가 필요합니다.

1. 게임 클라이언트의 **스케줄러**에 추적할 퀘스트·보스를 먼저 등록
2. [openapi.nexon.com](https://openapi.nexon.com)에서 발급받은 **본인의 개인 API 키** — [발급 방법을 화면 순서대로 안내](/api-key)합니다

앱은 회원가입을 받지 않습니다. 발급받은 API 키와 조회한 기록은 모두 이용자의 기기에만 저장되며, 운영자에게 전송되지 않습니다. 자세한 내용은 [개인정보 처리방침](/privacy)에서 확인하실 수 있습니다.
