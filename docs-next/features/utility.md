# 유틸리티

메이플을 하면서 필요한 도구를 모아 둔 탭이다. 지금은 **판매 분배금 계산기** 하나가 있다.
왜 이렇게 만들었는지는 [[ADR-001]] 에 있다.

|---|---|
| `app/utility/UtilityScreen.tsx` | 도구 목록(2열 타일) |

| `components/molecules/ShareField/` | 비율 입력. 보스 파티 설정과 같이 쓴다 |
| `navigation/routes.ts` · `navigation/RootNavigator.tsx` | `UtilityItemSplit` 라우트 |

## 도구 목록

유틸리티 탭은 2열 타일 목록이다. 타일에는 아이콘과 이름만 있고, 누르면 도구 화면이 루트 스택에
push 된다. 도구 화면이 열릴 때 하단바도 탭 화면과 함께 옆으로 사라지고, iOS 에서는 화면 왼쪽 끝을
밀어서 돌아올 수 있다.

도구를 추가할 때 고칠 곳은 네 군데다.

1. `routes.ts` 의 `ROUTE_TABLE` 에 한 줄(`origin: 'rn'`)
2. `RootNavigator.tsx` 의 `STACK_SCREENS` 에 한 줄
3. `UtilityScreen.tsx` 에 타일 하나
4. 이 문서와 ADR

## 판매 분배금 계산기

파티가 먹은 아이템을 한 명이 팔아서 나눠 줄 때, 파티원 한 명에게 얼마를 보내면 되는지 알려 준다.
판매할 때와 나눠 보낼 때 수수료가 두 번 떼여도 모두가 같은 금액을 갖게 되는 값이다.

| 입력 | 처음 값 | 범위 |
|---|---|---|
| 판매가 | 비어 있음 | 0 ~ 9,999,999,999,999. 단위 칩 다섯 개로 금액을 더할 수 있다 |
| 파티원 수 | 2 | 1 ~ 6. 1 이면 결과 대신 `혼자서는 나눌 것이 없습니다` |
| 비율로 입력 | 꺼짐 | 켜면 파티원 수 대신 내 몫과 비율 합을 받는다. 1:1 에서 시작한다 |
| 판매 수수료 | 3% | 3% · 5% |
| 분배 수수료 | 3% | 3% · 5% |

결과로는 `정산 금액` 하나만 보여 주고, 어디에도 저장하지 않는다. 계산식과 내림 규칙은
[[ADR-001]] 결정 1 · 2 · 4 에 있다.
