# 옛 ADR → 새 문서 분류표 (작업용)

재작성 동안만 쓰는 파일이다. `docs/` 와 바꿀 때 지운다. 옛 번호 333개가 새 문서 64개 중 어디로 가는지 적었다. 제목만 보고 나눈 초안이라, 옮기면서 본문을 읽고 맞지 않으면 이 표를 먼저 고친다. ⛔ 는 배너의 🔗 줄에 적힌 결정만 옮긴다.
