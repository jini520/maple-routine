# Step 0: docs-motion

이슈 **#38**(당겨서 새로고침)의 기능은 이미 구현돼 있다([[ADR-072]]). 그런데 **인디케이터 표현이 사용자에게 반려됐다** — 콘텐츠가 고정된 채 불투명 띠만 열려서, React Native `RefreshControl` 처럼 "페이지가 손가락을 따라 당겨지는" 물리 감각이 없다는 지적이다(2026-08-01).

이 task는 **표현 레이어만** 바꾼다. 제스처 감지·활성 조건·재조회 호출은 그대로 둔다.

이 step은 **문서 전용**이다. `src/` 는 한 줄도 건드리지 않는다(docs-first).

## 사용자가 확정한 것 (2026-08-01)

1. **헤더는 고정, 목록만 내려간다.** 제목·탭·새로고침 버튼이 있는 `sticky top-0` 헤더는 제자리에 있고, 그 아래 카드 목록만 손가락을 따라 내려간다. 벌어진 틈에 단풍잎이 뜬다.
2. **재조회가 도는 동안 목록은 내려간 채로 머문다**(RN `RefreshControl` 방식). 손을 떼면 임계 위치(56px)까지만 되돌아가 멈췄다가, 재조회가 끝나면 제자리로 돌아간다.

## 작업

### 1. `docs/adr/ADR-073.md` 신설

현재 최신 ADR은 ADR-072다. **반드시 ADR-073을 쓴다.** 기존 ADR 파일의 서식(배경 → 결정 N → 트레이드오프/한계 → 상태)을 따르라.

제목: `ADR-073: 당겨서 새로고침 인디케이터 — 불투명 배너에서 목록 이동(RN RefreshControl 감각)으로`

배경 절에 **왜 바뀌었는지**를 적어라: [[ADR-072]] 결정 4는 "목록을 밀어내지 않는다"를 택했고 그 근거는 ① 터치 프레임마다의 리플로우 회피 ② 보스 수익 `stickyHeaderRef` 실측 높이 불변이었다. 두 근거는 여전히 옳지만, **그 대가로 "당겨진다"는 물리 감각이 사라졌고 그것이 이 기능의 본질이었다.** `transform` 은 레이아웃을 건드리지 않으므로 두 근거를 지키면서도 콘텐츠를 움직일 수 있다 — 즉 결정 4는 필요 이상으로 강한 제약이었다.

아래 결정을 **전부** 담아라.

- **결정 1 — 헤더는 고정하고 목록 블록만 이동한다.** 사용자 지정. 헤더는 `sticky top-0` 로 "항상 그 자리"가 계약인 요소라, 당김에 따라 움직이면 그 계약이 깨진다. 고정 네비게이션을 가진 RN 화면의 일반적인 모양이기도 하다.
- **결정 2 — 이동은 목록 블록의 `transform: translateY()` 다.** 마진·높이·패딩이 아니다. `transform` 은 레이아웃을 유발하지 않고 컴포지터에서 처리되므로 [[ADR-072]] 결정 4의 두 근거(리플로우 없음 · sticky 헤더 실측 높이 불변)를 그대로 지킨다.
- **결정 3 — 휴지 상태에서는 `transform` 속성을 아예 걸지 않는다.** `translateY(0px)` 조차 containing block·stacking context를 만들어 `position: sticky` 후손(보스 수익의 중첩 카드 헤더, [[ADR-047]])의 동작에 영향을 줄 수 있다. 오프셋이 0이면 `transform` 을 `undefined` 로 두어 **평상시 DOM이 지금과 완전히 같게** 한다. `transition` 속성은 항상 걸어둔다 — 속성만으로는 아무 컨텍스트도 만들지 않으므로 복귀 애니메이션이 산다.
- **결정 4 — 드래그 중에는 전환(transition)을 끈다.** 손가락이 붙어 있는 동안 전환이 걸리면 목록이 손가락보다 늦게 따라와 "끌린다"는 감각이 죽는다. 손을 뗀 뒤(정착·복귀)에만 전환을 건다.
- **결정 5 — 재조회 중에는 임계 위치에 머문다.** 사용자 지정. 손을 떼면 `PULL_THRESHOLD_PX`(56px)까지 되돌아가 멈추고, 재조회가 끝나면 0으로 돌아간다. 대기 중이라는 신호가 **위치로** 남는다.
- **결정 6 — 인디케이터 높이와 목록 오프셋은 같은 함수에서 나온다.** 하나의 순수 함수(`resolveContentOffsetPx`)가 둘 다에 값을 준다. 두 벌로 계산하면 틈과 목록이 어긋나 인디케이터가 카드 위에 겹치거나 빈 띠가 남는다.
- **결정 7 — 인디케이터는 배경·테두리 없이 벌어진 틈 안에 중앙 정렬한다.** 목록이 내려가 생긴 틈은 이미 페이지 배경(`bg-bg`)이므로 덮을 것이 없다. [[ADR-072]] 결정 6의 불투명 배너(`border-b border-border bg-bg`)는 목록이 제자리에 있다는 전제에서만 필요했다. 단풍잎은 틈의 세로 중앙에 있어 틈이 벌어질수록 함께 내려온다.
- **결정 8 — [[ADR-072]] 결정 4·5·7의 배너 형태 부분을 폐기한다.** 지금 유효한 것은 이 ADR의 결정 1~7이다. 다만 [[ADR-072]]의 **결정 1·2·3·9·10·11·12·13·14는 그대로 유효**하다(제스처 감지 방식·최상단 판정·store 재사용·수익 과거 기간 비활성·헤더 버튼 존치·제스처 발 재조회에만 표시·재조회 중 재당김 금지·적용 범위·스크롤 레이어 가드). **폐기 범위를 이 문장 그대로 명시하라** — 다음에 읽는 사람이 무엇이 살아 있는지 헷갈리면 안 된다.
- **결정 9 — 문구와 스피너 규칙은 유지한다.** 3상태 문구(`당겨서 새로고침` / `놓으면 새로고침` / `새로고침하고 있어요`)와 "당김은 정적 단풍잎 회전, 재조회는 `MapleSweepSpinner`"([[ADR-061]] 스피너 2종 규칙 준수)는 [[ADR-072]] 결정 6·7 그대로다.

**위험 분석 절**을 두고 아래를 적어라(이것이 이 결정의 안전 근거다):

> `transform` 은 `position: sticky` 후손의 시각적 위치를 함께 옮긴다. 그러나 **제스처는 `window.scrollY <= 0` 에서만 시작되므로**([[ADR-072]] 결정 2), 당김이 일어나는 순간엔 중첩 sticky 카드 헤더가 아직 멈춰(stuck) 있지 않다 — 페이지 최상단에서는 모든 카드 헤더가 자기 자연 위치에 있다. 두 메커니즘이 겹칠 창 자체가 없다. 여기에 결정 3(휴지 시 transform 미적용)이 더해져, 스크롤 중인 평상시 DOM은 이 기능 도입 전과 동일하다.

트레이드오프/한계:
- 재조회 중 목록이 56px 내려가 있어 화면에 보이는 카드가 그만큼 줄어든다(결정 5의 대가).
- 이동하는 것은 목록뿐이라 헤더와 목록이 서로 다른 평면처럼 보인다 — 페이지 전체가 움직이는 iOS 러버밴드와는 다른 감각이다(결정 1의 대가, 사용자가 선택).
- **iOS·Android 실기기 검증은 여전히 미완이다**([[ADR-072]] `## 남은 검증`). 이번 변경으로 검증 대상이 하나 늘었다 — 목록 이동이 60fps로 따라오는지.

상태는 **`(설계, 구현 전)`** 으로 적는다.

### 4. `docs/foundation/design-system.md` 갱신

`### 당겨서 새로고침(pull-to-refresh)` 절의 레시피를 아래로 **교체**하고, 옛 배너 레시피는 문서 하단 `## 폐기된 정책 (history)` 섹션에 `~~당김 인디케이터는 sticky 헤더 아래 불투명 배너, 목록은 고정~~ → 목록이 transform으로 내려가고 벌어진 틈에 인디케이터([[ADR-073]])` 한 줄로 남겨라.

```
적용 화면: 컨텐츠·보스·수익 3개 탭 최상위 화면만(서브 화면·설정 탭 제외)

목록 블록(sticky 헤더의 형제, `px-4 pb-4` 를 가진 블록):
  style transform: translateY(<오프셋>px)   ← 오프셋이 0이면 transform 자체를 걸지 않는다
  style transition: 드래그 중 'none' / 그 외 PULL_SETTLE_TRANSITION

인디케이터: sticky 헤더 블록의 마지막 자식(페이드가 있으면 그 다음 형제)
  루트: pointer-events-none absolute inset-x-0 top-full z-[1] overflow-hidden
        style={{ height: <오프셋>px }}     ← 목록 오프셋과 같은 함수에서 나온 같은 값
        배경·테두리 없음 — 목록이 내려가 생긴 틈이 곧 페이지 배경이다
  내용: flex h-full items-center justify-center gap-2
  당기는 중/임계 초과: 정적 단풍잎(MAPLE_LEAF_PATH) h-5 w-5 fill=currentColor text-primary-ink
                      회전 = 진행률 × 180deg, 불투명도 = 0.3 + 0.7 × 진행률
  재조회 중:          <MapleSweepSpinner size={24} className="text-primary-ink" />
  문구: text-sm text-text-muted
        당겨서 새로고침 / 놓으면 새로고침 / 새로고침하고 있어요

문서 스크롤 기준: window.scrollY <= 0
제스처 무시: 스크롤 가능한 조상 안에서 시작한 터치([[ADR-072]] 결정 14)
러버밴드 억제: index.css 의 html, body 에 overscroll-behavior-y: none
```

절 말미의 "헤더 버튼으로 시작한 재조회에는 배너를 열지 않는다" 한 줄은 **유지**하되 '배너'를 '인디케이터'로 고쳐라([[ADR-072]] 결정 11은 살아 있다).
