## 공통 규칙 (이 step 의 모든 위젯에 걸린다)

- **위젯은 스토어를 모른다.** `data: TodayViewModel` 프롭만 읽는다([[ADR-146]] 결정 4).
- **`w`·`h` 로 갈라 스스로 다르게 그린다** — 큰 타일이 작은 타일을 확대한 것이 아니다.
  크기가 줄면 **무엇을 버릴지 위젯이 정한다.**
- **타일은 스스로 커지거나 줄지 않는다.** 크기는 배치가 준다(`4×auto` 만 예외, 정정 1).
- **타일 안에서 스크롤하지 마라.** 넘치면 자르거나 접는다 — 타일 안 스크롤은 페이지 스크롤과
  제스처를 두고 싸운다.
- **위젯은 사라지지 않는다**([[ADR-146]] 결정 5). 데이터가 없어도 **자기 타일 안에서** 빈 상태를 말한다 —
  좌표 배치라 자리를 빼면 빈 사각형이 남는다.
- **«없다» 와 «모른다» 를 가른다.** 동기화 실패로 모르는 것을 «0» 으로 그리지 마라
  (예외는 주간 보스 수익 하나 — 정정 4).
- **색은 테마 토큰만 쓴다.** 하드코딩 hex 금지(`/docs/features/theme.md`).
- **선언한 크기를 전부 구현한다**(사용자 확정) — v1 배치가 안 쓰는 크기도 나중 편집 기능을 위해 남긴다.
  각 크기는 **스냅샷 테스트**로 검증한다(그것이 안 쓰이는 분기의 유일한 안전망이다).


## 작업

### 1. 주간 보스 수익 — `widgets/WeeklyBossProfitWidget.tsx`

| 크기 | 형태 |
|---|---|
| **4x3** (기본) | 기간 라벨 + 큰 금액(32px) + 결정석/아이템 **스택 바 + 분해 금액** + 캐릭터 top3(내역 포함) |
| 4x2 | 왼쪽 금액 + 스택 바, 오른쪽 top3 |
| 2x2 | 금액 + 스택 바 (top3 없음 — 158폭에 이름+금액 행이 안 들어간다) |
| 2x1 | 금액만 |

- **금액 뒤에 「메소」**(정정 4). 목록 행(top3)에는 **안 붙인다** — 머리가 이미 단위를 말했다.
- **증감 칩을 그리지 마라**(정정 4). `rise`/`fall` 토큰은 보스 수익 화면에 그대로 살아 있고
  ([[ADR-087]]) **이 위젯에서만** 안 쓴다.
- **기록이 없으면 `0 메소`** 를 그린다(사용자 지시 — 결정 5 의 «큰 0 을 그리지 않는다» 를 여기서만
  뒤집는다). 대신 **옆에 한 줄**(«아직 이번 주 기록이 없습니다»)을 남겨 0원과 미기록이 완전히 같은
  그림이 되지 않게 한다. 뷰모델이 그 플래그를 준다.
- 금액 표기는 `formatMesoShort` 를 쓴다 — 두 벌로 만들면 이 타일과 수익 화면이 다르게 접는다.

### 2. 최고가 아이템 — `widgets/TopValuableItemWidget.tsx`

| 크기 | 형태 |
|---|---|
| **2x1** (기본) | 아이콘 36 + 「이번 주 최고가」 + `12.0억 메소` (아이템명 없음) |
| 4x2 | 왼쪽 1위 + 오른쪽 **`top 5`**(2~5위 목록) |
| 2x2 | 아이콘 40 + `12.0억 메소` **한 줄** + **아이템 이름 한 줄** + 캐릭터·보스 |
| 1x1 | 아이콘 + 금액 (**「메소」 없음** — 물리적으로 안 들어간다) |

- **「가장 비싼」은 시세가 아니라 기록된 판매가**다(결정 9). 뷰모델이 이미 `entered` 만 걸러 준다.
- **아이템 이름은 한 줄**(말줄임). 두 줄로 접으면 행 높이가 데이터에 따라 흔들린다.
- **미입력 칩을 이 타일에 넣지 마라**(정정 5) — 그것은 위젯 7 의 몫이다. 건수를 두 곳에서 말하지 않는다.
- 0건 문구는 **«가격이 입력된 아이템이 없습니다»** 한 줄뿐. «N건이 값을 기다립니다» 같은 문구를 넣지 마라.
- **1x1 을 제외한 모든 크기의 큰 금액에 「메소」**(정정 11).

## 테스트

- 네 크기 × 두 위젯 스냅샷
- 수익 기록 0건 → `0 메소` + 미기록 한 줄
- 수익 어디에도 증감 칩이 렌더되지 않는다(회귀 가드)
- 최고가 0건 → «가격이 입력된 아이템이 없습니다» 한 줄, **미입력 건수는 안 나온다**
- 4x2 가 2~5위를 그린다 · 항목이 모자라면 있는 만큼만
- 1x1 에는 「메소」가 없다

## 금지사항

- **증감 칩·`previousPeriodTotalMeso` 를 쓰지 마라.** 이유: 정정 4.
- **미입력 건수를 최고가 위젯에 넣지 마라.** 이유: 정정 5.
- **금액 접기를 직접 구현하지 마라** — `formatMesoShort` 를 써라. 이유: 두 벌이 되면 화면마다 다르게 접는다.
- **미입력 드롭을 «0메소» 로 순위에 넣지 마라.** 이유: 값을 모르는 것을 가장 싼 것으로 단정하는 일이다.
- 기존 테스트를 깨뜨리지 마라.
