# 기능 설명 이미지 (`packages/core/src/assets/guide/`)

`packages/core/src/data/feature-guides/**` 의 안내가 **직접 import** 하는 스크린샷 자리다([[ADR-125]] 결정 4).

```
packages/core/src/assets/guide/<안내 id>/<번호>-<무엇>.webp
예) packages/core/src/assets/guide/boss-party/01-card.webp
```

- 폴더 이름은 **안내 id** 다(`FeatureGuide.id`). 안내가 두 그룹에 서기도 하므로 그룹으로 나누지 않는다.
- 형식은 **`.webp`**. PNG 를 커밋하지 말 것 — 아래 변환을 먼저 거친다.
- 넣는 법 — 그 안내 파일 상단에 `import` 를 추가하고, 해당 블록에 `image: { src, alt }` 를 넣는다. 대체 텍스트는 타입이 강제하므로 빠뜨릴 수 없다.
- **대체 텍스트는 그 그림에 실제로 보이는 것을 쓴다.** 옆 블록의 문장을 복사해 두면 화면 읽기에서 같은 말이 두 번 나오고, 그림이 바뀌어도 아무도 눈치채지 못한다.
- **`import.meta.glob` 을 쓰지 않는다.** 파일명이 틀렸을 때 `undefined` 로 조용히 통과하는 대신 빌드가 실패해야 한다.

## 촬영본 변환

캡처한 PNG 는 그대로 두면 이 폴더에서 가장 무거운 것이 된다(2026-08-11 실측: 21장 2,092kB → 475kB, **−77%**). `sharp` 로 변환한다 — 새 의존성 없이 이미 `node_modules` 에 있다.

**파일마다 `lossless` 와 `q90` 을 둘 다 인코딩해 작은 쪽을 고른다.** 캡처는 성질이 두 갈래다 — 평평한 UI(모달·목록·칩)는 lossless 가 더 작고, 보스 초상·아이템 아이콘이 섞이면 q90 이 크게 이긴다. 한쪽으로 통일하면 둘 중 하나가 손해다.

- **폭은 줄이지 않는다.** 기기 논리 폭 390pt 의 2배인 780px 이 상한이고, 여기서 더 줄이면 문자가 뭉개진다.
- **4kB 미만은 Vite 가 base64 로 JS 에 인라인한다**(`assetsInlineLimit` 기본값). `dist/assets/` 에 파일로 안 보여도 사라진 게 아니라 `screen-settings` 청크에 들어간 것이고, base64 는 원본보다 ~33% 크다.

**OTA 는 `dist` 전체를 압축해 내려주므로 여기 넣는 이미지가 곧 번들 용량이다** — 지연 로드가 깎아 주지 않는다.
